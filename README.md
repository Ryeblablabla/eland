# ELAND

> 看一群人如何在三颗太阳下活下去。

![三颗太阳之下，文明在冰霜与烈焰之间生长](docs/assets/eland-readme-hero.png)

他们醒来时，世界没有说明书。

没人告诉他们水在哪里，火能做什么，也没人知道下一个乱纪元何时到来。太阳可能远去，冻住河流；也可能一同逼近，烧焦土地。

开局只有几个人。他们去河边取水，捡拾木头，在风暴前找一处能过夜的地方。一次失败可能被记住，教会后来的人绕开同样的弯路；也可能随当事人的死亡消失。走得多了，地上才有路。

## 没有预定结局

这里没有现成的时代和发明。点火之前要找到燃料，房屋要用搬来的木石慢慢筑成。有人根据天象作出预言，等纪元改变时，大家自然会知道他说对了没有。

有的文明学会耕种和烹饪，把经验留给下一代。有的困在缺水、受伤和反复失败里。一个发现也许会改变许多人的生活，也许只在某个人的记忆中停留几个月。

## 人只看得见眼前

他们不知道完整地图，更不知道历史希望他们走到哪一步。一个人只记得自己在哪里喝过水，谁曾在受伤时照顾他，哪种植物吃下去让身体好受了一点。

有人把食物分给同伴，几个人合力修好住所。一次错误的预言会失去信任，一次背弃会让原本亲近的人走远。这些小事积累多年，后来才会被称作文明。争夺、暴力和遗忘也在其中。

## 恒纪元与乱纪元

恒纪元里，雨水落下，作物有时间生长。孩子出生，老人衰弱，人们修补住处，继续手里的活。

乱纪元可能带来冰封、酷热或烈火。有人相信观星者的警告，提前储水或进入脱水休眠；判断错的人要承担后果。孩子、伤者和老人往往无法独自熬过去，得有人停下自己的事去帮他们。

恒纪元回来时，幸存者醒来，看看少了谁，再捡起工具。

## 史册的最后一行

有些文明延续数代，有些没能熬过第一个乱纪元。

最后一个人死去后，世界会留下这个文明的编号、经历和死因。结语只负责说出已经发生的事：

> 第 141 号文明，毁灭于烈焰。

随后，第 142 号文明在一片新的自然地表上开始。几位先民站在河边，不知道路会通向哪里，也不知道第一堵墙应该建在哪儿。

## 你看着他们

从宇宙望去，一个文明只是行星表面的微光。继续靠近，光里有了名字。一个人在取水，另一个在照料伤口。屋顶还差最后一块木板，观星者正把猜测说给同伴听。

再近一点，有人把水留给孩子，把火种交给同伴。旁边那块屋顶，今天还没盖完。
