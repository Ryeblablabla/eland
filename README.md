# ELAND

> 一颗行星，三颗太阳。无数次从灰烬中重新学会成为人。

![三颗太阳之下，文明在冰霜与烈焰之间生长](docs/assets/eland-readme-hero.png)

他们醒来时，世界没有说明书。

没有人告诉他们水在哪里，火能做什么，寒夜还要持续多久。没有人知道头顶的三颗太阳何时会远去，何时又会一同逼近，把河流冻成沉默，或把土地烧成灰烬。

他们只有身体、眼前所见，以及彼此。

于是，第一个人走向河边。第二个人捡起木头。有人在风暴前寻找遮蔽，有人守着生病的孩子，有人抬头观察太阳留下的轨迹。一次尝试失败了，另一次被记住；一段经验传给了后来出生的人，一条踩出来的路渐渐通向共同的火堆。

文明就这样开始了。

## 没有预定结局

这里没有注定被点亮的时代，也没有保证出现的伟大发明。

一把火，必须真的有人找到燃料并把它点燃；一间房屋，必须真的有人搬来木石，一点点筑成；一句预言，必须在天空改变之后接受检验；一项传统，也必须被人记住、相信、传给下一个人，才可能活得比它的创造者更久。

有些文明会学会耕种、烹饪、记录与照护。有些文明会在漫长的匮乏中停滞。有些发现只存在于一个人的记忆里，随他的死亡永远消失。也有些微小的善意，会在许多年后变成一个共同体赖以生存的习惯。

没有任何结果因为“应该发生”而发生。

## 每个人只看得见一小片世界

他们看不见完整地图，也不知道历史期待他们成为什么。

他们只知道自己曾在哪里喝到水，谁在受伤时照顾过自己，哪一种植物让疼痛减轻，哪一次轻信带来了代价。饥饿会让手里的活停下来，恐惧会改变一段计划，衰老则来得比任何人希望的都早。有人把孩子抱进避难处，也有人背弃承诺，从此失去同伴的信任。

所谓文明，并不是一个不断上涨的数字。

它是一个人把食物分给另一个人，是几个人决定一起修好住所，是错误的预言失去信任，是正确的经验终于没有再次失传。它也可能是争夺、暴力、离散与遗忘。文明从来不只意味着进步；它意味着人和人之间发生过的一切，留下了后果。

## 太阳不会在意

恒纪元里，雨落下来，作物生长，新的孩子在火光旁出生。

乱纪元到来时，世界可能骤然冰封，也可能在烈日下干裂燃烧。有人相信观星者的警告，提前储水、迁徙、脱水休眠；有人迟疑，有人判断错误。成年人也许能熬过灾难，孩子、伤者与老人却需要他人停下自己的计划，伸出手来。

宇宙不会因为他们刚刚学会希望，就多给一个春天。

但他们仍会在每一次恒纪元归来时醒来，清点幸存的人，捡起散落的工具，在废墟旁重新点火。

## 史册的最后一行

文明可能延续数代，也可能在第一个乱纪元便消失。

当最后一个人倒下，留下的不会是一句预先写好的台词。世界会记得他们怎样生活、发现过什么、爱过谁，又究竟被什么带走。然后，历史为这段真实发生过的时间写下最后一行：

> 第 141 号文明，毁灭于烈焰。

星球沉默片刻。

第 142 号文明在河边醒来。

他们不知道哪条路最后会被踩出来，也不知道第一堵墙该建在哪里。他们只看见水、石头、陌生的同伴，以及天上三颗正在移动的太阳。

故事再次开始。但它绝不会重复。

## 你从远处看着

从遥远的宇宙望去，一个文明只是行星表面短暂的微光。

继续靠近，你会看见那束光里有名字：有人正在取水，有人正在照料伤口，有人在屋顶落下最后一块木板，有人第一次把对天空的猜测说给同伴听。再靠近一点，你会发现所谓历史，不过是无数个渺小的人，在并不知道结局的时刻，做出了各自能够做出的选择。

ELAND 不急着知道人类最终能够攀登多高。

它更想记下这些时刻：太阳还会回来，可人们仍把水留给孩子，把火种交给同伴，再为明晚多盖一块屋顶。
