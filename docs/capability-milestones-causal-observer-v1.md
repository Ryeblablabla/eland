# ELAND 能力里程碑因果观察器 v1

状态：历史版本，运行时已由 [v2](./capability-milestones-causal-observer-v2.md) 取代。本文保留 v1 当时的目录、回放结果和已知局限，不再代表当前观察器。

v1 当时共有 120 个定义并声称覆盖 117 个能力地图编号；后续审计发现多项语义错配、重复 detector 和过宽代理条件。当前运行时的准确统计、严格语义和重投影见 v2 文档。

## 边界

能力地图是事后观察坐标，不是科技树、任务列表或解锁顺序。人物不能读取定义、已达成数量或文明指数；模型文本也不能直接让里程碑成立。

“里程碑”不等于成就或进步。它可以是：

- 形成：新的做法、关系或制度出现；
- 稳定：做法被重复、传播或跨时间保持；
- 伤害：偷盗、暴力、杀人、强制、违约和排斥；
- 应对：抵抗偷盗、照护受害者、撤销授权或修复信任；
- 衰退与崩溃：项目阻塞、约定破裂、成员退出、共同体解体、知识无在世持有者；
- 恢复：灾后重建、技术重新被验证、信任或组织重建。

## 定义与观察分层

每项定义保存：

- 稳定 `id` 和对应的 `capabilityId`；
- 地图领域、价值属性 `constructive/harmful/ambivalent`；
- 阶段 `emergence/practice/stable/decline/collapse/recovery/harm/response`；
- 不少于两条的结构化因果条件；
- 判定说明和观察器版本。

观察结果另外保存参与者、受影响者、首次观察月份、发生次数和证据事件 ID。定义可以很多，观察结果只能来自真实历史。

## 因果判定规则

1. 一般项至少需要两个可连接事实，并用人物、物质、目标、约定、项目或来源 ID 中的至少一种关联键完成 join。
2. 出生等月度原子结算可作为例外，但事件本身必须同时保存父母、新人物和遗传/身体后果，而不是一句描述。
3. 状态实体可作为结果，但必须携带可解析的 `sourceEventIds`，如共同体、成员身份、授权、记录、项目和知识。
4. 不匹配 `result`、`summary` 或模型文本；不用文明指数、里程碑数量或隐藏地图做证据。
5. 同一事件可以支持多个观察坐标，但重复观察不能反过来改变世界事实或角色选择。

## 伤害事件的严格语义

- 偷盗尝试：未授权的人际转移返回 `attempted=true` 且被持有者抵抗；物资没有改变持有者。
- 偷盗得手：未授权的人际转移为 `completed`，`authorized=false`，并记录来源、去向、物质和数量。
- 人际暴力：`exert` 的人物目标与 `diff.victimId`、真实健康损失和伤口来源一致。
- 人际暴力致死：死亡事件的 `sourceEventIds` 必须追溯到以死者为 `victimId` 的人际施力事件。普通衰老、饥渴、暴露、疾病或动物袭击死亡不得计入。当前事实没有“行为人明知、故意或违法性”字段，因此观察器只能报告“人际暴力致死”，不能进一步声称法律或心理意义上的 `murder`。
- 强制拘束：绳的真实消耗/结合、受拘束人物 ID 与持续身体状态来源必须一致。
- 违约：必须先有已接受约定，再有超期的 `agreement:breached` 事实；拒绝、未回应过期、参与者死亡取消与已履约都不等于违约。

## 渐进与逆转

不通过“前置里程碑已解锁”判定后续阶段。稳定阶段必须由多人重复、跨月延续、实体制度或跨代传播的事实直接判定。衰退、崩溃和恢复使用同一实体 ID 或相同知识/功能键连接前后状态。

## 与文明指数的隔离

观察器从 30 项扩展到 100+ 后，不得因“换了一本更细的字典”而让历史得分自动上升。历史多样性将按真实结局锚点去重，同一因果链命中多个坐标只算一个历史事件；转折种类按领域、价值属性和阶段统计，不按定义 ID 堆数。公式版本变更前后的文明指数不做直接 A/B。

## 验收

- 定义数不少于 110，不同能力编号不少于 100；
- 定义 ID 唯一，每项有因果条件和领域/价值/阶段元数据；
- 所有观察证据 ID 都能在权威事实历史中解析；
- 聚焦回放覆盖偷盗尝试/得手、普通死亡/杀人、履约/违约的负例隔离；
- 对现有 10/20/30 年状态做多种子复投影，人工抽查首次出现的伤害、制度、知识和崩溃链；
- 新观察层不改变权威事件、人物意图、模型调用或确定性回放。

## 当前负向复杂性基线

v8 与 v9 各三个完整 30 年世界中，偷盗尝试、偷盗得手、人际暴力、强制拘束、暴力致死、约定违约、共同体退出和解体全部为 0，只有少量拒绝事实。对当前保存的 174 份 `state.json` 做结构化字段扫描，也没有找到未授权取物或人际伤害事实。

这些零发生不能用虚构里程碑补齐。底层已有未授权转移、抵抗、人际施力、绳索拘束和约定违约的合法性/后果规则，但当前动机入口过窄：求生反射往往在营养进入偷盗阈值前解决食物；暴力又需要已经很高的恐惧或极低信任，而恐惧的主要来源本身就是偷盗和暴力。后续行为版本必须从真实稀缺、财产竞合、关系破裂、外部威胁和被目击的历史中建立可达因果路径，不能为了达成负向里程碑人为强制冲突。

首批候选审计共形成 120 个定义、覆盖 117 个坐标，其中 108 个定义能由当前结构化事实形成严格正例；另外 12 个只能作为部分观察或负向守卫，不能报告完整达成：38 专业分工、103 止血、113 淘汰无效疗法、143 通风、147 修补住所、160 灾后重建日常、240 教学体系恢复、252 隐瞒/销毁/篡改记录、393 道路阻断与运输延误、466 囤积、500 灾后社区网络重建、642 识别欺骗与诈骗。它们分别缺少职业身份、出血、疗法比较、通风、构件损坏、生活连续性、学校实体、记录篡改、道路阻断、囤积意图、社区身份连续性或明知为假的事实字段。

## 既有历史重投影

使用同一 `capability-causal-v1` 观察器只读重投影 v8 与 v9 各三个 30 年终点，没有推进月份或改写存档：

| 行为版本 | seed | 已观察能力坐标 | 形成/实践/稳定 | 伤害/崩溃/恢复 | 未解析证据 |
|---|---:|---:|---:|---:|---:|
| v8 | 185 | 73 | 17 / 31 / 15 | 1 / 1 / 2 | 0 |
| v8 | 20260815 | 67 | 16 / 29 / 11 | 1 / 2 / 2 | 0 |
| v8 | 20260816 | 66 | 16 / 30 / 12 | 0 / 2 / 0 | 0 |
| v9 | 185 | 70 | 16 / 29 / 15 | 1 / 1 / 2 | 0 |
| v9 | 20260815 | 61 | 16 / 28 / 9 | 1 / 1 / 0 | 0 |
| v9 | 20260816 | 65 | 16 / 29 / 11 | 0 / 1 / 2 | 0 |

六次历史均没有观察到偷盗未遂、偷盗得手、人际暴力、人际暴力致死或违约；有害阶段来自真实营养危机，崩溃阶段主要来自死亡。v8 的两个种子还观察到技术失传：一项石材结合技术，以及石材结合、兽皮衣和骨制工具技术，在终点已没有在世可靠持有者，也没有仍存在的实体记录载体。恢复阶段来自同一项目先有失败/物流失效来源、随后真实完工。

用同一 `causal-diversity-v3` 公式分别投影旧 30 项观察结果与新目录结果时，历史分变化为 `0..5.63`，但文明总分只变化 `0..0.56`。新增分数来自新识别出的真实结果锚点和“领域 + 价值属性 + 阶段”组合，不来自 120 个定义本身；未发生的定义仍为 0，同一结果事件命中多个坐标只计一个因果片段。

完整重投影保存在 `three-body/data/experiments/capability-milestone-reprojection-v8-v9.json`。聚焦测试另外验证了：被抵抗的偷盗尝试不算得手；无主容器取物不算偷盗；普通死亡不算人际暴力致死；拒绝、过期和取消不算违约；12 个守卫定义永不产生观察结果。

## 长历史约束

1000 年上限下，观察器不能为每个定义重扫全部历史。v1 在一次投影中共享 `eventById`、按种类/人物/月份的索引和实体索引；长期存储改为只追加历史分段后，再用带 `throughEventSeq` 和公式版本的派生缓存增量消费新事实。缓存可丢弃并从完整事实重建，不代替因果历史。
