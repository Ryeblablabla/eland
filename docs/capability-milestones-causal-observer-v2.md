# ELAND 能力里程碑因果观察器 v2

状态：运行时已实现，并已对 v19/v20e 六条 30 年权威存档完成只读重投影。定义版本为 `capability-causal-v2`。

关联：[一千项能力地图](./human-society-capability-map-1000.md) · [因果链目录](./capability-milestone-causal-chains-v2.md) · [涌现能力底座](./emergent-capability-substrate-v1.md)

## 目录口径

当前共有 `137` 个定义：

- `120` 个 map 定义，一一占用《一千项能力地图》的 `120` 个不同坐标，并保存地图原始 `mapLabel`；
- 其中 `51` 个有当前结构化事实支持，可由 strict detector 观察；
- 其余 `69` 个是 guarded：坐标和缺失条件已经定义，但证据不足时永不报告“已发生”；
- 另有 `17` 个 world-specific 定义，不占用任何地图编号，记录恒乱纪元和当前世界确能严格判定的复杂事件。

目录数量不是文明成果。一个世界只报告其权威历史真正闭合的定义；guarded 条目、测试夹具和目录中尚未发生的负向事件均为零。

## 边界

里程碑是下游观察坐标，不是科技树、任务、解锁条件或人物目标。人物规划器、模型提示和文明指数均不能读取目录来决定行动。

“里程碑”也不等于正向进步。定义同时保存：

- `constructive / harmful / ambivalent`；
- `emergence / practice / stable / response / harm / decline / collapse / recovery`；
- 最少 episode、不同月份、不同参与者、证据事件数和可保留 episode 上限；
- 至少两段可执行的因果条件，以及完整、可解析的事件 ID。

稳定阶段必须跨月、跨人物、重复发生或包含多事件实体链，不能由一个孤立事件触发。观察结果的 `occurrenceCount` 只描述实际保留的完整 episode，不声称代表被截断的全部历史频次；单定义最多保留 `64` 个可回放证据事件。

## 地图坐标与世界事件分离

地图编号只能在语义严格一致时使用。例如：

- `802 设计算法处理重复任务`、`805 加密通信与保存信息`、`808 进行电子支付与线上交易` 都保持 guarded；恒乱纪元预言不会再冒充这些能力。
- `165 确认或争议亲子身份` 不再由出生事实触发；出生只证明诞生和遗传亲缘，不能证明人物进行过身份确认或争议。
- `322 切割、打磨与钻孔` 保持 guarded；普通植物/木材分离也不再冒充 `354 管理森林采伐`。后者必须等限采、轮采、再生或资源存量管理成为结构化事实后才可解除 guarded。
- `384 规划路线与行程` 不再由普通项目物流触发，`392 协调跨地域供应链` 也不会由本地搬运冒充。
- `903 因违约失去信任` 保持 guarded，因为当前只有违约结果，没有可回放的信任下降事实；“已接受约定逾期未履行”另作为 world-specific harm 记录。

三体特有的天气发生、纪元循环、预言提出/应验/落空和跨次预测实践属于 `three-body` 世界事件。天气自然变化可以记录“世界发生了变化”，但不能自动形成 `58 观察自然现象` 或 `841 识别危险`；后两者仍要求人物真实观察或识别事实。

## 负向复杂性

当前严格定义包括：

- 未授权人际取物被抵抗与偷盗得手；
- 人际施力造成伤害，以及死亡事件明确追溯到同一受害者施力来源；
- 绳索拘束与解除拘束；
- 已接受约定逾期未履行；
- 共同体成员退出、解体与退出后的恢复；
- 项目有来源阻塞与同一失败后的恢复完成；
- 最后可靠持有者死亡且无实体记录后的技术失传；
- 动物袭击人物。

观察器只能报告“人际暴力导致死亡”，不能从结果推断行为人的故意、法律责任或“谋杀”。普通衰老、疾病、饥渴、气候和动物导致的死亡都不能算人际杀人。

关键负例已锁定：被抵抗的未授权取物不算偷盗得手；容器取物不算偷盗；普通死亡不算暴力致死；拒绝、未回应过期和取消不算违约；记录被搬运但无人理解不算共享记忆；一次喂养不算稳定养育；四块不相连的夯土不算道路；一个人物营养不足不算群体饥荒。

## 渐进链而非解锁链

同一因果家族可以从一次实践发展到跨月稳定，也可以分叉到伤害、崩溃和恢复。例如：

```text
取得食物 → 烹饪/储藏 → 重复协作供给
                     ↘ 多人短期营养伤害（饥荒）

单次协同行动 → 多个跨月共同项目 → 团队工作流程

持有与许可 → 未授权取物尝试 → 得手/抵抗
                              ↘ 人际暴力 → 伤害/致死

项目供给失败 → 项目阻塞 → 同一失败来源后的恢复完成

可靠技术 → 持有者死亡且无载体 → 技术失传 → 后续重新验证（待底层事实支持）
```

箭头只描述可审计的因果家族，不要求人物先“解锁”前一个里程碑。后项必须从自己的世界事实直接成立；观察器结果不反向进入世界。

真实主干仍包括诞生—养育—衰老—死亡、采集—工具—火—烹饪—衣物—住所、栽培、契约、自然观察与试验、跨月保存的记录实体、制绳与容器、仓储、共同项目、共识和恒乱纪元预测。

当前自然历史只出现了三类负向/逆转复杂事件：技术失传、已接受约定违约、项目阻塞；同时出现了项目恢复。偷盗得手、人际伤害、暴力致死、拘束、共同体退出/恢复和动物袭击仍为零。零发生表示这六条历史没有闭合相应条件，不是目录缺失，也不能靠换种子或注入剧情补齐。

以相同 `causal-diversity-v3` 文明指数公式重算时，二次审计相对存档里的旧里程碑投影使总分变化为 `0..-0.24`。这说明收紧字典没有制造分数红利；文明指数只把真实因果结局和领域/阶段多样性作为历史证据。

初版与二次审计产物分别为 `three-body/data/experiments/capability-milestone-reprojection-v19-v20e-v2.json` 和 `three-body/data/experiments/capability-milestone-reprojection-v19-v20e-v2-audit.json`。

## 验收与后续扩展

当前聚焦回归和后端构建均通过：

- 目录不少于 100 个精确地图坐标，ID 唯一，标签逐项与源文档一致；
- world-specific 定义无 `capabilityId`，不会污染地图坐标；
- guarded 定义永不产生观察结果；
- stable 定义拒绝单事件捷径；
- 所有输出证据可解析，观察器不修改权威状态；
- 模型文本、摘要相似度和文明指数都不参与判定。

后续扩展应先为 guarded 坐标补齐可产生后果的底层事实，例如职业身份、出血、疗法比较、空气流动、构件损坏、亲子身份主张、路线计划、信任变化、调查过程和社区连续身份；随后再把对应定义从 guarded 升为 strict。不得仅为提高覆盖率复用一个宽泛 detector。
