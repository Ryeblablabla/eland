# ELAND 文明指数 v1

## 1. 目的

文明指数用于表示“文明已经演化到什么程度”，取代旧的“文明完整度”。旧指标只计算存活者平均健康，实际上衡量的是群体健康，不是文明演化。

新指数是对权威世界状态的纯观察投影：它不授予科技、不改变人物决策，也不决定历史结果。每个分项都保留可回放的原始证据数量。

## 2. 总分

`CI = P×0.20 + T×0.20 + K×0.25 + S×0.25 + H×0.10`

- `P` 人口数量；
- `T` 地区探索与地形改造；
- `K` 科技发展；
- `S` 社会关系与人际互动复杂度；
- `H` 历史多样性。

所有分项和总分均为 `0..100`。总分保留两位小数。

## 3. 五个分项

### 3.1 人口 `P`（0.20）

`P = 100 × (1 - exp(-livingPeople / 28))`

灭绝时为 0。使用饱和曲线，避免人口无限线性抬高指数：6 人约 19.3 分，25 人约 59.1 分，50 人约 83.2 分。

### 3.2 探索与改造 `T`（0.20）

- 探索格：人物所在格、真实移动路径、通行记录和个人已知地点的并集；
- 改造格：行动事件造成的材料变化、种植、道路和结构占地的并集；
- 自然冻结、降雨和动物取食不计入“人类改造”。

`exploration = min(100, exploredCells / (worldCells×35%) × 100)`

`modification = min(100, modifiedCells / (worldCells×5%) × 100)`

`T = exploration×0.5 + modification×0.5`

### 3.3 科技 `K`（0.25）

- `techniques`：置信度至少 55 的唯一技术知识，加上实体记录中保留的技术；
- `processes`：真实完成过的结合、分离、施力、暴露和捕猎“操作+产物”类型；
- `diffusion`：已核验技术在当前成年存活者中的平均覆盖率。

`K = saturating(techniques, 8)×0.5 + saturating(processes, 7)×0.3 + diffusion×0.2`

`saturating(n, scale) = 100 × (1 - exp(-n/scale))`

这样新增配方不会让旧文明的得分倒退，但只有个人偶然成功、未核验也未传播的经验不会被高估。

### 3.4 社会 `S`（0.25）

- 关系网络：具有事件来源或足够信任、羁绊、恐惧强度的唯一人际对；
- 互动广度：发生过直接沟通、人际转移或对人行动的唯一人际对，以及互动类型多样性；
- 制度事实：协议、共同体、决策规则、职责和授权。

`S = relationCoverage×0.30 + (interactionCoverage×0.60 + interactionVariety×0.40)×0.45 + institution×0.25`

重复聊天不能靠事件量无限刷分；负向关系也属于社会复杂性，但不代表道德上的正面评价。

### 3.5 历史 `H`（0.10）

事件按生死、气候、天气、动物、身体状态、移动、转移、各类物质操作、沟通语用、协议等类别分组。决策机会日志不计入，避免调度噪声刷分。

`H = normalizedShannonEntropy×0.45 + min(categoryCount/20, 1)×100×0.35 + saturating(milestones, 10)×0.20`

它同时奖励类型丰富、分布不被单一重复事件垄断，以及已被证据观察器识别的里程碑。

## 4. 阶段名称

- `< 12`：萌生人群；
- `12..<28`：自然探索群体；
- `28..<46`：技术聚落；
- `46..<68`：复杂共同体；
- `>= 68`：成熟文明。

阶段只是指数区间的人类可读名称，不会反向解锁能力。

## 5. 计算节奏与存档

- 前台逐月演化时每月重算；
- 后端长时演化时每 12 个月和终点重算；
- `SimulationState.civilization.civilizationIndex` 保存总分、五个分项和证据数量；
- 演化 checkpoint 直接保存完整指数快照，不再输出 `integrity`。
