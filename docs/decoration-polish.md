# 装饰层质感调整

本轮基于开始工作时的实际工作区保存基线，仅调整视觉呈现。没有修改模拟、地图生成、地形高度、建筑占地、资源数量、人物尺度或交互逻辑。

## 改动

- 现有阴影贴图在近景使用更集中的覆盖范围，降低法线偏移；轻调 GTAO，让屋檐与接触处更清楚，不扩大贴图或增加后处理 pass。
- 新增一个贴地阴影实例批次，最多 256 个平面。只读取真实住房、树根及落地物资，按格合并，18–34 世界单位渐隐，34 外不绘制。高处或无法确定承重面的物资跳过；没有拾取代理。
- 原材质分桶复用现有盒子和实例色。木材、茅草、石材与瓦面增加克制的表面亮度/粗糙度变化；14 内完整，52 外消退，并抑制亚像素高频。叶面保持安静的哑光。
- 风按植物原点统一计算，避免每个方块独立摇晃；已有烟雾方块平滑漂升与回收。没有新增烟、火、树叶或资源实例，35 外恢复原位置/尺寸。
- 晴天及干燥天气下增加轻微远景空气透视，沿用现有天光颜色来源，不改变天气事实。

## 有界验证

- 与冻结基线逐实例比较：第 16 号文明 49,941 个、第 75 号文明 57,032 个；几何、材质桶、颜色值、顺序、数量及原动画标记完全一致，仅增加共享风原点元数据。
- 接地层完整同步中位约 0.62 / 1.55 ms，含矩阵更新约 0.26 / 0.50 ms；缓存命中低于 0.03 ms。远处实例为零。
- 实际浏览器同中景短测 90 帧：帧间隔中位 33.7 → 33.7 ms，95 分位 50.7 → 50.1 ms；包含阴影和 AO 的绘制调用中位 1423 → 1310。两页面均运行于同一设备和视口，这只是短时对照，不是全场景帧率保证。
- 完整装饰动画 CPU 的四组近远景短测均下降。首次装配耗时波动过大，不将其作为改善结论；原始值保留在 acceptance-cpu-scope.json。
- Vite 生产打包通过，实际 WebGL shader 编译没有错误。整仓 TypeScript 检查报告了一处同期非装饰代码的未使用导入：`src/game/eland/domain/actions/world-assembly.ts:2` 的 `MaterialId`。为遵守本轮范围，没有改该规则文件。

没有新增 CI、模拟测试套件或长时间演化测试。

## 后续：体素展示规则优化（2026-09-09）

用户随后允许优化体素模型本身。上面的六张截图与性能记录保留为上一轮材质/阴影工作的历史对照，本次另外记录在 `tmp/plant-display/`。

- 浆果丛与普通灌木共用按世界种子、格子位置确定的株形；果实仅表示结果状态，不代表精确产量。每个果实标识都接触叶面，并与叶丛共用风原点。单丛最多 22 个方块实例。
- 物资先适配槽位，再乘原有数量系数，让少量与大量的大小区别生效；零数量不显示。
- 注册容器的外部尺寸不随内容量改变；空箱露出内腔，装载高度按真实填充比例，填料采用实际主内容物的材质和颜色。内容物变更会刷新装饰，即使总装载量不变。
- 继续保持同格最多四个语义堆；主要松散资源和非空容器优先，空箱后置。

本次未修改生长、收获、库存、建造或交互规则。局部验证覆盖果实贴叶、结果/无果株形一致、数量大小差异、空箱与满箱外部尺寸一致、同容量内容变化刷新，以及主要资源不会被空箱挤掉；生产打包通过。原有非装饰文件的未使用类型导入诊断仍未改动。
