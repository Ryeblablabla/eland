# ELAND 双闭环 v8–v33 历史迭代账本

状态：已冻结的历史账本。范围实际为 v8～v33；表内状态记录各版本作出决定时的结论，不代表当前待办。新的规则实验应单独建立带日期的报告，不再继续扩展本文。每个版本只有在完成“因果预登记 → 实现 → 配对矩阵 → 历史诊断 → 决定”后才计数；单纯改文档、改观察器显示或重跑相同代码不计为新版本。

## 固定规则

1. 人物只响应身体、环境、局部感知、来源记忆、关系和承诺；文明指数不进入人物规划。
2. 每个普通候选至少使用 3 个相同种子的配对运行；跨代、制度与生态机制使用 10/20/30 年。
3. 10/20/30 年通过后，关键候选用同种子扩展到 50/100 年；最终或关键代际候选可继续到文明全员死亡，未灭绝时硬上限为 1000 年。确定性重跑只验证回放，不增加样本数。
4. 每轮同时检查人口、生存、项目、生产、建造、物流、知识、社会、制度、移动和模型独立性。
5. 允许机制级接受而整体候选继续修订；不利种子、灭绝、停滞和零发生必须保留。
6. 模型调用保持异步、可缺省、来源绑定；模型输出必须经过本地合法性和后果裁决。
