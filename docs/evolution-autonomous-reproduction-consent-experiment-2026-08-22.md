# 生殖自主同意实验（2026-08-22）

状态：机制候选通过；30 年初步人口回归通过，但未完成长程裁决。

## 可证伪假设

当前生殖链已经有连续的 `consent` appraisal，会读取人物自己的关系、亲缘风险和照护负担，但固定双向 `trust / bond >= 60` 在提议、接受和最终执行三处先行裁掉候选，导致人物无法对低于 60 的真实关系自行判断。若只移除这项固定关系合法性门槛，并保留有来源关系、成年与身体条件、明确提议、独立接受、可撤回协议和动作时协议重验，那么人物应能按本人关系、人格、恐惧、责任和已知风险选择接受或拒绝，而不是由引擎替其拒绝。

预期链：

```text
本人的有来源关系
→ 身体条件允许时出现生殖提议候选
→ 提议者的 BDI 自行决定是否开口
→ 对方同时获得接受 / 拒绝候选
→ 本人的连续 consent appraisal 排序
→ 明确接受才形成可撤回的短期协议
→ 每次尝试前再次在“继续 / 撤回”之间判断
→ 有效协议 + 当前身体合法性才允许生殖动作
```

## 基线与接受标准

本轮基线沿用上一轮当前代码已冻结的三种子 30 年矩阵：

- artifact：`three-body/data/experiments/candidate-young-trust-ticks-v1-20260822.json`
- seeds：`185 / 20260815 / 20260816`
- horizon：30 年
- `chaosIntensity=0`、`climateBias=balanced`、本地规则、无模型决策

机制接受要求：低于 60 的有来源关系不再被候选生成或动作执行硬拒绝；同一合法提议必须同时存在接受与拒绝选项，且改变本人关系、人格、恐惧、照护负担或亲缘风险能够改变排序；没有有效双方协议的动作仍被阻止。候选矩阵不得出现无提议、无接受或无来源的生殖链。

30 年矩阵只用于生殖与早期人口的初步回归；50 / 100 年和终局审计本轮省略，因此不据此作完整代际连续性结论。

## 实现结果

- 删除生殖关系 `60 / 60` 常量，以及提议、接受、活跃窗口和领域动作中的关系分数重验。
- 提议者仍必须拥有一段有真实来源的关系；这只建立候选来源，不替人物决定是否开口。
- 身体适格的回应者同时获得接受与拒绝；有效窗口中的双方同时获得继续与撤回。
- `consent` appraisal 连续读取本人对伴侣的 `trust / bond / fear`、HEXACO 人格、当前照护责任与本人已知的亲缘风险。接受、拒绝和撤回都由同一 BDI 排序。
- 最终生殖原语仍硬性要求准确的有效双方协议、当前年龄与身体条件、无妊娠或产后恢复、近身范围和同一人物对每月最多一次尝试。
- 每条完成的生殖尝试事实新增 `agreementId` 与双方当时的 `relationshipSnapshot`，使旧 60 分以下的自主尝试可以直接审计。

## 自主与来源审计

三条候选历史合计：

- 187 次生殖提议，缺失有来源关系 basis 为 0；
- 126 次完成接受、60 次完成拒绝、3 次主动撤回；
- 266 次完成尝试，缺失同意或关系快照为 0；

- 71 次尝试的关系快照低于旧 `60 / 60`，最低值为 43，证明旧门槛已从权威动作链移除；
- 模型决策为 0，结果完全来自本地规则。

## 裁决与限制

机制假设成立：固定关系线不再替人物拒绝，接受、拒绝和撤回都真实发生；来源、身体和明确双方协议仍保持为不可绕过的边界。候选可作为当前实现保留。

人口只做初步通过：总体出生和末期人口上升，且种子 `185` 的断代被修复；但 `20260816` 出现 5 次幼儿暴露死亡和人口回落。后续若要宣称完整代际连续性，必须再跑 50 / 100 年与终局审计，并把幼儿生态照护作为独立因果问题分析，不能用重新加入生殖关系硬门槛来掩盖。

运行过程中 Node 24 的 V8 在种子 `185` 第 156 月发生一次原生 GC 崩溃；同一隔离 SQLite 从检查点恢复后，以更大堆并关闭 concurrent sweeping 完成全部矩阵。该故障属于运行时稳定性，不是模拟动作失败，已保留恢复路径。
