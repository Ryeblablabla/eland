# BDI 项目满足与家庭准备度实验（2026-08-22）

状态：`status=revise/preliminary`。规则与来源审计已经通过，但最终 V8 的端到端行为没有达到接受标准：三个种子中有两个没有出生，生殖提议均值从基线 `62.33` 降到 `9.67`。当前实现可以作为下一轮候选基础，不能按现有参数直接接受。

## 可证伪假设

旧行为在项目完成后只关闭项目与意图，没有留下“本人观察到某项需要已被缓解”的目标层结果；一次合法但未受孕的生殖动作也可能被当作成功经验。人物虽然会重新规划，却不能可靠地区分“动作执行成功”“项目功能达成”和“当前是否具备建立家庭的条件”。

本轮假设是：如果亲自造成项目最终功能事实的人形成一条有来源的 `needResolutionEpisode`，该 episode 短期缓解同 `need + desiredFunction` 的重复新建压力；同时，人物只从当前可感知的食物、水、真实住所质量、照护余量与环境风险形成 `generativity` need，那么项目的真实产出可以参与后续家庭判断，但项目完工本身不能变成快乐值、繁殖奖励或无条件生育冲动。

预期链为：

```text
局部压力与项目触发事实
→ 本人持续执行项目
→ 本人造成最终功能 ActionFact
→ 有来源的 needResolutionEpisode
→ 同类新建压力短期缓解
→ 当前食水、住所、照护与气候重新评估
→ 条件成立时形成 generativity need
→ 提议 / 接受 / 尝试仍经过本人 BDI 与明确同意
→ 生殖动作结果与妊娠目标结果分别学习
```

这里必须拆成两条并行因果：`episode → 同 need/function 的新项目压力缓解`；项目真实留下的食物、水源或住所功能则由人物再次感知，形成 `当前资源 → readiness → generativity`。episode 只追加 basis / reason / source，不增加 readiness 数值，也不产生物资。

机制接受标准：

- episode 逐条解析到状态中的已完成项目、匹配的 `need/function`、真实完成动作与正确行动者；
- 所有终局 `intent.goalOutcome` 均存在且来源可解析；
- `attempted-unmet` 生殖结果必须有 `conceived=false` 动作，`achieved` 必须有 `conceived=true` 动作；
- 三个种子都应出现项目完成后 12 个月内、由 episode 来源直接进入新生殖意图的案例；
- 不得绕过双向同意、用项目记录替代食物 / 水 / 住所，也不得增加任一配对种子的幼儿暴露死亡。

人口、项目活动、储备与幼儿死亡同时报告，避免把提议数或出生数单独当作成功。

## 实验边界

冻结基线与最终 V8 使用同一矩阵：

- seeds：`185 / 20260815 / 20260816`；
- horizon：30 年，每条运行完成 360 月，无提前终止；
- `chaosIntensity=0`、`climateBias=balanced`、`civilizationNo=1`；
- 每种子 1 次确定性运行；本地规则，模型决策与 token 使用均为 0；
- 按 `seed + years + repeat` 精确配对，配置与文明指数公式一致。

基线代码与 SQLite 来自冻结快照，基线数据库 SHA-256 为 `ccd8c9c837acd2caa38da16a416eff54917da89a92252f220982de6d8ab7025c`。V8 同样冻结数据库与三份后端可执行文件，哈希见文末。

这里只运行了一个 30 年时标、三个种子。它适合发现生殖、重复项目与早期人口回归，不足以证明长期生态稳定或代际连续性；比较器也因此保留“只有一个 horizon”的警告。

## 权威来源审计

V8 三条终态 SQLite 历史由 `project-family-readiness-audit-v2` 只读审计。家庭相关 episode 只接受准备度规则可能使用的五种项目功能：`settled-cultivation`、`reserve-storage`、`reliable-water`、`weather-shelter`、`crop-processing`。

- 20 个人物—运行持有者共有 `114 / 114` 条完整 `NeedResolutionEpisode`，未解析来源与人物 / 项目 / need / function 错配均为 0；
- `13,762 / 13,762` 条 goalOutcome 来源引用可解析，来源错配为 0；
- 所有终局意图都有 goalOutcome；仍活跃的 4 条意图尚未结算，不属于遗漏；
- 生殖 goalOutcome 为 `4 achieved / 16 attempted-unmet / 0 not-evaluated`，审计到的 achieved / attempted-unmet 来源语义错配为 0；20 个历史样本全部来自 seed `20260815`，另两个种子没有可评估样本，V8 也没有覆盖 not-evaluated 历史分支；
- 114 条 episode 中有 35 条属于家庭相关功能；其后 12 个月内只出现 2 次同一人物的生殖决策，来自 1 条 episode，直接携带 episode 来源的决策为 0；
- 三种子的“家庭相关 episode / 窗口内生殖决策 / 直接来源链接”分别为 `7/0/0`、`17/2/0`、`11/0/0`。

因此，V8 证明了 episode、目标后验与终局结算可回放，也证明项目完成没有变成隐藏繁殖奖励；但它没有满足“三个种子都出现端到端项目完成 → 新生殖意图来源链”的接受标准。不能把组件完整误写成行为假设已经成立。

当前审计能够检查部分来源传播，却不能做反事实归因，也没有审计 episode 前后的项目压力或真实资源分量。它把 trigger / outcome / source 的任一交集视为链接，可能把仅有 trigger 的决策算成正例；只归因最近 episode，又可能漏掉较早真实链接；读取的是终态 intent 来源而非决策时的完整 `DecisionFact` 快照。生殖 outcome 审计确认受孕真假来源，但不独立核对动作参与者与意图 owner / partner 的精确对应；这部分及 not-evaluated 分支由定向实现测试覆盖，不应冒充 V8 历史证据。

V8 的选中意图没有持久化决策时五个 readiness 分量和最终激活 need；下一轮若不先补这组只读证据，就无法区分“真实资源一直不足”“可感知范围过窄”与“need 强度 / aspiration 校准过高”。

## 裁决与下一断点

- 规则完整性：通过。episode、动作后验 / 目标后验分层、受孕语义、死亡与休眠终局、中断清理均通过定向测试和终态审计；
- 安全边界：结构上通过；正向生殖不能再由 `belonging` 或通用机会值旁路，记忆住所不提供虚假容量，未知死讯不解除照护责任；
- 行为假设：未通过。项目完成后的端到端家庭路径没有在三个种子复现，生殖和储备同时塌缩；
- 整体候选：`revise`；证据等级：`preliminary`。

下一条可证伪瓶颈不是“关系分不够”，也不是把项目 episode 再接成奖励。应先在决策事实中持久化 `food / water / shelter / care / climate` 五个准备度分量、`generativity` 强度与 aspiration 差值，然后回放 seed `185`、`20260816` 最早未形成正向生殖意图的月份。只有确认某个分量对人物已知的真实余量产生系统性假阴性，才调整该最低层感知或强度映射；关系与人格继续保持门控，不能重新获得激活权。

下一轮至少保留同三种子的 10 / 30 年配对矩阵。接受条件仍包括端到端来源链、逐种子幼儿安全不回退，以及不以出生消失换取表面安全。
