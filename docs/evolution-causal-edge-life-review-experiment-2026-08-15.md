# v11 因果边沿生活复核实验

状态：矩阵完成；只读预览与结构化证据基础设施接受，关系重提整包继续修订。

## v10 最早断点

v10 证明“进展中的项目可以被局部生活机会重新权衡”，但第一次实现混入了三个非预期机制：完整决策上下文预览会写入项目物流；没有交流历史被自动当作 13 个月孤立；同一月发出的生殖提议未阻止本人再次生成相同提议。15 次生活复核只覆盖 8 个不同人物—月份，且多数远程提议放弃了旧项目意图。

## 单一因果假设

生活复核应由一个新的、可保存的机会证据边沿触发，而不是由固定时间阈值触发。人物只在以下条件同时成立时复核：

1. 当前正在推进真实项目；
2. 只读预览得到合法的结伴或生殖提议选项；
3. 关系证据、女性生育窗口分段、目标人物或选项种类相对上次同类复核发生了变化；
4. 生活压力仍高于当前项目压力至少 10；
5. 本人没有向同一对象发出仍未决的同类提议。

本版删除“三个月无正向沟通”孤独代理。孤独只有在未来存在人物可感知、可记忆的孤立 episode 后才重新进入动机；静态归属倾向可以调节压力，但不能单独制造重复边沿。

结构化 `lifeReview` 证据至少保存：规范化选项种类、行动者、对象、关系来源事件、女性年龄窗口分段、项目与项目触发来源、生活压力、项目压力和稳定 `basisKey`。同一 `basisKey` 已经出现在本人的历史意图后，不再复核；新的关系来源或生育窗口分段才允许重新考虑。

只读要求：当预览没有触发复核时，项目、物流事件、意图、协议、记忆和世界事件必须逐字段不变。真正选择生活机会后才允许正常编译项目下一步。

## 预登记矩阵

- 基线：`candidate-grounded-life-review-v10`；同时回看 v9；
- 候选：`candidate-causal-edge-life-review-v11`；
- 种子：`185, 20260815, 20260816`；
- 时长：30 年；规则模式；同配置、同配对键；
- 文明指数只作观察，公式来源不一致时隔离。

主要指标：

- 生活复核总数、唯一人物—月份、同月重复数、唯一 `basisKey` 与重复 basis；
- 生殖提议、接受、尝试、受孕、出生；
- 项目行动人—月、项目完成/阻塞、物流事件及履行；
- 终局人口、死亡和儿童暴露死亡。

接受护栏：

- 同月相同人物重复生活复核必须为 0；
- 同一 `basisKey` 重复必须为 0；
- 无触发预览不得改变任何权威状态；
- 没有未决的重复外发提议；
- 项目完成与物流履行不能因预览本身下降；
- 不以出生或人口单项上升为接受条件；
- 模型调用与 token 保持 0。

## 结果与决定

三个同种子 30 年运行均达到 360 月，模型调用与 token 为 0。聚焦回归证明只读预览不会改写权威状态；完整模拟与项目物流回归通过。

| seed | 生活复核 / 同月重复 / 重复 basis | 提议 / 接受 / 尝试 / 受孕 | 终局人口 / 出生 | 项目完成 / 阻塞 | 物流履行 |
|---:|---:|---:|---:|---:|---:|
| 185 | 0 / 0 / 0 | 13 / 12 / 42 / 7 | 9 / 7 | 41 / 5 | 195 |
| 20260815 | 3 / 0 / 0 | 13 / 11 / 48 / 3 | 4 / 3 | 28 / 3 | 88 |
| 20260816 | 1 / 0 / 0 | 39 / 29 / 136 / 5 | 9 / 5 | 34 / 2 | 78 |

相对 v10，生殖提议三个种子分别减少 `66 / 3 / 37`，受孕反而为 `+2 / +1 / 0`；同月重复从 `5 / 0 / 2` 全部归零。唯一 basis 与复核数严格相等，没有同一证据重复决策。说明“未决提议门槛 + 新关系/年龄窗口边沿”消除了刷提议，却没有靠压低真实受孕换取表面整洁。

项目结果仍有轨迹差异。相对 v9，完成数是 `+7 / -3 / +8`，阻塞是 `-2 / +1 / -4`；没有三种子一致坍塌。物流事件数量明显减少，但完成数在两个种子上升，说明原先一部分物流事件是重复规划周转，不能把事件越多直接解释成生产越好。

决定：接受 v11 的只读预览、结构化 `lifeReview` 和 proposed 状态的外发提议门槛。保留一个零复核种子，因为没有跨越压力边沿本身是合法结果。人口和出生仍然分叉，不把它们作为机制目标。

但关系重提机制尚未闭合，因此不能宣称整个 causal basis 已接受。进一步读取 Agreement 历史后发现：普通规划没有携带 life-review basis，同一 directed pair 在协议过期后仍可重提；seed 20260816 最多出现 6 次同向提议。当前 basis 还混入普通沟通来源，年龄压力在同一年龄段连续增长。v12 必须把白名单 basis 下沉到所有 companion/reproduce Proposal，并用“新增证据集合”而非 key 不同裁决重提。

远程意图连续性仍是真实断点：四次复核中的三次远程生殖提议没有 `projectId`，另一次同地 companion 形成复合 social intent。但按最早未闭合因果链排序，先在 v12 统一关系 Proposal basis，v13 再独立实现 `interrupt → suspend → 原 intent 同 ID 恢复`。
