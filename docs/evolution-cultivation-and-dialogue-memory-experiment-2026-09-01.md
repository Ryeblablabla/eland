# 耕地扩展与规则对话记忆实验（2026-09-01）

状态：v84 已补完 `18 / 185 / 20260817` 的 10、30、50、100 年与自然终止审计。人物行动反转、拒绝后反向重提、关系证据淘汰、休眠履约期限与水源帮助重复动作均通过定向回放和长程守卫；最低层机制接受为当前候选基线。人口与阶段仍保留自然高方差，不以提高出生或观察器阶段作为验收条件。

## 问题与假设

人工审阅发现两个最早断点：

1. 多个定居耕作项目已经真实播种 3～5 格并收获 2 次，却因场址内刚好缺第 6 格既有可种地而阻塞。假设：人物若持有真实生产工具，应能在不读取隐藏规则的前提下逐步尝试草地、裸土和夯土；已有裸土整地经验后，才值得清理灌木或枝叶继续扩田。
2. 30 年历史中，同一说话者会在 7 个月后向同一听者原样复述同一来源。假设：根因不是需要永久冷却，而是规则对话只进入 24 条旧人物记忆 / 关系来源，没有进入统一 Agent 记忆。把真实 grounded conversation basis 写入双方有界 dialogue memory，应在人物仍记得时消除原样重复，记忆自然淘汰后仍允许重谈。

禁止通过文明阶段、观察器指标、固定种子、项目 ID、固定月份禁令或模型调用修复。

## 实现

- `interaction-rules.ts` 增加田间工具对草地、裸土和夯土的普通物质作用；草地先变裸土，裸土 / 夯土再成为可播种的贫瘠土。
- `steps/cultivation.ts` 只从本人可见、可达地表和本人持有工具编译动作。未知工具仍按精确 target 记录 response / no-response；灌木 / 枝叶清理只有在人物已经有来源地掌握“当前工具可整理裸土”后才出现。
- 规则演化中完成的 grounded conversation 给双方各写一个受 48 条个人容量、模糊和遗忘约束的 compact dialogue basis。它不扩张 `Relation.sourceEventIds`，也不新增按月禁止规则。

## v57–v70：100 年、终止与人物真实性闭环

### 预登记假设

长程历史的最早断点不在文明阶段，而在连续行动与有来源社会记忆：

1. 动作把健康降到 0 后，月末只遍历 `livingPeople`，会留下没有死亡事实、遗体和遗产结算的零生命人物；
2. 住所、野兽和幼儿照护只保存单步动作，目标跨一格感知边界或警戒半径后就恢复旧意图，产生同月往返；
3. 关系只保留最近 24 条来源，频繁预言校验或普通共同活动可挤掉早期直接照护、履约和跨月证据；
4. 脱水休眠者仅因进入恒纪元就在没有可执行补水来源时恢复清醒代谢；同一休眠 episode 又可被多名见证者拆成多份救援项目。

接受标准不是“更多出生”或“阶段提高”，而是：死亡结算原子化；保护性 episode 能连续到危险消失；关系关键来由不被普通新来源覆盖且不成为对话黑名单；休眠恢复由真实水源或协作救援支撑；等价救援只保留一个项目并记录真实贡献者。三种子保留灭绝、低出生与失败样本，模型调用必须为 0。

### 最低层修复与共同检查点

- 动作致死：月末结算遍历尚未写入死亡事实的人，而资源竞争仍只计算真实存活者。seed 20260817 第 576→588 月重放把第 582 月受击至 0 健康的人在同月结算成一次死亡、遗体和遗产，重复结算不产生第二次死亡。
- 保护性意图：生存与照护在没有父项目时也建立一个有来源的根 episode；单步完成不等于整个危险完成。已选择的幼儿目标可在 episode 中跨过当前感知边界，住所离开只在存在真实求生动作时开放。
- 野兽：进入住所后维持到当月结束；有路线的逃离继续跟踪同一只仍可见动物，但 `hold` 没有可继续的路线，完成后下一 tick 必须重新满足当前警戒半径或追击事实，不能靠旧动物 ID 永久垄断行动。
- 关系：最近 24 条仍供近期情境与自然遗忘；另外按自然月保留最多 4 条真实双方互动、2 条直接照护 / 实质回应 / 履约和 2 条共同生活锚点。正式关系读两层并集，生活对话原样去重只读近期来源与 Agent dialogue basis。

### v74–v83：关系决定连续性、被动搬运与长程成本

v73 之后的长跑说明“最近 24 条来源”只是部分根因。它确实会让早期照护、回应和履约被预言校验等高频来源挤出，但不能解释同月拒绝后立刻反向提议：那类样本中双方仍各自持有 15 / 16 条相关来源。继续按话题加禁止只会隐藏矛盾，因此本轮假设是：关系需要一层有界的语义账本保存关键来由和本人决定；旧边界应被时间与后续真实互动连续修正，而不是靠话题白名单、固定冷却或删除候选。

最终实现保留每条关系最近 24 条热来源，同时把 decision boundary 分为 `companion / reproduce × self / other` 四个语义槽位。同月本人拒绝、对方拒绝或两类正式关系决定不会互相覆盖。拒绝成本仍是排序中的软偏好；后续可回放的履约 / 出生、照护、非沟通支持、grounded response 与 opening 依因果强度提供连续 renewal，同月证据只取较弱权重，总强度有界。它们都不能改变关系分、解锁能力或删除合法候选。曾尝试过按“新话题”直接重开提议的实现，因属于语义白名单而撤回。

### v84：水源帮助必须形成双方可执行的路线
