# v33 先民熟悉度与独立生殖尝试实验

状态：用户要求的机会机制接受；整体人口与文明平衡待后续修订。

## 决定

接受三条窄机制：先民共同抵达的可追溯熟悉度、`4/4` 生殖关系门槛、按动作事件 id 独立采样的多次生殖尝试。单次基础受孕概率仍是 `0.18 × min(健康, 营养, 水分) / 100`，没有通过直接抬概率或脚本出生达成结果。

同种子 `3×10y` 中，出生中位数从 `2→4`，接受从 `4→8`，真实尝试从 `20→26`；原先 0 接受、0 尝试、0 出生的 seed 20260816 变为 `3 / 17 / 2`。三种子都有接受、尝试和出生，最终人口最大 13，低于开局人口的 3 倍。

`3×20y` 中，出生中位数从 `5→9`、接受 `8→16`、尝试 `37→75`，证明“难以进入受孕机会”的瓶颈已经解除。但儿童死亡中位数从 `0→3`，最终人口中位数反而从 `11→8`；总项目完成中位数 `13→9`，文明指数 `52.53→46.15`。生产项目中位数由 `1→3`，因此不是生产链整体消失，而是新增人口带来的照护和暴露压力改变了历史分配。

六组 10/20 年历史中，每条完成的生殖动作都有采样键：分别为 `30/26/17` 与 `75/76/38` 条，组内唯一数与动作数完全相等，缺键为 0。所有后代关系中的共同抵达来源泄漏为 0。

因此 v33 不扩展 30 年，也不继续提高受孕概率。下一最早断点已经从生殖机会转为婴幼儿暴露、住所容量与依赖照护承载；这应作为独立机制迭代，不能在本轮暗改儿童存活率来美化人口结果。

## 观察到的最早断点

v32 的同种子 `3×10y` 历史中，seed 185 有 22 次生殖动作、seed 20260815 有 20 次，但同一对人物在同一月的重复动作复用 `reproduce:<month>:<female>:<male>` 这一随机键。因此一个月内无论真实尝试多少次，样本都完全相同，多次尝试没有增加受孕机会。seed 20260816 则出现 3 次生殖提议、0 次接受、0 次尝试；当前生殖关系门槛为有来源的单向 `trust>=6 && bond>=6`，开局先民之间又全部从 0 开始。

这说明当前困难同时来自两个可分离但落在同一生命周期上的机会瓶颈：先民需要从陌生人开始跨过较高关系门槛；跨过后，同月重复的真实生殖行动仍被折叠成一次概率试验。

## 单一因果假设

若共同抵达的开局先民获得一条可追溯的相互熟悉事实与中等正向关系，生殖关系最低门槛从 `6/6` 小幅降到 `4/4`，且每个已执行的生殖动作按其事件 id 使用独立、可重放的确定性样本，那么：

```text
先民共同抵达事实
→ 双向初始熟悉关系
→ 更早出现合格提议与回应
→ 有效同意期内的多次真实尝试
→ 每次尝试增加累计受孕机会
→ 妊娠与出生仍由身体状态和时间自然结算
```

新生儿不继承“共同抵达”加成；其与父母仍可由真实出生事实形成既有的亲缘 bond，其余关系从 `0/0/0` 开始，再通过后续共同经历变化。

## 候选规则

- 为开局先民群体生成一条月 0 的“先民共同抵达”环境事实，参与者明确列出全部先民；该事实是关系分数的共同来源，也能被每一对关系因果基础解析，且不会伪装成多次玩家动作。
- 开局先民对其他先民的有向关系设为 `trust=6, bond=6, fear=0`，来源仅指向这条共同抵达事实。
- 生殖提议最低关系门槛改为有合格来源的 `trust>=4 && bond>=4`；同意、年龄、同地、身体阈值和妊娠排他规则不变。
- 受孕基础概率公式不变；随机键加入当前动作 `eventId`。每个真实完成的动作获得不同的确定性样本，重放同一历史仍得到同一结果。
- 新生儿不获得共同抵达来源；父母关系仍由出生事实形成亲缘 bond，非父母关系保持零分。

## 守卫与验收

- 定向测试必须证明：先民双向关系为 `6/6` 且来源能解析为月 0 共同抵达事实；新生儿没有该来源，非父母关系也没有该加成。
- `4/4` 且有真实共同经历可提议，低于任一门槛或缺少来源仍不可提议。
- 同月同伴的两个不同生殖事件必须产生不同采样键；样本按事件 id 可重复计算，且基础 chance 公式不变。
- 先跑 v32 与候选的同种子 `3×10y` 配对矩阵：seeds `185,20260815,20260816`、chaos 0、规则规划器。至少 2 个种子出现接受和真实尝试，出生中位数不低于 v32 的 2；不得出现无同意受孕、儿童自动获得先民关系或 10 年人口超过开局 3 倍。
- 10 年通过后扩展同 seeds 的 `3×20y`。20 年候选与同版本基线比较时，不能因人口增长让全种子文明指数或可追溯生产系统性退化；不得出现人口爆炸或出生链停摆。
- 若接受率改善但出生仍高度离散，保留机会规则，不继续提高基础受孕概率；下一轮单独诊断同意期长度、动作优先级和婴幼儿存活。
