# 创世原型人格与经历叠层实验（2026-09-01）

状态：机制级接受，群体平衡结论为 `preliminary / revise`。本轮完成三种子 10 年配对；没有运行 20/30 年，因此不能据此判断跨代社会与人口长期分布。

关联：[规则优先人物架构](./rule-first-agent-architecture-v1.md) · [演化迭代协议](./evolution-iteration-loop-v1.md)

## 假设

若人物原型档案先通过通用语义信号形成有界创世人格中心，再与种子个体差异混合，并把三个合成反应范式作为只读 Character Card；同时让带来源人格变化和当前可召回记忆形成独立 experience layer，那么：

```text
原型档案 → 创世 disposition prior → 本地选择 / 稳定 Soul
真实行动与关系后果 → 有来源人格变化 / 多 lane 记忆
→ 动态注意、召回与表达
```

人物应在创世时更符合原型方向，经历又能改变当下注意与表达而不抹掉稳定核心。原型、模型和提示词均不得授予能力、旧事、关系、知识、行动或结果；后代仍只从父母人格与自身经历形成。

## 实现与机制验收

- `founder-persona.ts` 从档案性格摘要编译 HEXACO、控制 / 地位中心和三个结构化反应范式；反应范式只描述 cue、attention、response tendency 与 speech tendency，不含原作引文。
- 创世人格以 76% 档案中心和 24% 种子样本混合；后代继续调用原有父母人格继承函数，不读取原型档案。
- Soul 升为 v3：baseline、稳定动机和原型反应范式构成稳定核心；`learnedDelta` 不改写 Soul。
- `adaptive-personality-v1` 只显示能解析到 `PersonalityChange.sourceEventIds` 的变化；`person-experience-layer-v1` 只从当前召回的负面高显著记忆、未完责任、对象一致亲近和成功程序记忆派生动态 cue。
- 记忆排序仍以人物、主题、basis、显著度、置信度和新近性为主，有效人格只增加 `±18` 以内的注意偏置。compact 模型请求把记忆引用换成 request-scoped handle，只发送来源数量，不暴露稳定记忆 / 事件 ID。
- 定向测试覆盖全部档案均有三个范式、代表原型先验方向、不同种子仍有差异、后代继承边界、Soul 稳定、动态变化来源、四类 experience cue 和人格变化后的召回顺位。

三组基线与候选都完成 120 月，灭绝、死亡与儿童死亡均为 0。终局人口中位数保持 10，项目完成中位数从 36 增至 42，移动占比下降；但关系 / 生殖提议和共同项目 / 功能制度下降，且种子间方向不一致：

- seed `185`：人口 `7→8`、出生 `0→1`、完成项目 `16→20`、共同项目 `8→10`、制度 `1→3`；
- seed `20260815`：人口 `13→10`、出生 `3→0`、关系提议 `59→16`、共同项目 `15→7`、制度 `7→4`；
- seed `20260816`：人口 `10→11`、出生 `0→1`、完成项目 `36→43`，但共同项目 `12→8`、制度 `8→5`。

这说明创世人格先验已经真实进入本地行为，而不是只改变模型文案；同时也说明档案语料的整体性格分布会改变群体社会节律，不能把“更贴原型”自动解释为所有文明指标都应上升。

## 决定

机制级 `accept`：三个用户要求都有直接测试与源码边界支持；原型只影响创世先验和风格，后代继承不变，经历通过来源事实改变召回、注意和表达，模型缺席时规则世界完整运行。

候选包的长期群体结论为 `preliminary / revise`：三种子 10 年没有生存或人口中位数回归，但关系 / 生殖提议、共同项目和制度明显下降。因为本轮目标是人物可辨识度而不是提升社会指标，这些变化不能直接判为失败；也不能在缺少 20/30 年配对和逐人物行为审阅时宣称无回归。

下一项可证伪瓶颈：档案语义编译出的群体先验是否系统性压低社会接近，还是只让不同原型产生合理分化。下一轮应冻结当前编译器，使用同一 `3–5 seeds × 10/20/30 years`，同时按创世人物报告“档案目标方向命中率、主动社交 / 拒绝 / 承诺 / 探究的逐人分布”和代表性历史；若低外向 / 高尽责信号在多数档案上形成语料偏置，再调整信号归一化，而不是按人物或种子特判。
