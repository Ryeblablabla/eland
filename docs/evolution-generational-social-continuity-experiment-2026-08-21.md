# 代际社会连续性实验（2026-08-21）

状态：已完成。V5f 权威连续运行已产生首名第五代人物；V6/V6b 家庭共居候选因重复记账和纵向世代回归被拒绝。

## 目标与已知断点

初始目标不是按脚本增加人口，而是让权威规则历史至少真实产生一名 `generation >= 3` 的人物；长程验证随后扩展到 `generation >= 5`。每一代都必须经过可回放的关系形成、提议、明确同意、生殖动作、受孕和出生事实。

已审计的 `seed=20260821` 终局运行只包含 `generation 0` 的 6 名先民和 `generation 1` 的 8 名后代。第一代女性成年后没有生殖提议。最早断点不是人口承载或受孕概率，而是新生人物从低关系起步后，缺少一条主动且有来源的关系培养链；短期结伴又不能沉淀为持续共同生活结构。

## 可证伪假设

若人物能从本人可感知、有来源的积极关系或孤立事实形成归属需要，通过可拒绝的 `company` 请求建立短期陪伴，并在真实共同生活履约后形成可持续、可撤回的共同生活关系，那么无近亲的一代人物应能在女性 45 岁前积累双向信任与亲近，进入现有生殖同意链，并使部分长程历史继续到 `generation >= 3`。

预期链：

```text
局部关系或孤立事实
→ 有来源的 belonging need
→ 可见对象的 company 请求
→ 明确接受
→ 固定生活锚点内的真实共同活动与履约
→ 持续共同生活及关系证据
→ 双向 trust / bond >= 60
→ 生殖提议、接受、真实动作、受孕
→ generation 2 出生
→ 同一规则再次闭环
→ generation 3 出生
```

## 候选边界

- 保持女性 16–45 岁、男性 16 岁以上、双方身体最低 55、双向关系 60、生殖同意窗口和受孕概率不变。
- 不给后代复制先民初始关系，不按人物、种子、运行 ID 或期望代数添加特判。
- 不读取文明指数、全局人口或隐藏人物位置。
- 普通陪伴只向当前可见人物提出；跨地返回只使用双方已经同意的固定生活锚点，不追踪伴侣实时坐标。
- 关系增长只来自已提交的共同生活、履约、共同劳动、照护或有来源对话事实；同处、空闲或指标增长不能直接加分。
- 所有提议可拒绝，已生效的共同生活可明确撤回；关系跌破生殖门槛时既有生殖协议仍按当前领域规则失效。

## 基线与矩阵

基线使用候选修改前隔离的编译后端，监听独立端口，不受开发热重载影响。权威运行仍写入同一 SQLite，但使用唯一前缀：

- prefix：`baseline-gen3-social-v0-20260821`
- seeds：`185 / 20260815 / 20260821`
- horizons：`10 / 30 / 50 / 100 / 1000` 年；1000 年为终局审计上限
- `chaosIntensity=0`、`climateBias=balanced`、本地规则、无模型决策
- artifact：`three-body/data/experiments/baseline-gen3-social-v0-20260821.json`

候选使用完全相同的种子、时长与配置，另用唯一前缀保存。确定性重跑只验证回放，不计为独立样本。

## 接受、修订与拒绝标准

最低能力证明：至少一条候选权威历史出现 `generation >= 3` 的出生人物，且可逐事件回放两次跨代关系—同意—受孕—出生链。

整体候选接受还要求：

- 三个终局审计中至少两个出现 `generation >= 2`，至少一个出现 `generation >= 3`；
- 生殖提议、接受和动作都具有可解析的关系与协议来源，没有无同意出生；
- company 与持续共同生活确实履约，不以重复聊天或空闲同处冒充关系培养；
- 30/50 年移动占比中位数不高于配对基线 5 个百分点，不出现追踪移动振荡；
- 30/50 年人口、死亡、幼童死亡、生产项目和功能制度没有未解释的明显退化；
- 模型调用与 token 仍为零，文明指数只作观察。

若短期陪伴发生但没有持续共同生活，分类为协调/状态沉淀失败并继续修订；若持续关系达标但身体或年龄窗口错开，则下一轮只修最早的身体—生活连续性断点。若行为主要变成追人、刷协议或强制接受，即使出现第三代也拒绝。

## 权威审计

`three-body/scripts/audit-run-generations.mjs` 从 SQLite 的状态根与 shell 直接读取每条运行的代际分布、最早出生和 `generation >= 3` 人物，不使用前端或文明观察器推断。

## 最终结果

V5f 连续运行 `candidate-gen5-social-v5f-cont-20260821-s20260815-m948-y200-r1` 在权威检查点 `m1752 / revision 68` 冻结，状态根为 `5ab9efe213f577be92bf966b8d9d7c12d9c0ac8a8f305819120040e88f4b2451`。首名第五代人物克拉拉·阿姆斯特朗于 m1750 出生，父母诸葛芷若与诺亚·阿姆斯特朗均为第四代。冻结时世代累计为 `g0=7 / g1=19 / g2=24 / g3=22 / g4=17 / g5=1`。

这条链没有修改年龄、身体、关系、人口容量或受孕概率门槛：

```text
m1496 / m1501 company 履约
→ m1502 companion 提议与接受
→ m1527 累计 12 个真实共同生活月并建立关系
→ m1552..m1735 persistent shared-living 事实
→ 双向 trust / bond >= 60
→ m1737 reproduce 提议
→ m1738 接受
→ m1738..m1740 三次合法尝试未孕
→ m1741 第四次尝试受孕，due=m1750
→ m1750 generation 5 出生
```

完整审计覆盖所有 `generation >= 2` 人物，核心出生链与社会来源链均为 `64 / 64` 完整，缺失来源为 0。首名第五代的紧凑审计解析了 68 个唯一引用，全部存在。受孕动作记录 `chance=0.22022`、`sample=0.174471`；出生记录 `parentalKinshipRisk=0.9`、`geneticLoad=0.74628125`、`inheritedHealth=64`。父母共享母亲，因此这是高亲缘风险案例；规则把风险作为可学习的选择成本和后代遗传负荷，而不是动作禁令，不能把“到达第五代”误写成亲缘安全已经解决。

新生儿弱初始信任作为独立单变量在 V4f→V5f 三种子 m360 配对中验证：47/47 次出生写入，实际值 `5..7`、均值 `5.957`；160 个目标中 63 个为非亲缘人物。它提高了 company 层的有源接触面，但多数非亲缘边仍保持单向，尚未稳定提高 companion establishment 或 persistent shared living。因此长程第五代结果证明整条规则链可达，不能单独归因于新生信任。

V6/V6b 曾尝试把亲生子女纳入父母已建立 companion 的家庭共居证据。V6 因跨协议重复消费同一共居月份而拒绝；V6b 修复重复后，m1320 的 household facts `2151 / 2151` 合法，但低代新增出生先把存活人口推过软容量线，使含第三代的关系在跨过 60 前失去生殖窗口，而配对 V5 已产生 3 名第四代。该候选因纵向世代回归冻结，不合入当前规则。
