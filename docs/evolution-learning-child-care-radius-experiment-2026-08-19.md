# 学习期儿童照护半径实验（2026-08-19）

状态：已完成；v3 单独未过暴露死亡门槛，进入 v5 组合包。

## 历史断点

有界生殖窗口 v2 已满足协议实体绑定和同一对人物每月一次的合法性，但整体候选拒绝：相对已接受基线，30 年灭绝率仍为 `33.33%`，儿童冷热暴露死亡集合从 `0` 增至 `2`，移动动作占比中位数从 `52.45%` 增至 `69.44%`。

seed `20260815` 的唯一后代孙安歌在第 62 月出生，第 87 月（约 2 岁）开始连续选择普通 `collect` 意图拾取石料：在照护者仍位于约 `(22,17)` 时，孩子沿 `(25,16) → (28,15) → (31,16) → (33,14) → (34,12) → (37,11)` 的可见掉落物逐月漂移。每一个局部目标都在孩子当时视野内，但组合后离开了亲代视野。第 98 月起缺水触发生存搜索，第 114 月在热浪中因脱水与暴露死亡。

这不是亲代远程感知缺失：一旦孩子已经离开双方视野，禁止亲代读取其身体是正确边界。最早断点位于年龄规划：`1–11` 岁虽然只允许简单劳动，却没有“普通劳动保持在当前可见照护者附近”的空间约束，局部合法拾取可以累积成无照护远行。

## 假设

若学习期儿童的普通移动候选只能落在当前可见亲生照护者周围、且已经存在的普通移动意图一旦将离开该本地照护半径就被放弃，那么：

```text
孩子看见亲代与附近简单任务
→ 只选择仍处在亲代本地照护半径内的目标
→ 局部拾取、采收、观察和跟随仍可发生
→ 普通任务不能逐月滚动成跨地图迁移
→ 急性生存反射仍可独立寻找眼前水食（不被观察器或远端亲代控制）
→ 亲代继续能以真实视野感知并提供照护
```

## 边界

- 不同步移动、不把满 1 岁儿童隐式携带到亲代位置；
- 不读取视野外亲代或孩子位置；没有可见亲代时，仅禁止新的普通远行，不禁止原地动作与急性生存反射；
- 不限制青少年和成人，不改变水、食物、气候、寿命、生育概率或时代门槛；
- 照护半径只使用孩子当前感知半径和当前可见亲生父母；
- 已有普通意图若下一步越出照护半径，以可审计的放弃结束，不伪造完成或失败。

## 实验

- 机制基线：`three-body/data/experiments/candidate-bounded-reproduction-window-v2.json`；
- 整包权威基线：`three-body/data/experiments/candidate-visible-dependent-rescue-v2.json`；
- seeds `185 / 20260815 / 20260816`，horizons `10 / 20 / 30` 年；
- 配置继续为 `chaosIntensity=0`、`climateBias=balanced`、纯本地规则。

验收：

- 定向回归证明孩子可在亲代半径内拾取，但不能选择或继续执行半径外普通移动；没有可见亲代时普通移动停止，急性生存规则不受此过滤器影响；
- 相对 v2，30 年儿童暴露死亡集合下降，移动动作占比至少 `2 / 3` 个配对种子不增加；
- 相对整包权威基线，30 年灭绝率不高于 `33.33%`、儿童暴露死亡集合不高于 `0`、移动占比中位数最多增加 2 个百分点、项目完成中位数至少保留 `85%`；
- 若儿童只是停止移动却仍在无人照护处死亡，说明缺少的是可回放的最后目击位置或家庭会合协议，本机制必须继续修订，不能改成远程跟随。

## v3 结果与决定

v3 把 30 年灭绝率从 `33.33%` 降为 `0%`，移动占比中位数从基线 `52.45%` 降为 `42.77%`，项目完成中位数从 `12` 升为 `21`；但幼童暴露死亡总数仍为 `2`，只是从 seed 20260815 转移到 seed 185，因此未通过本实验“暴露死亡必须下降”的独立门槛。

真实历史确认了预注册的失败分支：普通任务不再逐格漂移后，低储备幼童仍会启动独立找水生存反射并与亲代分离。照护半径因此没有单独宣告成功，而是进入下一项“危机时可见亲代会合”实验。最终 v5 组合包通过整体门槛；当前只把 v3 视为该组合中的必要约束候选，不声称它单独消除了幼童死亡。
