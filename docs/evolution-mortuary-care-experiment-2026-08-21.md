# 死亡感知、悲恸与遗体照料实验（2026-08-21）

状态：有条件接受。机制闭合与自然发生已通过；总体人口和项目护栏不作干净因果归因。

## 可证伪假设

当前人类死亡只留下死亡事实和地面背包掉落物，死者仍停留在人物投影中，但活人的局部决策上下文没有可感知、可搬运、可安葬的遗体对象。因此最早断点位于：

```text
死亡压力 → 遗体感知
```

若死亡结算生成一个带死亡事件来源的真实人类遗体，只有当前能看见遗体或后来通过有源交谈获知死讯的人才形成死亡记忆，并由亲缘、羁绊、人格和当前生存压力派生悲恸与遗体照料需要；同时遗体的搬运和安葬必须经过近身、移动、挖掘、放置和覆土等合法物理动作，那么：

- 局部可感知且有关系的死亡会在部分可行历史中产生遗体照料与真实安葬；
- 看不见、未被告知的人不会凭空悲伤或前往遗体位置；
- 没有材料、路径、时间或安全余量时，人物可以放弃、失败或让遗体继续暴露；
- 墓碑和纪念只能建立在已经发生的安葬、真实材料与记录行动之上，不能由表现层自动生成；
- 新增照料劳动不会通过强制行为显著恶化生存、项目完成或移动收敛。

## 预期因果链

```text
人物死亡
→ 生成唯一遗体与带死者来源的遗物
→ 活人局部看见遗体 / 通过有源死讯交谈得知
→ 保存死亡记忆并形成有来源的 grief
→ NeedAgenda 派生遗体照料需要
→ 选择收拢遗物、接近或搬运遗体
→ 在可达地面真实挖掘、放置遗体并覆土
→ 遗体进入 interred，墓葬事实闭合
→ 有材料与记录能力时可另建纪念标记
→ 重复行为由观察器报告为实践；不反向奖励人物
```

## 实现边界

- 人类遗体不是普通 `Material`，不能被普通生产、食用或狩猎规则消费。
- 不从全局 `state.people` 向所有亲属广播死亡；死讯必须来自可见遗体、亲眼目击或真实沟通。
- 悲恸只调节已经合法的候选，不绕过急性生存、路径、年龄、材料和动作校验。
- 安葬是人物意图与原子行动闭环；单次安葬不自动建立制度。
- 遗物保持物理谱系，普通拾取与有源“为死者收拢”在事件语义上分开。
- 装饰层只读取权威遗体、墓葬和纪念标记，不写回规则状态。

## 基线与矩阵

- 模型策略：后台本地规则，不调用模型。
- 种子：`185, 20260815, 20260816`。
- 重复：确定性规则每个 `seed + years` 一次。
- 预注册矩阵原为 `10 / 30 / 50 / 100 / 1000` 年；实际主矩阵在得出死亡与照料样本后收敛为 `10 / 30 / 50` 年，避免让一次普通规则改动承担超长实验。
- 基线前缀：`baseline-mortuary-care-v1-20260821`。
- 候选前缀：`candidate-mortuary-care-v1-20260821`。
- 基线与候选保持相同文明配置、气候配置、种子和时长。

## 主要指标

- 死亡数、生成遗体数、遗体唯一性违规数；
- 有资格感知死亡的人物数、死亡记忆数、无来源悲恸数；
- 收拢遗物、抬起、搬运、放下、挖墓、安葬与纪念标记事件数；
- 从死亡到首次照料、从死亡到安葬的月份；
- 暴露、被携带、已安葬遗体的终局数量；
- 安葬 episode 中的死亡事件、遗体、行动者、格位和动作来源闭合率；
- 重复安葬的参与者、月份跨度和墓葬实践观察。

## 护栏

- 人口、出生、死亡、灭绝率与终局存活人口；
- 移动动作占比及代表性目标反转；
- 项目提出、完成、放弃与主要生产链；
- 急性生存、照护、履约和项目父意图不被悲恸无条件压过；
- 没有隐藏远程感知、传送遗体、无挖掘覆土的假安葬、无材料墓碑；
- 文明指数和能力观察不得进入人物候选或评分。

## 决策门槛

接受机制需要同时满足：

1. 定向历史证明死亡、局部感知、记忆、需要、合法动作和墓葬后果来源闭合；
2. `100%` 人类死亡最多对应一个权威遗体，安葬最多闭合一次；
3. 不可感知且未听闻死讯的人物的无来源悲恸为 `0`；
4. 至少一个自然样本出现真实遗体照料或安葬；若完整矩阵没有满足局部条件的死亡，则只接受底层合法性机制，不宣称行为发生率改善；
5. 三个配对种子的灭绝与幼童死亡不出现一致性恶化，移动和项目回归必须能由真实照料成本解释且不形成循环追逐；
6. 墓碑只在安葬、材料消耗与记录来源同时成立时出现。

若遗体可感知但人物始终不形成照料需要，下一最早断点是动机；若有需要却无法完成物理链，下一最早断点是动作可供性或计划编译。不得用提高固定概率掩盖这些断点。

## 实验结果与决定

实际完成 `3 seeds × 10/30/50 years` 的九组配对运行，配置完全匹配且无灭绝。候选使用从冻结基线 source map 恢复的源码，仅覆盖殡葬机制涉及的 18 个运行时源文件，避免混入工作区同时进行的其他规则改动。

候选九个样本合计观察到：

- `34` 次死亡生成 `34` 具唯一遗体；遗体重复、缺失和孤儿来源均为 `0`；
- `228` 条死亡记忆，其中亲见 `210`、由有源死讯交谈获知 `18`，无来源悲恸为 `0`；
- `71` 次带死者语义的遗物收拢、`18` 次哀悼、`10` 次抬起遗体；
- `7` 次挖墓、放置、覆土完整闭合的安葬，安葬来源违规为 `0`；
- `8` 次殡葬动作被合法条件阻断，未发现不可达遗体触发远程动作；
- 自然样本没有产生墓碑；定向历史证明墓碑必须同时引用死亡、安葬和消耗的 `WoodTablet`，因此只接受“可以立碑”的合法机制，不宣称自然发生率。

代表性历史来自 `seed=185, 30 years`：Persephone 的死亡事件 `e-272-environment-death-13` 留下遗体，Socrates 在第 `291` 月依次完成挖墓 `e-291-action-socrates-42`、放置 `e-291-action-socrates-44` 与覆土安葬 `e-291-action-socrates-45`。

50 年终局三个候选样本共有 `19` 次死亡、`5` 次安葬、`8` 具遗体得到至少一次照料。其余遗体仍可暴露，说明照料没有被写成强制剧情。

总体护栏不能作为干净的殡葬因果结论：候选在尚无殡葬动作的 10 年样本中已经与基线发生分支差异；且冻结基线数据库重启后出现状态尾事件语义哈希不一致，导出时只保留了逐块 SHA-256 与历史长度校验。50 年均值上候选终局人口为 `13`（基线 `17`）、死亡为 `6.33`（基线 `5`）、项目完成为 `69.33`（基线 `92`），但三个种子的方向并不一致。因此本轮接受底层事实、感知、行动和观察器机制，保留这些总体差异为后续独立回放问题，不把它们归因于悲恸劳动。
