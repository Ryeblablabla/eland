# 实体记录的独立复现 v1（预登记）

状态：实现前预登记；尚无候选长程结论。

## 可证伪假设

当前人物已经可靠掌握一项技术（`confidence >= 55`）后，即使本人持有或看见异人留下的实体记录、正在推进会真实使用同一技术的项目，也会被 record-use 候选、重编译和 knowledge goal 三处提前过滤。因此实体记录只能帮助低置信读者首次学习，不能促成来源独立的复现、反证或标准化。

若在现有 demand-bound record-use 上增加 `replicate` purpose：只允许存活读者围绕本人 active project、异人实体记录和精确 canonical technique 形成一次来源绑定的复现实验，并继续通过普通物流与物质动作真实取得、消耗输入，那么权威历史应能产生可失败的独立复现 receipt，而不读取文明时代、现代 gate 或隐藏配方。

## 最低通用机制

- `learn` 保留现有低置信阅读与实验语义；`replicate` 不降低已有可靠知识置信度。
- `replicate` 必须绑定 `reader + project/renewal basis + record/version + rule signature`，更换载体不能重复刷同一实验。
- goal 必须是来源绑定的实验 receipt，不能复用已经满足的 `knowledge >= 55`。
- 候选仍只读取本人背包或当前可见的实体记录、本人 active project 和本人已知技术。
- 实验继续使用现有 `combine / exert / expose` 领域动作；输入、数量、lineage、真实输出和状态进入权威事实。材料失效、动作失败或输出不符不得生成成功 receipt，并须留下可追溯负结果。
- observer 在权威 receipt 自然出现前不修改；文明指标与 gate 不进入人物 planner。

## 最小验收

1. 可靠读者、异人实体记录、匹配 active project 与真实材料形成一个 `replicate` option；取得、阅读、备料和实验仍按普通步骤执行。
2. 阅读后技术置信度不下降；成功实验真实消耗输入、产生预期输出并只写一条来源绑定 receipt，同 basis 不再生成。
3. 无 active project、自写记录、技术不匹配、输入失效、输出不符和已有 receipt 均不能伪造成功。
4. 现有 `<55` learn 路径、通用物理合法性和无模型运行保持成立。
5. 定向机制通过后，候选才进入相同种子的 `10/30/50/100 年 + terminal` 配对；终局或现代证据才支持整包接受。
