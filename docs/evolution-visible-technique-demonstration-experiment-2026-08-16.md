# v31 可见范围技术请求与示范实验

状态：可见请求—物理示范机制接受；整体学习链继续修订。

## 决定

3×10 年请求 `15 / 11 / 11`，unique project/teacher `34 / 17 / 29`，重复为 0；seed 20260816 自然形成 1 次真实示范与 1 个 sourced tentative basis，距离、受众、可靠性、function、operation、response、source 和 order 守卫均为 0。生产项目完成 `0 / 1 / 3`，中位数 1，达到继续门槛。

但 imitation 为 0。代表历史 `project-53-washington-food-preparation` 在第 59 月获得生火示范后，学习者因缺 Fiber 立即回到旧 hypothesis（制作长矛）；第 77 月才沿普通探究生火并核验，造成 `reliableWithoutOwnImitation=1`。接受可见请求和远端本地物质示范这一窄机制；因可靠化绕过示范绑定，停止 30 年并修订整体候选。

## v30 后的最早断点

v30 的同地广播请求在两个种子发生，但实际到达者在请求当月都没有匹配可靠技术；世界中同时存在匹配持有人，只是未与请求者站在完全相同体素。完全同体素是沟通/观察契约过窄，而不是缺少需要、项目或知识。

## 单一因果假设

若 active inquiry 可向本人当前可见范围内的人发出手势/呼喊请求，收到请求的可靠持有人可以在双方仍处于学习者可见范围时，用自己的当前实体和本地 target 执行权威操作，那么物理示范无需强迫两人占据同一体素，也不需要跨地图追逐。学习者仍只获得暂定知识，必须以自己的实体模仿后才可靠化。

```text
active inquiry
→ 当前 visible people 的 project-bound gesture request
→ executor 只记录真实处于感知半径内的 reached teacherIds
→ 匹配可靠持有人仍在学习者感知范围内
→ 教师本地真实材料操作与 response
→ v28 tentative → own imitation → reliable
```

## 守卫与矩阵

- 请求与示范距离不得超过学习者当前感知半径，垂直差不得超过 2；超范围不得记录请求或 demonstration basis。
- 不创建移动追逐、会合传送、材料赠送或远程物质作用；教师操作仍只作用于自身可触及 target。
- 多受众 project/teacher 对、示范受众成员、function、可靠性、operation、response、source、order、imitation exact-source 守卫均为 0。
- 定向测试增加“相邻但不同体素可观察成功”与“移出可见范围后不可示范”。
- 以 v30 重投影矩阵为直接基线，跑相同 seeds 的 `3×10y`。至少 2 个种子有请求、至少 1 个种子有真实示范且生产中位数不低于 1 才进入 30 年；若示范出现但模仿为 0，下一断点定位为学习者材料/项目连续性。
