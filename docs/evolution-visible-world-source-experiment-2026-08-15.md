# v19 可见世界物料来源实验

状态：机制接受。

## v18 最早断点

v18 让项目知道当前步骤究竟缺多少，但也消除了旧逻辑误收几十份材料形成的假库存。三组 30 年运行的 search episode 中位数由 243 升到 458；候选三组历史合计 1178 个 search episode 在找 Wood，远高于 Stone 的 35 个。

代表历史 `project-161-born-16-leonardo-7-food-preparation` 已取得食物和 Stone，却为了 Wood 在 34 个月内检查 81 个位置后阻塞。世界规则与普通生活选项本来允许人物从视野内的 Wood/Leaves 体素分离木材，但项目编译器只读取地面 drop；一旦人物进入长项目，这个真实 affordance 反而消失。

这属于“需求存在、世界来源存在、动作效果存在，但项目规划没有展开来源动作”，不是资源稀缺，也不应靠扩大搜索半径修补。

## 单一因果假设

当当前项目步骤明确缺 Wood 时，项目可以把本人视野内的真实树木体素编译为稳定的来源 episode：

- 只使用本人当前可见、当前仍为 Wood/Leaves、且有真实可达工作位置的体素；
- episode 保存项目、人物、Wood 定量需求、源体素和固定工作位置；移动、分离及产物事件都可追溯到同一来源；
- 到达后执行已有权威 `separate` 动作，产量和附带 Fiber 仍由世界规则裁决，项目不能直接生成物品；
- 分离出的 Wood 先成为地面 drop，随后继续沿 v18 规则只取得当前缺口；多余和附带产物留在世界中，可被未来人物真实发现；
- 若树木被别人先取走、路径失效或动作失败，episode 失效并据当前世界重编译；不建立不可侵犯的资源所有权；
- 当前视野不存在合格来源时，才继续 v16/v17 的有限搜索；里程碑、文明指数和完整地图不进入选择。

本版只打通被真实历史确认的 Wood 来源，不顺手加入采矿、狩猎、共享库存或 drop claim。它们必须各自由后续历史证据触发。

## 预登记矩阵

- 基线：`candidate-quantified-step-demand-v18-observer-v11`；
- 候选：`candidate-visible-world-source-v19`；
- 种子：`185, 20260815, 20260816`；
- 三种子 × 10 年快速诊断，三种子 × 30 年最终配对；
- 模型调用与 token 为 0。

主要指标：Wood source episode 数量、需求覆盖率、真实分离输出、来源/人物/项目/体素错配、失效原因、来源移动、Wood search episode、food-preparation/knowledge-preservation 阻塞，以及生产、建造、记录和 v12～v18 护栏。

接受护栏：

- 定向测试证明“可见树木优先于盲搜；远处树木固定工作位并持续接近；分离后生成真实 drop；下一步精确取得缺口”；
- source episode 的 demand、人物、项目、源体素和动作事件覆盖率 100%，未解析、非 Wood 需求、不可见起点、虚假输出及 target 错配为 0；
- 开启 Wood search 时本人视野内存在合格树木来源的次数为 0；
- 来源被占用或改变时允许诚实失效，不得凭空补 Wood，也不得吞掉求生打断；
- v18 数量护栏和 v17 搜索记忆护栏保持为 0。

不要求文明指数、人口或某个产物单调上升。若 Wood 搜索不降，必须检查人物是否真的看见树、树是否可达、项目是否仍被更早步骤阻塞；不能把树木密度调高来掩盖编译断点。

## 结果与决定

保存产物：

- 10 年快速诊断：`data/experiments/candidate-visible-world-source-v19-quick.json`；
- 30 年候选：`data/experiments/candidate-visible-world-source-v19.json`；
- v11 观察器重投影：`data/experiments/candidate-visible-world-source-v19-observer-v11.json`；
- 与 v18 的同种子配对：`data/experiments/candidate-visible-world-source-v19-vs-v18.json`。

三组 10 年与三组 30 年均到达边界，模型调用和 token 均为 0。30 年候选建立 `7/5/7` 个 Wood source episode，全部由同一人物抵达固定工作位、执行权威 `separate` 并产生真实 Wood drop 后完成；来源失效、活动遗留、非 Wood demand、数量不平、体素引用、快照、项目、人物、target、输出、未解析事实、虚假完成和失效移动均为 0。Wood search 创建快照覆盖率 100%，有可见来源仍开启搜索为 0；v12～v18 既有护栏保持为 0。

目标行为的 30 年配对结果：

- Wood search episode 为 `451/227/500 → 2/0/9`，全部 search 为 `458/227/501 → 29/6/9`；
- 项目阻塞为 `14/8/19 → 2/1/2`，完成为 `29/36/31 → 27/42/33`；
- 移动占比为 `77.13/67.74/79.35% → 67.83/55.52/69.85%`；
- source 只产生 `25/17/27` 份 Wood，却打通分离后的 drop 与精确取得；减少搜索来自选择正确 affordance，不是无限增产；
- 生产完成中位数 `22 → 24`、熟食 `13 → 15`、建造完成 `7 → 7`；文明指数中位数 `51.34 → 55.33`，仅作观察证据。

决定：接受“抽象缺口必须先展开为本人可见的合法世界来源”这一机制。没有顺手加入 Fiber 来源、采矿、狩猎或 drop claim。

不利结果也必须保留：儿童暴露死亡中位数 `0 → 3`。逐条审计 14 次候选死亡后，13 名儿童死亡位置正是早已完成住所的内部，而非父母没有带其入屋。当前基础住所的 `weatherProtection=68` 对热负荷只缓解约 `68/145≈0.47`；极端炎热仍会累积到三级。更早的规划断点是：项目把“存在完整住所”误当成“保护已经足够”，因此没有从本人或受益者的持续暴露事实形成住所加固、热适应或迁移项目。v20 应预登记“有因果伤害证据的住所适应”，不能直接加入万能儿童保护。
