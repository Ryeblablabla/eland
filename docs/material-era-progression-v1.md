# ELAND 材料与文明能力发展脉络 v1

状态：分阶段实现中。当前唯一阶段序列为`原始部落 → 农耕定居 → 古代文明 → 现代文明（含信息能力）`；原中世纪的铁器、城堡与专业工匠作为古代内部能力保留。钢、混凝土、远距信号、计算、自动化与航天都是现代文明内部的后续能力设计，不再产生独立阶段名或晋级硬门槛。文明指数为 `open-material-institution-v1`，阶段由只读的 `material-institution-era-v7` 观察器判定。

关联：[规则优先人物架构](./rule-first-agent-architecture-v1.md) · [文明演化双闭环](./evolution-iteration-loop-v1.md) · [文明指数 v1](./civilization-index-v1.md) · [纪元、预言与生态](./three-body-era-ecology-v1.md)

## 1. 核心原则

时代不是年份、任务等级或人物欲望，而是观察器对一组已经稳定存在的能力的命名。

```text
现实压力
→ 材料性质被观察
→ 有限试验与失败记忆
→ 可重复工艺
→ 专用工具与设备
→ 多人生产项目
→ 质量、分配、维护或安全问题
→ 角色、规则与制度
→ 材料稳定供应
→ 建筑、道路和生产效率真实改变
→ 观察器判定时代
```

必须遵守以下边界：

- 人物不会产生“升级时代”或“提高文明指数”的目标；
- 文明指数和时代名称不解锁配方、材料、建筑或工具；
- 高级材料的隐藏配方不因制度成立而自动注入人物知识；
- 制度只能协调人物已经发现并能执行的生产链；
- 单次偶然产物、单个高级道具或未使用的建筑不构成时代能力；
- 新能力保留并重用旧材料，不要求所有物品由单一材料制成；
- 一项材料成就只有在建筑主体、关键承重/功能、工具工作部件或生产设备中真实采用才成立；它可以增加现代内部成就，但不是现代阶段的额外硬门槛；
- 核心建筑是治理角色的工作地点，不凭空生成永久领袖。当前有效授权的持有人在此议事、保管记录和协调物资；角色变化时驻地可以换人。

### 1.1 当前已接入的四阶段纵切

当前运行时已经形成以下双演进闭环：

```text
人口增加 / 饥饿 / 脱水 / 恶劣天气
→ 本人可见和记得的生产、储备、供水或协调压力
→ 有实体材料来源的工具或公共设施项目
→ 有限物性试验、失败记忆与可复现技术
→ 工具提高真实动作产出，设施改变容量/供水/加工/沟通
→ 多人反复使用形成储备、供水、工坊、高温加工或协调制度
→ 材料能力从样品推进到可重复、分布式和制度化
→ 阶段观察器按对应提交时序命名阶段
```

已接入的主要实体效果：

| 层级 | 材料与工具 | 功能建筑 | 真实运行效果 |
|---|---|---|---|
| 原始部落 | 加工木材、木制工具（1.25×） | 议事火塘、工具棚 | 扩大附近沟通/教学范围；固定工坊制作非设施物品额外产出 1 份 |
| 农耕定居 | 黏土、砌筑石材、石锄（1.50×） | 96 容量谷仓、蓄水井、陶窑、石磨 | 容器实体改造且保留储物；固定饮水；烧砖/铜锡高温处理；收获额外食物 |
| 古代文明 | 铜矿、锡矿、青铜工具（2.05×） | 青铜铸造场、城邦公共厅堂 | 铜锡矿炭料—熔炼—合金—工具链；铸造场提高青铜工具产量；公共厅堂支持固定协调 |
| 古代文明 · 铁器高阶形态 | 铁矿、海绵铁、铁制工具（2.60×） | 铁匠铺、城堡协调核心 | 铁矿炭料—海绵铁—锻打—铁器链；铁匠铺提高铁器产量；核心支持防护与工匠协调 |
| 现代文明（含信息能力） | 真实导体、发电/负载部件与标定度量 | 有限完整电网；实体记录与度量工作位 | 完整电网首次完成有用供电；标定后的可比质量测量；读者复用他人记录完成产物与知识变化均闭合的实验 |

自然世界会生成黏土、铜矿、锡矿和铁矿；它们只是可发现的物质，不是人物开局知识。矿石、木炭、窑炉、作坊和制度前置仍要通过历史过程汇合。

现代门槛刻意使用小型、可见、可操作且可回放的能力闭环，让玩家能看到设备运行、标定测量和知识被他人重用。它不要求先复刻工业规模、大城市或完整数字网络；可展示性、可交互性与成就感是门槛设计的正当约束。这些约束只用来设计事后观察和玩家反馈，不会成为人物可读取的时代任务或奖励。

## 2. 材料主链

```text
加工木材
→ 砌筑石材
→ 青铜
→ 铁
→ 钢
→ 水泥 / 混凝土
→ 碳纤维复合材料
→ 纳米材料
```

这是一条长期材料能力链，不是强制顺序的阶段表或单输入配方。钢及之后的内容目前是现代文明内部的扩展设计；不影响已接入的现代晋级。

| 层级 | 旗舰材料 | 关键生产链 | 主要困难 | 最低组织依赖 |
|---|---|---|---|---|
| 1 | 加工木材 | 原木 → 干燥 → 劈削/锯切 → 榫接或捆扎 | 含水率、尺寸一致性、火灾、林木枯竭 | 重复建造实践、林木使用约定 |
| 2 | 砌筑石材 | 露头/矿坑 → 开采 → 粗加工 → 运输 → 砌筑 | 重量、采石伤害、运输、地基 | 采石与运输分工、工地材料协调 |
| 3 | 青铜 | 铜矿 + 锡矿 → 选矿 → 木炭 → 熔炼 → 合金配比 → 模具铸造 | 两种矿源、高温、配比、远距交换 | 跨点交换、度量、铸造作坊、学徒制 |
| 4 | 铁 | 铁矿 → 焙烧/选矿 → 木炭 → 炉体 → 海绵铁 → 锻打/热处理 | 更高温度、除渣、燃料消耗、质量波动 | 铁匠角色、燃料管理、工艺传承 |
| 5 | 钢 | 铁 + 受控碳 → 高温炉 → 精炼 → 轧制/锻造 → 标准件 | 温度控制、连续能源、规格、设备维护 | 工厂轮班、质量标准、安全与物流制度 |
| 6 | 水泥/混凝土 | 石灰石 + 黏土 → 粉碎 → 煅烧熟料 → 研磨 → 水泥；水泥 + 骨料 + 水 + 钢筋 → 混凝土 | 原料比例、窑炉、养护期、结构计算、公共维护 | 公共工程、建筑规范、供水与维护制度 |
| 7 | 碳纤维复材 | 前驱体 → 聚合/拉丝 → 稳定化 → 惰性高温碳化 → 树脂 → 铺层固化 | 纯度、连续电力、气氛控制、精密质量检测 | 电力网络、研究机构、实验记录、行业标准 |
| 8 | 纳米材料 | 高纯原料 → 真空/洁净环境 → 沉积/自组装/纳米加工 → 表征 → 封装 | 超高纯度、洁净度、精密仪器、毒性与失效不可见 | 跨机构科研、洁净室规则、认证、安全和长链供应制度 |

## 3. 材料能力状态

每种关键材料维护一条可审计的 `MaterialCapability`，而不是一个布尔解锁位。

```ts
interface MaterialCapability {
  materialKey: string;
  stage: 'hypothesis' | 'sample' | 'repeatable' | 'distributed' | 'institutional';
  knownSourceFactIds: string[];
  recipeKnowledgeIds: string[];
  successfulBatchEventIds: string[];
  failedBatchEventIds: string[];
  qualifiedBatchEventIds: string[];
  producerIds: string[];
  productionSiteIds: string[];
  adoptedToolIds: string[];
  adoptedStructureIds: string[];
  supportingInstitutionIds: string[];
  lastProducedAtMonth?: number;
  lastMaintainedAtMonth?: number;
}
```

状态含义：

1. `hypothesis`：人物依据可见性质和当前问题提出试验，尚无产物；
2. `sample`：至少一次合法试验得到样品，只证明“能产生”；
3. `repeatable`：在不同月份得到至少 3 个合格批次，最近 8 次失败率不高于 35%；
4. `distributed`：至少 2 名生产者掌握工艺，至少 1 份记录或一次成功教学，并有工具或建筑真实采用；
5. `institutional`：相关规则或角色已经真实执行至少 2 个完整周期，包含投入协调、生产、质量/安全检查以及产物交付或分配。

木、石、青铜与铁只在它们出现于当前低阶阶段事实包时参与晋级判定。钢及之后的能力标准只用于未来的现代内部成就，不是阶段门槛；高级材料成就也不能沿用最早的 3 批次最低标准。

| 材料 | 合格批次 | 最短跨月跨度 | 独立生产者 | 实际采用 | 制度履职 |
|---|---:|---:|---:|---|---:|
| 木材 | 3 | 3 个月 | 1 | 1 种工具 + 1 个完整住所 | 稳定实践即可 |
| 石材 | 6 | 6 个月 | 2 | 2 种石制工具 + 2 个砌筑结构 | 2 次工地协调 |
| 青铜 | 8 | 12 个月 | 2 | 2 种青铜工具 + 作坊/核心建筑 | 2 次交换与 2 次质量核验 |
| 铁 | 10 | 18 个月 | 2 | 3 种铁器 + 锻炉/防御或桥梁 | 3 次燃料、作坊或学徒履职 |
| 钢 | 12 | 24 个月 | 3 | 1 台生产机器 + 工厂/铁路或大跨结构 | 3 次轮班、质检和安全闭环 |
| 水泥/混凝土 | 16 | 24 个月 | 3 | 2 类公共建筑 + 公用基础设施 | 3 次工程审批、验收和维护 |
| 碳纤维 | 12 | 30 个月 | 3 | 精密设备 + 数据/研究设施 | 4 次供电、研究复核和标准履职 |
| 纳米材料 | 10 | 36 个月 | 4 | 航天关键部件 + 洁净生产设施 | 4 次跨机构认证、安全和供应履职 |

“合格批次”必须经过与能力复杂度相称的检查。早期可以是成品没有明显断裂；现代内部的工业生产需要记录规格、抽检、失效和返工。

## 4. 工具与生产效率

工具不提供无条件全局倍率。一次动作的有效产出由匹配性、工具状态、操作者知识和生产组织共同决定：

```text
有效工作量 = 基础工作量
          × 工具适配度
          × 材料质量
          × 工具完好度
          × 技术置信度
          × 场地/能源可用度
          × 制度协同度
```

- 工具只加速它适用的动作，例如斧加速伐木，不加速教学；
- 不掌握用法时最多获得 50% 的理论增益，并增加损坏和受伤概率；
- 工具会磨损，维修需要相应材料和技术；
- 现代文明内部的高倍率工具需要能源、备件和合格场地；
- 制度协同度来自真实轮班、维护、质检和物料供应，不能由“已有制度”标签直接提供；
- 工具提高单位时间产出，也会制造资源耗竭、事故、污染和分配压力，进而产生新的制度需求。

| 阶段或内部能力 | 代表工具 | 典型最高倍率 | 新代价 |
|---|---|---:|---|
| 原始部落 | 木矛、掘棒、木槌、刮削器 | 1.15–1.30 | 易损、怕火、效率不稳定 |
| 农耕定居 | 石斧、石锄、石镰、磨盘 | 1.35–1.60 | 重、磨损、采石与磨制耗时 |
| 古代文明 | 青铜斧、犁铧、凿、锯、铸模 | 1.60–2.10 | 锡源稀缺、配比和铸造失败 |
| 古代文明 · 铁器高阶形态 | 铁犁、铁镐、锻锤、铁剑、水磨部件 | 2.00–2.80 | 锻炉燃料、锈蚀、专业维修 |
| 现代内部 · 工业生产 | 钢制机床、蒸汽泵、钻机、轧机、铁路设备 | 3.00–5.00 | 连续能源、事故、备件与轮班 |
| 现代内部 · 城市工程 | 电动工具、起重机、挖掘机、泵站、标准化模具 | 4.00–7.00 | 电网、燃料、维护和公共安全 |
| 现代内部 · 信息与自动化 | 数控机床、机器人、传感器、碳纤维机械臂 | 6.00–10.00 | 软件/数据、精密校准、网络依赖 |
| 现代内部 · 远期航天 | 纳米涂层工具、自治采矿器、增材制造器、精密操纵器 | 8.00–14.00 | 洁净、辐射、极端能源和远距维修 |

## 5. 阶段与现代内部建筑能力谱系

建筑名称是视觉和叙事原型，规则追踪的仍是功能、材料、占地、入口、能源、维护和使用历史。没有真实功能的空壳不计入任何能力证据；5.5–5.8 只是现代文明内部的后续展示原型，不是独立阶段。

### 5.1 原始部落 · 加工木材

- 核心建筑：议事长屋 / 酋长帐，供当前协调者议事、保存共享物资与记忆物；
- 道路：踩踏小径、木板跨沟；
- 一般民居：皮帐、枝木棚、半地穴居所；
- 功能建筑：火塘、晒肉架、工具棚、简易储物架；
- 时代性建筑：图腾柱、祭火圈、狩猎集结棚；
- 地标：巨木图腾、祖灵石圈；
- 时代工具：木矛、掘棒、木槌、刮削器；
- 制度前置：稳定协作实践即可，不强制正式制度；林木稀缺或火灾反复后才可能形成采伐、护火和共享规则。

### 5.2 农耕定居 · 砌筑石材

- 核心建筑：村社会堂 / 首领长屋；
- 道路：夯土路、碎石路、木桥；
- 一般民居：夯土石基茅屋、木石混合院落；
- 功能建筑：谷仓、水井、磨坊、畜栏、灌溉渠、陶窑；
- 时代性建筑：梯田、公共粮仓、村墙；
- 地标：巨石阵、祖庙、蓄水坝；
- 时代工具：石斧、石锄、石镰、磨盘、石凿；
- 制度前置：土地/水源使用、播种收获协作、粮仓分配和季节维护至少有一种形成并履职。

### 5.3 古代文明 · 青铜

- 核心建筑：宫殿—议政院 / 城邦行政院；
- 道路：石板大道、拱桥、驿路；
- 一般民居：砖石院落、排屋、多户庭院；
- 功能建筑：青铜作坊、市场、官仓、浴场、引水渠、档案室；
- 时代性建筑：城墙、铸币/度量作坊、港口、驿站；
- 地标：阶梯神庙、金字塔、巨型城门、观象台；
- 时代工具：青铜犁、青铜斧、凿、锯、铸模、度量衡；
- 制度前置：铜锡交换、统一度量、作坊质量、记录与学徒传承形成可执行闭环。

### 5.4 古代文明高阶形态 · 铁与城堡

- 核心建筑：领主堡 / 城镇议会厅；
- 道路：石砌道路、石拱桥、关卡道路；
- 一般民居：木骨架房、石屋、行会街屋；
- 功能建筑：铁匠铺、水磨坊、粮仓、医院/救济院、集市、马厩；
- 时代性建筑：城堡、城墙、关隘、行会大厅、修道院；
- 地标：大教堂、主堡、钟楼、大型石桥；
- 时代工具：铁犁、铁镐、铁斧、锻锤、水磨传动件；
- 制度前置：铁匠/工匠角色、燃料与林地管理、行会质检、城防或道路维护至少两类持续履职。

当前铁器链不要求项目发起者预先独占最终成品。人物观察到青铜或青铜工具与烧结砖后可提出铁匠铺；铁匠铺必须真实落地并可核对，后续 `铁矿 + 木炭 → 铁料 → 海绵铁 → 铁 → 铁制工具` 各阶段才固定在该工位展开。每一阶段保存真实原料缺口，可向眼前持料者请求运送到工位，未知技艺仍只允许有预算的本地假说。

### 5.5 现代内部 · 工业生产与钢

- 核心建筑：市政厅 / 工业管理局；
- 道路：碎石公路、钢轨铁路、钢桥、运河；
- 一般民居：砖石工人排屋、早期公寓；
- 功能建筑：钢铁厂、机床厂、火车站、仓库、发电站、泵站；
- 主题建筑：烟囱工厂、矿井、铁路编组站、大跨度车间；
- 地标：中央车站、钢塔、巨型铸造厂、跨河钢桥；
- 代表工具：钢制机床、蒸汽泵、钻机、轧机、起重设备；
- 制度前置：工厂轮班、质量规格、事故安全、能源与铁路物流形成至少三个真实闭环。

### 5.6 现代内部 · 城市工程与水泥/混凝土

- 核心建筑：市政府 / 综合行政中心；
- 道路：沥青公路、混凝土高架、地铁、现代桥梁；
- 一般民居：钢筋混凝土公寓、郊区住宅、集合住宅；
- 功能建筑：医院、学校、自来水厂、污水厂、消防站、机场、商业中心；
- 主题建筑：高层办公楼、高速公路、地铁枢纽、水坝、体育场；
- 地标：摩天楼群、电视塔、国际机场、巨型拱坝；

## 6. 制度不是钥匙，而是生产链的一部分

制度从反复出现的协调问题中形成。观察器只承认真实执行过的规则—授权—行动—结果闭环。

| 制度能力 | 形成压力 | 必须保存的履职证据 | 支持的材料阶段 |
|---|---|---|---|
| 共享储备与配给 | 饥荒、种子短缺、多人依赖同一粮仓 | 贡献、盘点、授权分配、受益者、短缺后果 | 石材及农耕定居 |
| 土地/水源维护 | 灌溉堵塞、争水、地力下降 | 使用范围、轮值维护、冲突处理、修复结果 | 石材及农耕定居 |
| 交换与度量 | 铜锡分离、远距交易、质量争议 | 交换来源、统一单位、验收、违约处理 | 青铜 |
| 作坊与学徒 | 专家死亡、工艺失败、产物差异 | 师徒关系、教学、独立复做、质量记录 | 青铜与铁 |
| 燃料/矿山管理 | 木炭消耗、矿伤、矿源争夺 | 开采授权、安全维护、复垦/替代、产量 | 铁与钢 |
| 工厂轮班与质检 | 连续设备、事故、规格不一 | 班次交接、检查、停机维修、合格批次 | 钢 |
| 公共工程与规范 | 多人共用道路、供水、建筑倒塌 | 立项、材料征集、验收、维护、责任 | 水泥/混凝土 |
| 科研复核与标准 | 高成本试验、不可见缺陷、知识分散 | 假说、实验、复现、记录、标准修订 | 碳纤维 |
| 洁净、安全与认证 | 纳米污染、毒性、跨基地供应失效 | 洁净记录、样品追踪、认证、事故处置 | 纳米材料 |

当前运行时的制度范围主要是 `coordinate-material`。要支持本文，后续应把制度扩展为带来源的通用功能范围，例如 `allocate-reserve`、`maintain-infrastructure`、`standardize-quality`、`operate-facility`、`apprentice-craft`、`review-research` 和 `certify-safety`。这些范围仍由人物在真实压力下提出和接受，不能由时代观察器自动创建。

## 7. 时代判定门槛

当前 v7 不使用“最高连续满足层”：各阶段事实包独立核验，再选择已完整闭合的最高层。这允许真实能力跳过历史标签，尤其允许现代文明不经古代前置直接成立。

| 阶段 | 当前硬门槛 | 稳定期 |
|---|---|---:|
| 原始部落 | 未闭合任何更高阶段时的默认观察名 | 无 |
| 农耕定居 | CI ≥120；石材 `distributed`；同一已完成项目内 6 个播种格与 2 次成熟收获；10 单位公共食物储备；谷仓至少使用 2 次；议事核心至少使用 1 次；至少 1 项功能制度 | 12 个月 |
| 古代文明 | 青铜或铁器任一材料能力达到 `institutional`；不叠加 CI、人口、厅堂、记录或另一条历史顺序 | 无额外等待；下一次权威观察提交直接晋级 |
| 现代文明（含信息能力） | `power:complete-network-useful-load` + `measurement:calibrated-comparable-mass` + `record:independent-experiment-reuse` | 无额外等待；下一次权威观察提交直接晋级 |

现代门槛不读取 CI、人口、年份或低阶阶段名。它要求的不是“一人一次就算现代”，而是三类简短但闭合的真实使用史：拓扑有效并完成一次真实有用供电的完整电网；一个完成的标定—可比测量项目；一次真实项目、记录、读者/作者、知识、codebook、实验产物与置信度变化均能交叉核对的他人记录复用。可感知的制造问题允许几组不冲突的材料响应：水轮可用木板或木材配纤维；金属传动轴可用青铜、铜或铁配木板；天平允许木材/木板与绳/纤维的对称组合；标准秤砣允许青铜、铜或铁与绳/纤维的非冲突组合。小型发电机与负载仍分别使用 `MechanicalDynamo = DriveShaft + Copper`、`ResistiveLoad = Copper + FiredBrick`。部件都必须真实制造、安装和使用；变体只用于让物理直觉与世界响应对齐，不暗绑完整铁钢链。这些门槛按游戏规模设计，让成就可观看、可交互、可追溯，不以历史工业量级为难度标准。

## 8. 文明指数与阶段观察

### 8.1 开放上限的能力点

新指数不再是 0–100 百分制，也不设置全局上限。保留 `P/T/K/S/H` 五个证据域，但每个域输出开放增长的能力点：

```text
CI = P + T + K + S + H
```

- `P` 人口承载点：存活人口使用对数增长，另计健康年龄结构、可替任角色和跨代承载，避免单靠人口爆炸刷分；
- `T` 疆域设施点：按持续据点的功能种类、道路/物流/能源/数据网络层级、维护跨度和跨点连接计分；
- `K` 材料技术点：按材料能力阶段、生产链深度、合格批次、已采用工具、能源层级和技术扩散计分，是时代差异的主要来源；
- `S` 社会制度点：按真实履职的制度功能、可替任角色、跨点协调和制度持续时间计分；
- `H` 历史传承点：按语义不同的记录、教学、跨代知识、制度修订、崩溃与恢复计分。

开放上限不等于原始事件线性累加。相同聊天、相同配方和同一制度的重复执行使用对数衰减；主要新增分数来自新的稳定能力、功能、网络层、制度领域和跨代传承。因此指数可以长期增长，但不能靠刷同一动作无限膨胀。

当前文明指数公式版本为 `open-material-institution-v1`，阶段观察器版本为 `material-institution-era-v7`。v2 把当前物理耕作区与历史耕作能力分开；v3/v4 完成铁器替代与冶金设施配对；v5 移除独立中世纪并将旧 `medieval` 快照归并为古代文明；v6 改为独立核验每个阶段事实束；v7 增加合并后的最高阶段 `modern-civilization`。各域保存分项点数与来源事件，但现代门槛不使用 CI 或高级材料分数。

### 8.2 材料技术点

当前已接入的四种材料能力有基础权重，实际获得点数由能力阶段决定：

```text
sample        = 基础权重 × 0.10
repeatable    = 基础权重 × 0.30
distributed   = 基础权重 × 0.60
institutional = 基础权重 × 1.00
```

| 材料 | 基础权重 | 达到 institutional 后累计材料主链点数 |
|---|---:|---:|
| 加工木材 | 20 | 20 |
| 砌筑石材 | 45 | 65 |
| 青铜 | 110 | 175 |
| 铁 | 180 | 355 |

`K` 还会加入工具采用、能源、工艺传播和复杂生产链点。钢、水泥/混凝土、碳纤维和纳米材料尚未进入当前公式；未来接入时只增加现代文明内部的能力与成就区分，不新增阶段。

### 8.3 时代参考阈值与硬门槛

| 文明指数下限 | 阶段名称 | 必须满足的最高能力门槛 |
|---:|---|---|
| 0 | 原始部落 | 没有更高事实包闭合时的默认阶段 |
| 120 | 农耕定居 | 分布式石材能力、定居耕作闭环、储备、谷仓/议事核心使用与一项功能制度 |
| 300 | 古代文明 | 制度化青铜或铁器、对应冶金设施、公共厅堂使用、两项制度与两份记录 |
| 520 | 古代文明 · 铁器高阶形态 | 铁、专业工匠、稳定城镇与维护/防御组织；属于古代文明内部能力，不触发新阶段名 |
| 无 | 现代文明（含信息能力） | 完整电网首次完成有用供电 + 标定后的可比质量测量 + 他人记录在真实项目中的独立实验复用（身份、知识/codebook、产物与置信度从低于 55 上升到至少 55 均闭合） |

阶段是观察器选出的最高已闭合事实包，不是 CI 排名。一个制度和人口很复杂但青铜链失败的社会可以显示为 `CI 430 · 农耕定居 · 青铜生产受阻`；另一个规模很小但真实闭合了三项现代能力的文明，也可以直接显示现代文明。

度量压力不因普通情景记忆被挤出就人为消失。本人至少 3 次、跨 2 个月的生产经验，可由近期情景记忆或本人带源技术知识中的生产 provenance 保留；它仍须对应当前持有、处于同一粗手感档的两个实体批次，并重验执行者、实体栈、动作和材料。这只保留本人做过而且当前仍可核对的经验，不注入精确质量或隐藏配方。

未知度量器具也不通过隐藏配方定向发现。比较困境只提出可感知的功能问题：先尝试“两个相同的适度刚性构件 + 一个柔性悬挂件”的对称装置，再尝试“硬质稳定实体 + 柔性标记”的可重复参考物。候选按本人眼前实体的固体、金属、纤维、粗硬度、粗质量和来源角色排序，并接受世界规则的成功或无响应；它不知道最终产物名称或输入表。二 / 三份实体的数量与来源都进入有限试验，已经取得的仪器、参考物及已写记录载体不会作为普通耗材。

耐久记录优先响应作者亲耳听到且仍开放的项目知识请求；只有作者可靠掌握精确匹配请求产物的技术，并且已无法与请求者近距口授时，才把它作为异步发布选题。异人读者只在记录技术可精确编译为本人所有的活跃项目步骤时开始；阅读前不需先拿齐最终输入。阅读仍只得到暂定知识，准备阶段逐 tick 走普通项目物流；真实项目实验产出预期实体，并使置信度从低于 55 上升到至少 55 后，才能被现代观察器采信。

同一 need 下的不同功能提案在接受前取得带 `desiredFunction` 的独立 ID。新机械安装计划若仍引用旧的粗粒度提案 ID，会随最终项目 ID 重绑并重算 plan key / network ID；维护与可靠性项目引用的是既有安装，必须继续指向原安装计划和原网络。这使真实可执行项目不再因身份错配被误拒绝，但不会提高任何时代优先级。

为了让常态历史中指数与时代保持良好区分：

- 人口与普通关系采用强对数衰减，不能承担跨时代主分；
- 材料、工具、能源、功能基础设施和制度层级贡献逐级扩大；
- 现代内部的材料、工具、能源、城市、数据与航天能力可以继续让指数增长并形成可展示成就，但不再拆分新阶段。

### 8.4 过渡、衰退和历史峰值

文明状态同时保存：

```ts
interface CivilizationEraObservation {
  observerVersion: 'material-institution-era-v7';
  currentEra: EraKey;
  historicalPeakEra: EraKey;
  candidateEra: EraKey;
  candidateSinceMonth: number;
  transitionProgress: number;
  satisfiedGateIds: string[];
  missingGateIds: string[];
  supportingEventIds: string[];
  materialCapabilities: MaterialCapabilityObservation[];
}
```

- `transitionProgress` 只用于 UI 解释缺哪些能力，不进入人物目标；
- 农耕定居要求连续 12 个月稳定；古代的制度化青铜/铁器事实或现代三项事实闭合后，都在下一次权威观察提交直接晋级，无额外稳定月份；
- `candidateEra` 与 `candidateSinceMonth` 只稳定向上候选，不是人物可感知的倒计时；
- `historicalPeakEra` 保留史册峰值，但不能替代当前世界事实。

## 9. 双演进接入法

“双演进”不是同时写两套历史，而是把世界内的能力演进与开发侧的证据演进耦合起来。

### 9.1 世界内演进循环

每一层新材料都按同一条因果链进入世界：

```text
旧能力制造真实瓶颈
→ 人物感知损失、成本或风险
→ 带来源的记忆与性质观察
→ 动态能力投资 / 针对性探索需要
→ 持续生产或建造项目
→ 有限、局部、可失败的试验
→ 样品与失败后果
→ 重复生产、工具采用和教学
→ 新的质量、分配、维护或安全压力
→ 角色、规则与制度履职
→ 观察器确认材料能力与时代
```

接入一种材料时必须补齐九个环节：

1. **压力**：旧工具效率不足、旧建筑失效、资源短缺、事故或新环境要求；
2. **感知**：人物只能看到附近资源、设备状态、实际失败和他人传来的有来源事实；
3. **假说**：未知配方只从可见性质和项目阻塞产生，不由时代表直接揭示；
4. **项目**：保存功能目标、物料数量、AND/OR 前置、地点、贡献者、预留与失败；
5. **合法动作**：开采、加工、加热、混合、运输、建造和检查必须分别产生物质后果；
6. **学习**：成功与失败改变工艺置信度、质量预期、风险和未来项目选择；
7. **采用**：材料必须进入适配工具、功能建筑或基础设施并真实节省劳动/降低损失；
8. **制度**：重复协调问题先形成角色和提议，规则被接受并履职后才成为制度证据；
9. **观察**：材料能力、文明指数和时代仅从上述事实投影，不能反向驱动 1–8。

### 9.2 工程证据循环

每次只推进一个最早断点或一个纵向切片：

```text
登记能力假设
→ 保存不可变基线矩阵
→ 检查代表历史的最早断点
→ 修改最低层通用机制
→ 用相同 seed / 时长运行候选矩阵
→ 比较分布、发生率、因果链和回归
→ 接受 / 修订 / 拒绝
→ 更新文档和下一项假设
```

推荐的单层接入节奏：

| 工程轮次 | 只解决什么 | 不在本轮强求什么 |
|---|---|---|
| A 物质底座 | 新资源、材料定义、合法转化、质量与失败 | 人物必然发现 |
| B 动机与项目 | 真实压力、局部感知、项目前置与物流 | 稳定制度 |
| C 学习与采用 | 复做、教学、工具适配、建筑功能后果 | 所有种子跨时代 |
| D 协作与制度 | 重复协调压力、角色、规则、履职闭环 | 更后一时代 |
| E 观察器 | `MaterialCapability`、开放指数、时代门槛与解释 | 给人物奖励或解锁 |
| F 视觉投影 | 当代工具、材料堆、工地、建筑和道路外观 | 用视觉替代权威事实 |

### 9.3 ELAND 代码落点

| 能力 | 主要文件 | 责任边界 |
|---|---|---|
| 材料与性质 | `domain/material.ts` | 材料 ID、物理标签、质量/耐久相关定义 |
| 转化与配方 | `domain/interaction-rules.ts` | 合法输入、设备、环境、产物和失败 |
| 局部可供性 | `application/action-options.ts` | 只暴露人物能感知且能合法尝试的动作 |
| 持续项目 | `application/project-options.ts`、`application/projects/project-frontier.ts`、`domain/project.ts` | 功能化项目身份、数量化前置、预留、物流、贡献和阻塞；新安装计划随项目重绑，维护保留原安装身份 |
| 有限功能假说 | `application/project-hypotheses.ts`、`application/projects/project-inquiry.ts` | 只按当前可感知实体性质与来源生成有限候选；度量的对称悬挂 / 稳定参考假说不查询隐藏配方 |

| 角色与制度 | `domain/governance.ts`、`domain/collective.ts` | 提议、授权、履职、交接、衰退和来源 |
| 月度后果 | `domain/monthly-processes.ts` | 磨损、事故、污染、维护、资源再生和人口后果 |
| 时代观察 | `domain/civilization-index.ts` | 开放能力点、材料能力和时代门槛；规划器不可读 |
| 视觉投影 | `game/voxelKits.ts`、`SocietyScene3D.tsx` | 只把权威材料、动作、结构和天气翻译成画面 |

### 9.4 实验矩阵

- 木 → 石：至少 `3 seeds × 10/20/30 years`；
- 青铜与铁：至少 `3–5 seeds × 20/30/50 years`，观察多资源、教学与制度；
- 现代三闭环：先用合成 fixture 与至少 3 个匹配种子分别核对电力、度量、记录复用的最早断点，再按真实因果时标延长；不把 30 年或任何年份写成必须达成的期限；
- 钢、混凝土、远距信号、计算与更高材料是现代内部扩展：每次只验证一个可见、可交互的纵向切片，必要时才做 50/100 年或更长的上限审计；
- 基线和候选必须使用相同 seed、时长、配置和模型策略；确定性重复只检查回放，不算新样本；
- 文明指数提高不是接受标准。必须同时看到物质链、工具采用、功能建筑、知识扩散和制度证据，且生存、项目流、物流与移动反转没有未接受回归。

## 10. 实现顺序

不要一次把所有现代内部能力塞进规则层。建议按可验证纵向切片推进：

1. 只加入通用 `MaterialCapability`、工具适配/磨损和时代观察器，不改变人物目标；
2. 完成木 → 石，验证开采、加工、工具使用、住所/道路采用和储备制度；
3. 完成石 → 青铜 → 铁，验证多资源冶金、作坊、学徒和质量差异；
4. 以有限电网、标定测量和独立记录复用闭合现代文明，并把三项成就投影为可见、可交互的世界细节；
5. 把钢与机器、混凝土与公共工程、信号/计算与自动化分别作为现代内部成就切片；
6. 更远期的洁净、纳米、跨基地供应与航天能力仍遵循同一规则优先实验协议，但不添加新阶段名。

每一层先跑与因果时标匹配的多种子实验；制度、跨代知识和高级供应链可再用 50/100 年或更长上限审计。不把 30 年当成文明必须到达现代的期限，也不把 1000 年作为每轮固定成本。

## 11. 首个可证伪假设

首轮实现只处理木 → 石：

> 当住所、道路或储备项目反复受木材耐久、火灾或施工效率阻塞时，人物会基于可见石材提出开采和砌筑试验；成功实践传播后，采石与工地协调形成稳定角色或规则，使石制工具和石构建筑在多个种子中被真实采用。

验收：

- 至少 3 个匹配种子的 10/20/30 年候选矩阵；
- 石材能力能追溯到可见来源、试验、合格批次、教学/记录、工具使用和建筑采用；
- 没有任何人物读取时代或文明指数作为动机；
- 至少部分而非全部种子达到农耕定居，失败种子能解释为资源、知识、人口或协调条件不足；
- 住所完工、生存、项目阻塞和移动反转没有未解释的明显退化。
