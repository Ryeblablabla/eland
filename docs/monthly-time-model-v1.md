# Eland 月度时间模型 v1

状态：当前权威时间设计（schema 15）。月是存档与日历单位，每月包含 15 个本地规划刻度。模型调用遵循[规则优先人物架构](./rule-first-agent-architecture-v1.md)，不在月度主链中。

范围：three-body 人间世界的时间、规划、长期行动、历史与播放节奏。

关联：[规则优先人物架构](./rule-first-agent-architecture-v1.md) · [空间行动契约](./spatial-action-contract-v1.md) · [像素世界（空间·历史·迁移）](./pixel-world-v1.md)

## 1. 核心决定

世界的存档时间步是一个月，人物的执行粒度是一个规划刻度：

```text
1 月 = 15 个 planning tick
```

关键分离：

```text
月度世界推进 ≠ 模型调用
人物规划       ≠ 每月只发生一次
规划刻度       ≠ 每次都更换长期目标
长期意图       ≠ 一次完成行动
没有模型       ≠ 人物没有决定
```

规则世界、人物规划和动作执行必须在本地完整闭环。模型只通过异步任务提供少量长期建议、交互或叙事。

## 2. 权威时钟

```ts
interface WorldClock {
  unit: 'month';
  elapsedMonths: number;
  monthsPerYear: 12;
}

const PLANNING_TICKS_PER_MONTH = 15;
```

`elapsedMonths = 0` 是文明初始态。完整执行 15 个 tick 和月末结算后，才能提交下一个月并增加 `elapsedMonths`。

显示纪年只由月数派生：

```text
completedYears = floor(elapsedMonths / 12)
monthOfYear = elapsedMonths === 0 ? 1 : ((elapsedMonths - 1) % 12) + 1
displayYear = elapsedMonths === 0 ? 1 : floor((elapsedMonths - 1) / 12) + 1
```

年龄、妊娠、疾病、承诺期限、长期目标复核和制度持续时间均保存月数，不另存年度计数。

## 3. 月不是地球季节，tick 也不是自然日

月是文明内部等长时间单位，不预设春夏秋冬；当月温度、光照、降水、冻结和火灾风险来自宇宙天象与世界过程。

15 个 tick 是人物行动密度，不等于 15 天。环境可以在月初、特定 tick 或月末按明确规则变化，但同一规则版本、种子和历史必须得到相同结果。

## 4. 长期意图

人物至多有一个当前执行中的 `Intent`。意图保存目标条件，不保存“本月一次动作”：

```ts
interface Intent {
  id: string;
  ownerId: string;
  domain: 'strategic' | 'social';
  goal: FactPredicate;
  nextAction: PrimitiveAction;
  status: 'active' | 'suspended' | 'completed' | 'blocked' | 'abandoned' | 'failed';
  createdAtMonth: number;
  lastProgressAtMonth: number;
  stateGoalUntilMonth?: number;
  sourceFactIds: string[];
}
```

采集、储藏、建造、种植、知识和关系目标通常维持 3～12 月。状态暂时满足时可以进入维护；跌破目标时恢复执行；到复核月份时由本地规划器决定完成、延长或更换。

每个 tick 只推进意图的一项原子动作。移动、搬运、施工、照护、观察和履约因此能在同月产生多段真实进展，也能跨月延续。

## 5. 目标组合与当前焦点

人物同时保留四类目标压力：生存、生产、社会和求知，但任一 tick 只执行一个当前焦点。

本地规划器每个 tick 都检查：

- 当前意图是否仍合法且有进展路径；
- 身体或直接危险是否要求反射；
- 是否存在到期承诺、必须回应或依赖照护；
- 空闲人物是否有可执行生产/探索目标；
- 未完成生产目标是否应优先续作；
- 重复社交是否应被冷却；
- 当前目标是否达到复核月或已经客观完成。

稳定意图不生成无意义的“继续生活”决策文本；引擎直接推进并记录动作。只有创建、改变、挂起、恢复、放弃或完成意图时才生成 `DecisionFact`。

## 6. 本地规划刻度

对 `planningTick = 1..15`：

1. 计算当前人物稳定执行顺序；
2. 为当前人物生成最新局部感知和合法可供性；
3. 执行确定性生存/照护反射；
4. 检查并修复 active intent；
5. 若没有可执行意图，立即由正式 `RulePlanner` 选择目标；
6. 编译下一项原子动作并进行前置条件预演；
7. 执行动作，写入路径、成本、结果、世界差异和来源；
8. 后续人物读取本 tick 已提交的世界状态。

本地规划器始终可用。模型额度、网络状态和外部任务不能让人物失去这个入口。

## 7. 反射、计划和重新规划

优先级：

```text
直接生存反射
> 到期履约、必须回应和依赖照护
> 修复仍有效的长期意图
> 未完成生产与空闲生产机会
> 探索、求知和非必要社会活动
```

紧急吃喝、脱离火场、避免立即失温和幼儿依赖照护由规则直接执行，不创建模型任务。

生殖合法性与生殖后果必须分开：双方同意且身体适格即可执行生殖原语；亲缘距离不阻断动作，而是在出生和后续月份形成遗传负荷、属性偏差与疾病风险。人物是否回避近亲取决于本人已经形成或经沟通获得的有来源认识，不读取全局族谱答案。

计划失败时：

1. 同 tick 尝试重算路径、靠近目标、取前置材料或更换已知方法；
2. 仍不可行则由本地规划器选择同目标的替代子目标；
3. 目标消失、持续失败或长期价值变化时，才改变长期意图；
4. 重大停滞可以排队一个异步战略建议，但本月继续按本地结果推进。

## 8. 模型任务

删除人物月决策 credit。模型预算不再决定谁能行动。

模型任务只属于：

- `strategy`：低频长期战略建议；
- `interaction`：玩家主动对话；
- `creative`：名称、符号、故事、仪式、假说或协议草案；
- `narrative`：对已经发生的重大事实补充人物视角。

后端提交规则月后才能派发普通模型任务。任务完成时，建议必须在未来规划 tick 重新验证；叙事只能写入非权威投影。超时、失败和非法内容不会回滚或暂停月份。

默认战略预算按文明年或重大事件计数，例如每年 1～3 次，而不是按人口和人物月计数。开局、紧急事件、回应和履约没有模型豁免。

## 9. 月度执行顺序

```text
1. 取得当月天象，推进月初环境过程
2. 更新协议、权限、记忆期限和月初感知基础
3. 顺序执行 15 个 planning tick
4. 每个 tick 内完成本地规划、预演、修复和原子动作
5. 月末结算身体、状态、疾病、妊娠、死亡和环境后果
6. 更新关系、知识、共同体与观察器
7. 写入 MonthRecord、WorldDelta 和 MonthFrame
8. 每 12 月生成确定性年度聚合
9. 如有重要事件，异步排队少量模型增强任务
```

月提交是原子的：进程中断时恢复上一个已提交月。模型任务不参与这个事务。

## 10. 同刻度冲突

人物按 `seed + branchId + month + planningTick + personId` 产生稳定顺序。

- 两人争取同一耗尽资源：先执行者取得，后执行者当 tick 本地修复；
- 两人放置互斥构件：第二项被拒绝并立即重新规划；
- 双人交换和对话仍要求双方当时可达；
- 一个动作造成的死亡、阻塞或物质变化立即影响后续人物；
- 不允许模型通过提前看到 tick 末状态获得全局优势。

## 11. 历史事实

```ts
// 与运行时 BaseEvent 一致；planningTick/orderInTick 对新事件应明确记录
interface EventTime {
  atMonth: number;
  orderInMonth: number;   // 兼容字段，旧事件沿用
  planningTick?: number;  // 0 表示月初/月末系统过程，人物动作使用 1..15
  orderInTick?: number;
}
```

旧事件可在迁移读取时把 `orderInMonth` 映射为兼容顺序，但新事件应明确记录 planning tick。每项动作仍保存人物、意图、路径、状态差异和来源。

## 12. 快速演化与播放

后端快速演化可以在一次进程中连续执行任意月数，每月仍完整运行 15 个 tick，不跳过中间规则状态。

前端 MonthFrame 至少包含：

- 人物本月 15 个 tick 的压缩路径或关键位置；
- 本月新建、改变或损坏的物质和结构；
- 意图开始、改变、完成和阻塞；
- 重大身体、关系、协议和环境事实。

客户端可以压缩展示，但不能伪造路径或提前显示月末结果。现有前端 Kimi 决策路径暂时保留，后续迁移；后端快速演化不复用该阻塞路径。

## 13. 时间尺度换算

| 概念 | 当前规则 |
|---|---|
| 年龄 +1 | 完成 12 月 |
| 一月行动 | 最多 15 个规则动作机会，受身体和反射限制 |
| 长期意图 | 通常 3～12 月，必要时更长 |
| 妊娠/疾病/承诺 | 保存 `dueAtMonth` / `durationMonths` |
| 道路和制度 | 跨多个 tick、月份和人物的事实组合 |
| 模型战略建议 | 独立异步任务，不属于时间换算 |

月度概率不能直接把旧年度概率除以 12。若过程确实满足独立月采样，才使用：

```text
p_month = 1 - (1 - P_year)^(1/12)
```

## 14. 验收不变量

- 完成 12 月才使年龄增加一岁；
- 每个已提交月完整执行 15 个 planning tick；
- 没有模型时空闲人物仍会获得本地意图；
- active intent 在同月可推进多项原子动作，并可跨月延续；
- 紧急、履约和必须回应由规则处理；
- 模型超时不会让月帧停在上一月；
- 模型结果不能直接修改格子、身体、物质、协议或计划进度；
- 相同种子和已接受输入得到相同规则历史；
- 回放不重新运行规划器或模型；
