# 人物自主性与文明演化：2026-09-05 重构

> 本次试验已于 2026-09-05 按用户要求结束。本文保留实现与设计记录；完整目标未验收通过，后续工作需用户重新开启。

人物的认知来自模型；家庭、组织、技术传播和文明进程应来自他们在世界中的行动及后果。系统不向人物下发文明阶段目标，也不把生育率、设施数、争斗次数或时代分数当作人物奖励。

## 执行边界

1. **Mind** 依据本人处境、经历和未完成关切选择目标及原话。
2. **Plan** 读取完整动作接口，把目标译成当前可执行步骤。接口包含对象、社会含义、耗时、回应关系和后续动作。候选是已有能力的示例，不是思想白名单；新做法可以交给世界语义解释。
3. **世界语义解释** 先编译实际 effects，再描述结果。取材、移动、建造必须分别发生实物转移、位置变化和组件投入；knowledge 只表示认知变化。纯社会行为使用说话者的结构化含义，经过实际传播和其他人物的独立回应。
4. **领域执行器** 提交身体、物资、空间、协议、作品和事件。一次失败保留原因和实际结果，不把“没达成目标”伪装成“什么都没发生”。

删除了以中文关键词、字面重叠和行动类别判断思想是否符合动作的策略。它们会把“我投阿山一票”等自然表达降为普通陈述，也会拒绝不在目录里的自命名造物。人物提出的含义与他人真正接受的含义仍是不同事实。

首次意图不再由性格正则预填。Mind 只收到真实抵达背景，关切保留实际持续月份及反馈，可见对象保留真实位置和相对距离。模型的可选关系解读若没有合法来源，只丢弃该项解读，不连带取消合法目标。

提示词 JSON 模式和仅支持 `json_object` 的服务现在也收到完整 JSON Schema，避免服务端要求字段却不告诉模型。批量请求使用与单人物完全相同的编译修复路径，个体异常独立记录；有限并发只控制上游请求，不决定人物行为。

## 时间与行动

每月仍有 15 个活动片段。模型按人物月复核，关键结果后可以进一步复核；其他片段执行已有计划、项目、身体反射和现实义务。远程调用的容量控制不改变模拟月的长度，也不应把基础设施失败写成人物选择发呆。

月内未完成的多步计划由独立 `continuePlans` 端口续编：复用原 Mind 目标，把完整计划及真实回执交给 Plan，不重新生成 Mind 或语言广播。阶段完成或受阻后才打开这个端口；原话不能用来新增社会同意，恢复旧事务也要确认没有待发的新话语。Plan 明确选择等待、暂停或放弃后停止当月续编。模型思考次数与计划翻译次数在观察报告中分开。

取消每月两次本地规划的限制。短观察取得结果便结束；未得到想要的证据会写为 `attempted-unmet`，不会靠重复观察刷新多年进展。预计月份用于复核，不能单靠到期就制造目标失败。最近完成或失败的任务会把原计划、已做步骤和实际回执交回 Mind/Plan。

Plan 可显式选择“说完之后本人去做”的物理后续，交谈和移动、取材或建设在同一意图内依次执行。开场提议独立产生协议，不能借来授权后续身体行动或替别人同意。没有选后续的对话独立结束。

旧 token 策略按每个 context 8,000 token 估算，实际 Mind + Plan + 世界解释可能超过该数，从而剥夺后续月份的思考机会。现在保留真实费用账本与请求容量控制，移除这项估值对人物月复核的隐性剥夺。

## 社会与代际

删除全局 50 人受孕上限，以及凭全局人数增加每个人代谢消耗的规则。资源压力来自实际可用食水和生活条件。生理状态连续影响受孕，独立同意、既有妊娠与出生过程仍由领域结算。

去掉亲密分数、固定冷却期、预设合作履历对提出关系、讨论选举和退出关系的限制。有效取用许可按实际约定执行，不再因为算法认为人物“不需要”而拒绝。偷窃与暴力沿已有的争抢、伤害、目击和关系后果运行。允许一种行为，不等于强迫人物选择它。

生育链路已有提案、回应、尝试、妊娠、出生和世代信息；选举已有独立选票、多数与任期授权。这只能证明机制存在，不能单凭这些代码认定模型已经自然形成多代社会。散居群体的异步议事仍未实现。

## 自命名设施与积累

`WorkState` 保存真实组件、排布、建造者、位置与使用回执。人物可以给组合物命名并继续加件，玩家的结构视图显示其自命名结果。名字不自动赋予电力、农业或文明等级；功能需要实际使用与可重放效果。

修复组合设施读取已经消耗的体素、把投入误记为空气的问题。投入先按动作前快照确定，组件数量不再被 24 单位截断，活设施不再因超过 128 个而被缓存淘汰。输入不能重复分配到产物和造物。开放实体状态也不再按全世界最近 256 条任意丢失。

自由动作的靠近可指向人物、物品或地表，沿真实路径和工作量移动；去水边会寻找可落脚的岸边。本人占着施工点时先让出位置，其他人占用时反馈其身份，由人物自行选择等待、协商或另选位置。被实际摧毁的锚点不再继续提供幽灵遮蔽。

现有组合物拥有遮蔽、结构与世界交互能力，并不等于任意新设施的全部功能都已自动实现。未被世界表示的因果过程仍需扩展通用物理或社会能力，而不能只生成一句“已经发明”。

自由动作的主结果文字从已提交 effects 生成；世界模型的自由叙述只留在解释字段，不再直接充当行动事实。个人观察或判断明确标识，不能把“认为对方愿意”写成世界中的实际同意。

## 长程演化与观察

旧后台长程演化固定调用同步 `stepOwned`，不管设置中的模型模式。现已接入同一 `ServerLlmDecider` 和异步月份用例；模型模式逐月保存已提交状态、实际模型名与 token 用量。本地模式继续使用本地规则。模型配置缺失不会被标成成功的模型演化。

可以运行独立观察，不改当前玩家存档：

```bash
cd three-body
node scripts/observe-society.mjs --months 24 --seed 31 --output data/experiments/society-observation
```

脚本调用生产长程用例，保存 `state.json`、`evolution.json`、`report.json` 和 `behaviour.json`。编译失败另存 `model-diagnostics.jsonl`，不当作人物选择或世界记忆。`--resume <state.json>` 继续已有历史；`--months` 是绝对终点。只有到达旧观察终点的样本可以延长观察，真实灭绝不会被复活。`--mode local` 可单独观察规则模式，不作为模型智能证据。

验收应阅读实际轨迹：人物是否根据结果改变做法，建造物是否被使用和继承，关系是否改变后续决定，后代是否活到成年并传播知识，文明阶段是否有真实生产与组织证据。短期构建成功、对话丰富或能力单测通过，都不能替代几十年、多代的观察。
