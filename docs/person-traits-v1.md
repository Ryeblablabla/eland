# 人物特质 v1

## 1. 权威语义

特质是 `PersonState.traits` 中的出生事实，不是人格标签、临时状态、文明奖励或 UI 装饰。每个人出生时一次确定，之后永久不变；最多保留三个遗传 / 先民特质和一个随机异变特质，`sourceEventIds` 指向开局共同抵达事实或本人的出生事实。

- 先民按档案人物 ID 使用固定配置，不随世界种子变化。
- 新生儿先从亲生父母已有的可遗传特质中抽样，再独立抽取随机异变；魅魔、双生和饕餮不进入遗传抽样，每人最多命中一项异变。
- 每项遗传用 `seed + childId + traitId` 确定性抽样；出生事实保存概率、样本、来源亲代和截断原因，因而可以回放。
- 每项异变用独立的 `seed + childId + traitId` 确定性抽样，当前单项概率均为 3%；出生事实保存全部异变样本、性别资格、命中与单项上限截断。魅魔只在女性出生时具备抽样资格。
- 同一普通特质由双亲共同携带时，概率为 `1 - (1-p)^2`；母脉激活后，母亲携带的其他特质先将母系概率乘 1.5，最高 90%，再与父系概率合并。
- 寒裔与炎裔互斥；若两项均抽中，保留样本值较低的一项。超过三个遗传特质时同样按样本值由低到高保留三项，异变另有一个独立槽位。
- 旧存档缺少 `traits` 字段时，只在恢复阶段按原历史做一次先民 / 遗传补全，不倒灌随机异变；已有特质不会在月度推进中重抽或改写。

| 饕餮 | — | 3% | 移动、操作、感知、沟通、认知各 +20，最终仍限制在 0–100；统一月度身体结算中的营养消耗乘 1.5。 |

## 4. 边界与投影

特质可以改变人物自身的出生能力、身体结算、记忆预算、婚育窗口和有来源的知识，但不能读取文明指数、观察器里程碑、全局地图或他人私有状态。先知知道“怎样做”，仍必须感知材料、取得实体、建立项目、移动到现场并通过 `ActionExecutor` 的全部合法性检查。

人物页只读显示特质名与效果说明；可选决策模型只收到当前人物自己的特质投影。UI 和模型都不能写入、添加或删除特质。

主要实现入口：

- `domain/trait.ts`：定义、固定配置、遗传与随机异变抽样、互斥、上限及共享效果函数。
- `application/simulation/state-lifecycle.ts`：先民赋值与旧状态补全。
- `application/action-options.ts`、`application/cognition/`：普通双方生殖候选与魅魔单方候选、需要和门槛投影。
- `domain/monthly-processes.ts`：新生儿遗传 / 异变、双胞胎、妊娠中止、产后恢复、母系命名 / 羁绊、身体与气候效果。
- `domain/action-executor.ts`：移动代谢、普通双方协议 / 魅魔单方授权、半仙婚育执行门禁与母亲首次技术教导。
- `domain/memory.ts`：灵记容量和留存。
- `adapter.ts`：只读人物页投影。
