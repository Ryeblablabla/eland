## 1. 核心决定

Eland 是一个可以独立运行的确定性社会模拟游戏。大模型不是世界时钟、人物行动或规则裁决的依赖。

旧假设：

> 人物出现关键决策机会，就应尽量交给模型。

当前假设：

> 人物始终先由本地规划器获得完整可执行决定。实时会话把“选什么”和“怎么说”分开：只有存在真实选择空间的少量关键上下文可让模型从本地合法候选中重选；规则实际提交的每一条口头沟通，则在事实完成后以结构化 `speechAct` 交给模型自主表达。决策失败保留本地决定；台词失败保留沟通事实但不显示文字气泡。

因此必须满足：

- 没有 API Key、模型超时、模型返回非法内容或服务完全离线时，文明仍能从开局连续演化到终局；
- 后台快速演化、实验矩阵和动作提交不得等待模型；实时单月会话可在 planning tick 1 前为筛中的关键选择做有上限的等待，并在规则月提交后为已发生的口头沟通批量生成只读台词；
- 模型输出只能成为待验证的建议、人物表达或叙事，不直接成为世界事实；
- 快速演化的耗时主要由本地规则复杂度决定，不随人口 × 月份线性增加外部请求；
- 已提交月份从 DecisionFact、ActionFact 和已保存的 GameFrame 投影回放，不重新调用模型；从旧月份创建新分支后，后续模型选择与台词属于该分支的新输入。

## 2. 三层权威

```text
世界层（唯一事实权威）
  物质、空间、身体、资源、关系、承诺、知识、时间和后果

本地人物层（行动权威）
  反射、局部认知投影、因果 BDI、项目 / HTN 编译、动作预演、局部修复

模型层（非权威增强）
  候选内重选、玩家对话、创造性表达、绑定已发生动作的人物台词和历史叙事
```

世界层和本地人物层必须独立闭环。模型层可以缺席。

## 3. 时间：每月 15 个规划刻度

“月”仍是存档、人口、身体状态、环境过程、历史索引和 UI 日历的最小权威时间单位，但不再是人物规划与执行的最小单位。

```text
1 月 = 15 个 planning tick
```

每个规划刻度代表本月可辨认的一段行动机会。它不是固定天数，也不向 UI 承诺现实日历；15 只是当前动作密度与性能之间的规则常数。

月度流程：

```text
月初环境与协议生命周期
→ planning tick 1
→ planning tick 2
→ ...
→ planning tick 15
→ 月末身体、状态、人口和观察器结算
→ 提交 SimulationState 与 WorldEvent 历史
→ 实时会话记录 checkpoint / delta 快照和 GameFrame 投影
```

实时宇宙已经提交“三日凌空”时，它是月初世界层的终局事实，而不是人物可以规划应对的普通高温。该事实在第一个 planning tick 内先于任何 DecisionFact / ActionFact 让所有存活人物汽化，结算其当前及暂停意图并销毁随身库存，不生成遗体或遗物；随后本月 15 个 planning tick 仍按时间契约存在，但已无可行动参与者，月末以零生还者立即结束文明。普通纪元调度产生的 `fire` 不携带这项终局语义。

一次推进开始时固定 `atMonth = state.clock.elapsedMonths + 1`，并把它传给月初过程、15 个 planning tick 的候选生成与重编译、年龄门禁、协议生命周期、事实 ID 和月末结算。推进中的代码不得再把尚未提交的世界误当成旧月。普通只读查询仍以 `elapsedMonths` 指向最近已提交月；`elapsedMonths = 0` 的文明创世是显式例外。

每个 tick 对每位仍可行动人物执行：

1. 读取该 tick 开始时的局部感知与身体状态；
2. 优先执行吃、喝、逃离直接危险和依赖幼儿照护等确定性反射；
3. 检查当前长期意图是否完成、失效、受阻或需要局部修复；
4. 若无可执行意图，本地规划器立即选择一个合法目标；
5. 把目标编译为下一项原子动作，并在提交前预演其前置条件；
6. 先用廉价规则补移动、材料、恢复或替代目标；
7. 执行至多一个原子动作，写入真实路径、成本、结果和来源；
8. 下一人物读取已经提交的当前世界；稳定执行顺序写入历史。

人物不必每个 tick 更换长期目标。3～12 月状态目标仍可持续，但引擎每个 tick 都有机会推进、修复或在客观失效时改换手段。

## 4. 本地规划器

本地规划器不是占位 Mock，而是正式游戏系统。它的输入只有人物可获得的事实：

- 当前身体、状态和行动限制；
- 眼前可见对象与有来源的记忆目标；
- 当前长期意图及最近成功/失败；
- HEXACO 人格、控制/地位动机敏感度、关系、承诺和共同体职责；
- 引擎生成的合法可供性；
- 时间、距离、材料和风险的粗粒度估计。

它维护四个目标分支：

```text
survival    生存、健康与直接安全
production  采集、储备、建造、耕作、制作与维护
social      照护、合作、交换、承诺、冲突与共同体
inquiry     探索、观察、试验、学习、记录与表达
```

目标分支不是四个同时执行的计划。人物在任一 tick 只有一个当前执行焦点；其他分支保存需求压力、未完成目标和最近进展。

候选生成是只读预览：项目下一步可以在私有快照中试编译，但只有人物真正选择该候选，搜索 campaign、物流 episode、计划知识和项目状态才允许写入权威世界。年龄门禁也在每次候选编译内部执行，不能只依赖月初过滤。

材料证据分三层使用：`observedMaterialIds` 只证明人物看见过某种材料或能力线索；`accessiblePortableMaterialIds` 只包含本人背包和当前可取得的可见掉落物；`placedFacilityMaterialIds` 只包含世界中真实放置的设施，记忆地点也必须重新核对当前体素。另一个人物背包里的工具或设施可以成为观察证据，但不能冒充本人可用工具或已经建成的公共设施。

年龄门禁按已经过完的月数判断，并同时约束候选与移动归属：

| 年龄 | 规划能力 | 移动规则 |
|---|---|---|
| 未满 1 岁 | 不进入普通规划，只接受照护和身体结算 | 清醒且与亲代同处时，可由亲代的一次移动携带；脱水休眠时保持原位 |
| 1–11 岁 | 可在跟随、取水、拾取、采收、拾柴和观察学习中自主选择 | 普通目标须留在当前可见亲代的本地照护半径内；严重压力时可走向当前可见亲代；每次移动仍来自本人的合法行动 |
| 12–15 岁 | 可生产并参与既有项目，不能发起重大项目或繁衍 | 与普通人物一样提交自己的移动 |
| 16 岁以上 | 完整规划能力 | 与普通人物一样提交自己的移动 |

“照护关系”不等于“同步位置”。亲代可从视野内 12 岁以下亲生子女的真实位置与身体事实判断紧急度；需要近身的协助休眠或手中食物转移会先形成可达的会合动作，真实同地后才执行。亲代只有在会合后存在可执行帮助时才接近，不能只因共同乱纪元追逐一个已经不适合安全休眠的移动目标。1–11 岁孩子的普通任务不能通过连续局部目标逐步漂出当前可见亲代的本地照护半径；水分低于 32、营养低于 34、健康低于 45 或已有冷热状态时，可把当前可见亲代编译为本人的危机会合目标，并以 `caregiverRef` 记录。未满 1 岁、清醒且真实同处的婴儿可由亲代携带去取水、找食物或进入住所；满 1 岁后，孩子不会因为亲代移动而被批量带走。视野外亲代位置、同步跟随和传送都不是合法来源。`carriedPersonIds` 只记录这类婴儿；休眠者若未来需要运输，必须通过独立、可审计的搬运能力实现。

自主选择使用轻量的因果 BDI，不再把不同语义的九类分数直接相加成一棵固定规则树。一次评估按以下顺序进行：

```text
局部可感知事实 + 合法 ActionOption
→ 动态 NeedAgenda（身体、安全、照护、储备、能力、承诺、归属、延续 / generativity、自主、探究）
→ HEXACO 人格门控注意、风险、坚持、探索、社会接近与伤害抑制
→ 召回同一语义动作、且在社会行动中优先匹配同一目标人物的结构化亲历记忆
→ 读取本人的 ActionFact 动作经验与 Intent goalOutcome Beta 目标后验
→ 对候选形成 OptionAppraisal，并与本人的当前 aspiration 比较
→ BDI 保持或改换唯一 active Intent
→ 项目步骤编译 / 动作重编译 / 领域合法性重验
```

需要强度使用有界饱和函数，多个需要使用概率并集；人格、经验、关系、重复、伦理、可行性和意图连续性是有明确语义的乘法门控，不再共享一个可以任意互相抵消的总分单位。`decision-factor-forest.ts` 仍把 need、care、commitment、learning、relationship、social-repetition、consent、feasibility、harm 投影成带理由和来源的诊断值，供旧报告和定向测试读取，但规划器不累加这些值。稳定种子值缩小到万分之一，只处理真正等价候选；所有候选都没有跨过当前 aspiration 时，人物明确保持空闲。必须回应和已生效职责仍是候选集门禁，不与普通候选靠超大常数竞争。

`belonging` 表示尚未被真实社会关系满足的归属缺口，不把每个可见熟人都当成一份新的、完整孤独压力。仍在生效的共同生活协议按“已接受 / 已建立”、本人对对方的 trust / bond / fear，以及本人当前是否位于双方约定的生活区，连续形成有来源的满足度；多项关系按剩余缺口组合。它只削减未满足部分，不删除结伴或陪伴候选，也不把一段关系视为永久满足。关系破裂、恐惧上升、离开共同生活区或出现新的真实孤立事实时，归属缺口会随当前状态重新出现。该满足度不能激活 `generativity`，更不能直接产生生殖意图。

空间接近分为语音与身体两层。普通 `voice communicate` 允许听者处于水平相邻一格、站立高度相差不超过一级的位置；接受 / 拒绝提议、交换与许可协商、明确教学和有来源生活谈话都使用这条边界。双方更远时，计划编译器从听者周围的可达站位中优先选择占用更低的相邻位置，不再默认移动到听者的精确 `cell / z`。物品交付、照护、生殖、施力和携带等身体动作仍要求精确同一站位，语音可达不能替代近身合法性。

精确站位超过两名存活人物时，本人会形成有界的 `spatial-comfort` 柔性需要，并获得一步移动到附近更低占用站位的候选。它不扣健康、不强制弹开人物，也不属于可以打断项目或必须回应的急性压力；生存、身体照护、协议履约与真实工作仍可优先。两人同位不产生这项压力，住所容量、人口承载和生态资源竞争也继续由各自规则独立计算。

`reserve` 需要按资源分成食物与饮水两个独立缺口，`homeostasis` 也按健康、水分与营养分维。人物已有足量食物但没有可饮用水时，只形成饮水储备与低水分压力；食物候选只能缓解食物储备或低营养，饮水候选只能缓解饮水储备或低水分。取得型候选只有在本人缺少对应可摄入库存时才承接身体压力，任一资源都不能借用另一资源的数量或身体紧迫度取得虚假的动机。项目产生的需要还精确绑定 `projectId`：公共储备项目可以提高自己的贡献步骤，但不能被普通采食候选冒领。

当前 `Intent` 就是 BDI 的唯一 intention 事实源，人物状态不复制第二个“想做什么”。有进度、仍可执行的意图不会在每个 tick 被重新抽签；尽责性、实际进度、项目压力和本人对目标达成的成功预期共同形成承诺惯性。只有目标到期、严重身体 / 安全 / 照护需要、持续停滞或明显更强且不同的合法候选，才允许改换意图。required response、生存反射、履约和有源生活复核继续按各自硬边界形成可返回的临时中断。

结果学习只发生在领域层已经提交真实 `ActionFact` 之后，但“动作合法执行”与“意图目标达成”分层记录。`OutcomeBelief` 从 completed / progressed / blocked / failed 动作更新预计努力和伤害；`Intent.goalOutcome` 另以 achieved / attempted-unmet / not-evaluated 结算，并更新 `GoalOutcomeBelief` Beta 后验。候选的目标成功预期只读后者，不再把一个成功执行的原子动作当作长期目标已成功。因此生殖动作已真实取样但未受孕时，`ActionFact` 仍是 completed，而妊娠目标是 attempted-unmet；若在产生任何真实受孕样本前就被硬条件阻塞，则记为 not-evaluated，不污染目标后验。

绕过普通动作执行器的生命周期终局也必须结算 `goalOutcome`。直接死亡会终结人物当前及全部暂停意图；脱水休眠恢复若发现人物死亡，或目标项目已经完成、阻塞、放弃或缺失，则按已有真实样本写入 achieved / attempted-unmet / not-evaluated，并清理对应中断边。只有确实重新恢复为 active 的意图暂不结算。

动作与目标 basis 都排除临时 option、intent、project、cell 和 person ID，并只保存本人有来源的有界亲历。无位移的同格 `move` 只是引擎 bookkeeping，不进入后验或结构化因果记忆。旧 schema-v17 人物在恢复时补为空先验；这不是全局训练数据，也不会把一个人物的经历广播给别人。

`NeedAgenda` 的 `generativity` 表示把当前生活余量转化为一次可撤回的家庭选择，不是“完成项目就想生育”的奖励。家庭准备度只读本人当前可感知的食物与水、真实可达且有可见空余位置的住所、已有照护余量和冷热 / 可信乱纪元预言形成的气候安全；住所质量重新由当前体素几何的 `weatherProtection` 与 `thermalInsulation` 测得。只有本人当前可见、真实存在且确认未被占用的住所内部位置计入 shelter readiness；记忆中的远处住所只保留为未验证地点的来源说明，对 shelter 分量贡献 0，不能证明当前家庭容量。

对正向生殖，`belonging` 与 `autonomy` 都不进入 `needActivation`，只有 `generativity` 能产生激活；关系、人格、同意、恐惧和风险只在激活成立后连续门控与排序。拒绝或撤回仍可由 `autonomy` 驱动，家庭准备度不足也不会删除这些自主退出选择。

一旦本地或模型重选实际选中生殖方向，对应 `DecisionFact.reproductionEvidence` 会冻结该次 appraisal 的 `generativityUrgency / needActivation / motivation / aspiration / relationshipGate / readinessGate`、家庭准备度分量和来源事实。家庭准备度若引用大量建造、储备或照护历史，事件只保留均匀覆盖完整集合的最多 32 个来源样本，并另存 `sourceFactCount`；完整事实仍留在权威事件史中，不能在每条决策里再次无界复制。它只用于解释“当时为什么这样选”与实验审计，不进入下一次候选排序，也不允许投影层倒灌新的需要。

项目完成只给交付最后一个功能性完成动作的存活人物留下一条 `NeedResolutionEpisode`；其他协作者的共同完成记忆不等于本人观察到需要被解决。该 episode 在 12 个月内只对同 `need + desiredFunction` 的新项目提案压力提供线性衰减、最多 45% 的暂时缓解；在家庭判断中它只追加解释性的 basis / reason / source，不改变 readiness 数值，绝不补造食物、水或住所，也不能单独重开一段已被拒绝的生殖配对。

`social-repetition` 不是固定月份冷却，也不从候选集中删除可选社交发起。人物只查看自己仍保留的沟通记忆：若最近曾向同一受众谈过同一语义主题，而当前 `sourceFactIds` 相对上次 basis 没有新增事实，就降低再次开口的预期价值；上次未回应、拒绝、保留或违约时降权更重。出现本人可追溯的新事实会解除这项负票并提供有限的新颖度正票；即使没有新事实，与求助、照护或困境主题直接相关的身体状态显著恶化，也可能以生存急迫度抵消重复成本，不能用无关人物的危险抬高交换、生殖或共同体邀请。

这项软排序不替代社会协议的硬验证：同一协议 ID 不能重复建约，每位必需回应者只能接受或拒绝一次，同一生活对话 basis 只能开场一次，同一开场也只能回应一次。换一个临时 ID 但继续引用同一组事实来源，不会被视为新证据；必须回应和履约候选不进入 `social-repetition` 投票。

人格不是额外奖励项，而是六组有界认知参数：开放性调节未知结果下的探索，外向性调节主动社会接近，情绪性与宜人性调节照护、避险和冲突预期，尽责性调节持续投入、时长和切换成本，诚实—谦逊调节未授权占取与强制伤害的抑制。人格不能通过门控绕过候选合法性；高诚实人物在极端求生压力下仍可能取物，低诚实人物也不会在没有机会和收益时凭空偷窃。

结构化提议、预测、教学和回应本身就是完整动作，不强配第二个物理行动。只有有事实来源的生活对话开场，且后续行动与它共享同一人物、项目或来源事实时，才允许组成“先说、再做”的复合意图；记录使用是独立的主候选 / 子中断，不进入通用生活对话 follow-up 候选池。

开局不调用模型。每局按种子从人物档案池确定性抽取 5–12 位先民，也可由配置显式指定最多 12 位；共同抵达事实必须列明全部参与者。所有先民在第一个 planning tick 由本地规划器获得首个可执行意图。

## 5. 计划编译与动作模拟

模型或人物理由都不能直接引用临时 `optionId` 作为长期语义。运行时没有独立的 `GoalSpec`：长期目标直接使用 `ActionOption.goal` 和入选 `Intent.goal` 中的稳定 `FactPredicate`，目标实体使用 `WorldRef`，来源继续保存在 `sourceFactIds`。复核月份属于 `Intent` 生命周期，不另造一套目标 schema。

本地计划编译器把目标逐步展开为五种原子动作。提交前的 Action Simulator 只使用世界规则进行短视窗预演：

移动以每个规划刻度 2 点地形成本为预算。普通平地每条相邻边成本为 2，因此每刻度前进一格；夯土和木板路面成本为 1，连续道路可在同一刻度前进两格。高成本地形至少允许跨过一条边，避免永久卡死。一个 `move` 仍只沿四邻连续路径执行，`ActionFact.pathSegment` 保存全部中间格，体力、代谢与踩踏按实际累计成本和经过格结算；规划耗时使用同一预算规则。

- 目标是否仍存在且本人能够知道；
- 是否可达、是否需要先移动；
- 材料、工具、授权、身体和空间是否满足；
- 当前动作是否会产生负库存、越界、远程作用或其他非法状态；
- 是否需要先吃喝、恢复、取材或选择已知替代方法。

动作模拟器不预测完整社会未来，也不让模型判断合法性。它只保证眼前计划可执行并能留下明确失败原因。

多人项目先在局部候选阶段检查功能、受益者、目标知识和场地是否重叠，在实际提交 `ensureProject` 时再对当前权威项目重验。若同一 planning tick 中较早人物已经建立等价项目，后到人物不会另开工地：现有项目合并新受益者与触发事实，人物意图的 `projectId` 与 `project-completed` 目标一并重绑。非所有者若因同月合并暂时没有可编译步骤，只等待这个创建月；下一月仍无步骤才按真实失败处理。只有空间上不重叠的远方项目可并行。

材料协作请求是项目内的追加式事实，不维护可漂移的状态字段。当前实现只为固定场地的 `alloy-capability`、`iron-capability` 与明确的 `civic-coordination` 项目开放；请求的 `open / fulfilled / expired / contributors-unavailable` 每次从期限、当前材料缺口、收件人存活与库存、以及精确引用该请求的转移事实派生。转移数量同时受请求余量和项目当前缺口约束；固定冶金项目的贡献者把材料送到可核对的作坊工位，而不是追逐移动中的 owner，owner 再以真实取物接续生产。旧请求已履行、到期或无人可交付后，新的真实缺口才能产生续发请求。项目同步先检查客观完成证据，再处理所有者死亡，避免把已经完成的项目误记为放弃；旧搜索只有在与当前缺口材料集合一致、发生于最近进展之后且没有协作者、休眠、当月产物落地或作物生长等待时，才会使项目明确阻塞。纯材料搜索或实体假说进入终局失败时，还会冻结 owner、desiredFunction 和人物当时可感知的机会依据；后继项目必须带有此前不存在的精确材料来源、与功能相关的可靠技术、新目标环境或新 verified response，并把 renewal 绑定到实际首步。项目 ID、月份、压力、移动和同一来源的转移 / 改名不能充当新机会；从未发生搜索 / 假说终局失败的普通 construction 不受该重开约束。便携产物的完成证据还必须来自 owner 当前目标材料栈的来源事实与本项目 `actionEventIds` 的交集；旧项目留下的同材质产物和可跨项目复用的可靠技术本身都不能让新项目即时完成。

耐久记录项目先在预先固定的场地取得或制造空白载体，再由项目所有者写入目标知识。只要所有者背包中已经存在与本项目所有者、目标知识、写入动作和载体栈精确对应的已写记录，下一项目步骤就优先返回固定场地并投放到精确地面，不再先续跑旧的搜索 / 物流 episode；若还没有合格已写载体，原制造与物流顺序保持不变。成功投放仍通过既有 `project-completed` 事实关闭项目。普通 `combine / exert / expose` 的候选与领域扣减都不得消费带 `recordPayloadId` 的本人库存栈；空白载体仍可被写入或用于其他合法动作，擦除 / 回收需要未来另设明确动作。

水流机械动力遵循同一感知边界。世界把河道中的有向 `water current` 段及其上下游关系显式持久化，但段的当前可用性每次都从 Water 体素与上游连通性派生；一个人物必须在本人视野和可达范围内完成对具体段的 `attend`，才能把它作为本人的来源事实。普通 Water、他人的观察或观察器标签都不能代替这一步。

死亡善后也沿用同一因果边界。普通死亡结算先生成与死者一一对应的遗体，并把其背包变成标有原主人和死亡事件来源的地面遗物；不会把遗体伪装成可加工材料，也不会向全体人物广播死讯。三日凌空汽化是明确的终局例外：死亡事实引用同一灾变来源，随身库存被销毁且不生成遗体或遗物。人物只有局部看见普通死亡留下的暴露遗体或有标记的墓穴，或者听到引用同一死亡事实的当面对话，才形成带来源的丧亲经历。关系强度、情感性、宜人性与尽责性只调节已经成立的悼念和照料候选，不凭空产生死亡知识。远处未成年子女即使已经客观死亡，也不会因全局 `diedAtMonth` 自动从亲代的 `reproductiveResponsibility` 中消失；亲代必须先取得引用该死亡的丧亲来源，责任才释放，且仍不能读取远处子女的身体状态。

安葬不是一句叙事，而是可重编译的物理动作链：`lift → prepare-grave → place-in-grave → cover-grave`。挖墓必须命中可达、未占用的真实地表体素，移出的材料成为精确来源栈；覆土只接受这次挖掘产生的同材质栈，并引用死亡、挖掘与入葬事件。墓记必须在完成安葬后真实消耗空白 `WoodTablet`，并要求至少石器等级的生产工具。观察器只从这些已提交事实识别死亡照料实践或制度，不能替人物选择墓址或补造墓碑。

机械动力压力只从人物本人已经完成的真实 Mill 辅助谷物分离劳动产生；由此建立的 `water-powered-crop-processing` 项目只是对当前可见工地的试建假说。计划冻结具体水流源、几何、项目和网络身份，却不把部件配方、时代门槛或预期文明阶段透露给人物；未知的 `WaterWheel` 与 `DriveShaft` 方法仍须经过既有的有预算盲试、制造和验证。

项目的物理链必须保持 `Water endpoint → WaterWheel above endpoint → horizontal DriveShaft → new Mill` 的严格直线拓扑。首次完整 commissioning 试运转确定性产生 `commissioning-misalignment`：该动作记录为 `progressed` 而非终止性失败，输入 Seed 保持不变，连接轴进入 `BrokenDriveShaft`。修复必须引用故障后新制造并验证的 `DriveShaft`，并真实使用 `BronzeTool`；只有随后完成带输入来源的 `Seed → Food` 作业，安装、故障、修复、运行与完成引用全部闭合，项目才结束。失流、错源、错计划、错工地或拓扑不符都在扣减前拒绝。这个闭环只支持受限的水力机械作业，不能被解释为电力、信号、计算或信息时代。

## 6. 分级修复

失败处理固定为：

```text
一级：局部规则修复
  重算路径、靠近目标、补材料、恢复身体、重新选择同目标的已知方法

二级：本地重新规划
  保留长期目标，替换当前子目标；或在目标客观失效时选择其他目标分支

三级：可选模型建议
  实时会话可在筛中的关键重评点请求候选内重选；事实提交后可生成台词或叙事投影
```

一级和二级不依赖网络。实时关键决定会先保存本地回退，再进行有上限的模型请求，并在同一只读上下文中重新验证；失败或不合法时采用回退。台词、即时纪事和长程叙事增强都发生在规则事实提交之后，只进入投影或旁车 artifact，不成为下一规划刻度的隐藏建议。

失败记忆不再靠 option ID 或摘要文字阻止重试，而从原意图重建稳定的结构化 basis：动作、目标、数量、人物、项目、记录使用和关系 basis 都参与比较。失败发生后的第 0–6 个月内，只有同一 basis 且没有新增来源事实的候选被冷却；第 7 个月自动恢复。新来源、新目标、数量、人物、项目、记录或关系任一变化都会立即重开；必须回应与履约永远绕过这项冷却。无法从旧自由文本失败记忆还原结构 basis 时按 fail-open 处理，不让历史文案永久封死合法行动。

生存反射、依赖者照护与避护维持不是项目失败。人物已有项目时，这些动作会形成有类型的临时子中断，完成后返回原父意图；被保护性中断占用的月份不计入项目停滞。本人风险与孩子风险先换算到同一紧急度尺度，再决定本刻度优先处理哪一项，而不是固定“本人永远在前”。

新的记录使用候选严格属于读者本人：只有本人拥有的活跃项目存在真实技术缺口时才生成，候选来源只检查本人背包和调用方已按局部感知过滤的可见公共地面掉落物，不遍历他人背包、知识或活跃意图。v2 basis 冻结读者、项目、payload、技术与精确载体来源（本人库存栈，或地面 drop + cell + z）以及是否必须取得；它作为可返回父项目的子中断执行。地面来源的正常链是 `move → acquire → read → experiment`：移动本身不算取得，只有从冻结的精确掉落物成功转移到读者本人背包才计为 `acquire`；来源消失、换 payload 或换位置时拒绝继续，不自动切换其他载体。阅读把技术知识保持在不高于 54 的暂定范围，随后只有同一真实项目输入上的成功实验才增加 18 并形成项目进度；明确直接教学仍可直接达到 60，且能正常结束子中断并恢复父项目，但不会伪装成完整记录链。人物本月已经复核过时，只有真实 preview 确认的记录机会才能再次唤醒规划；同 tick 新提交且点名本人的结构化提议会加入只读事件 overlay，使 required response 仍先于记录使用与生活复核。

若外部行动已把冻结地面来源的同一谱系载体真实交付给读者，或读者此前已读过同一记录，重编译可按当前真实持有与知识状态继续后续步骤；观察器不会补造未发生的 `acquire` 或 `read`。事实报告仍保留原始阶段与独立违规计数，但完整链只接受通过读者 / 项目 / payload / codebook、精确取得、阅读理解与可靠度、实验产物与 `+18`、顺序以及项目进度全部守卫的动作；缺失阶段的 basis 不计完整链，普通移动与无记录语义的复合对话也不计记录动作。v1 的 `share / read-experiment` 持久化意图仍按动作语义恢复。

人物对下一纪元的预测只能读取已经发生的纪元转换、当前纪元已经持续的时间和本人认知能力。调度器内部尚未发生的 `endsAtMonth` 不属于人物事实，既不能进入候选，也不写入当期气候事件。

## 7. 当前模型入口

后端已经落地“已发生事实的叙事增强旁车”，接口与持久化格式见[非阻塞叙事增强旁车](../three-body/design/non-authoritative-model-enhancements.md)；实时单月会话也已接入少量候选内关键决策、完成口头沟通的台词投影、后代取名、事实纪事压缩，以及玩家从人物页发起的模型对话。玩家可在模型设置页（`M`）分别把当前文明切换为本地 / 模型演进与本地 / 模型总结；主动人物对话始终按需调用 `interaction` 路由，不受演进模式开关影响。后台长程演化不调用模型。`strategy` 目前只是端点配置扩展位，没有可执行的文明策略任务队列，本文不为它保留伪接口。

### 7.1 玩家交互

玩家在人物页打开“对话”子 tab 后，可以询问身体、当前动作、私有物品、记忆、关系和计划，也可以在自然交谈中提出请求或劝说；界面不要求玩家预先区分“聊天 / 建议”。服务端先从本轮玩家原话保守判定 `actionChoiceRequested`，模型不能自行把纯问题升级成行动请求。输入使用带 `sourceId` 的局部语义事实而不是原始引擎 DTO：位置只投影成“同一位置 / 身边 / 近处 / 视野较远处”，容器与未完成建筑分开，当前可行方向不能冒充永久技能。事实性回答必须回传实际依据；人物没有来源的概念必须保持“不知道”的认知边界，但由 Soul 决定自然措辞。人物回复本身缺端点、超时或非法时显示错误；后续隐藏意图解析失败只放弃本轮行动影响，不丢弃已经生成的回复。等待只阻塞这次交互，不阻塞世界时钟。

主动对话拆成两个独立协议。`agent-interaction-reply-v1` 只让人物按“身份与代词、权威事实、本轮回复、表达与输出”生成自然 `reply + grounding + evidenceIds`；解析器会忽略模型误带的旧版 stance / choice 字段，不让无关意图格式拖垮合法回复。人物状态、Soul、记忆、亲缘、证据和合法选项只放入每轮 `localContext`；历史仍按 user / assistant 角色传入。服务端还会在同一次请求前本地派生 `communication` 与 `personaFrame`：前者把年龄和 communication 能力转成实际句式限制，后者只从 Soul 中选择一个与本轮处境最接近的 scene facet，并引用已经筛出的记忆 sourceId；这不是额外模型调用，也不写入 `PersonState`。只有服务端已确认玩家明确提出行动请求时，才追加一次不对玩家显示的 `agent-interaction-intent-v1`：它只读取本轮玩家原话、已经生成的角色回复和当时合法候选，把回复中明确表达的接受、犹豫或拒绝提取成结构化结果，不得续写回复或凭空补承诺。

玩家在所有人物面前拥有稳定的“主”身份。玩家对自己身份、意图、感受和偏好的陈述是一手信息，其他话语是本轮必须回应的输入；“必须回应”不自动等于信任、亲近、服从、耐心解释或接受建议，具体态度仍由人物 Soul、相关亲历与处境决定。玩家话语中的“我 / 我的 / 我们”固定指主，“你 / 你的”固定指当前人物；人物回复中的“我 / 我的”固定指人物自己。“我是谁”类问题的身份事实由本地协议限定，但具体回答仍由人物按 Soul 自然表达。旧版未携带 grounding 和 evidenceIds 的自由回复仍保留在界面与持久化记录中，但不再回填给模型。

“主”是模型交互协议中的稳定关系，不是未经模拟产生的世界内关系数值，也不把玩家对世界的陈述变成客观事实。`actionChoiceRequested=false` 时，局部上下文不暴露其他人物尚待回应的 required option，也不触发隐藏意图调用；第一阶段即使误带行动字段，也只取合法回复字段，不会形成 choice。只有服务器确认玩家明确提出行动请求后，人物才按 Soul、人格、需要、记忆、承诺、风险与处境独立判断，并只可在自然回复中承诺本地已提供的合法方向。隐藏解析得到的 `choice` 仍须经过当轮和最新状态两次本地校验，不能创造行动、物质、知识或已经发生的结果。

父母、子女和同父母 / 半血缘兄弟姐妹从权威 `geneticParents` 谱系稳定投影到 `person.kinship`，不占用也不依赖会衰减的事件记忆。记忆仍只保存有来源的经历、对话、承诺、失败和摘要，例如“某人教过我什么”；教学、伙伴等经历关系可以与亲属身份同时成立。历史对话只证明人物曾经那样说过，不自动升级为世界事实；旧回复与本轮结构化谱系冲突时，人物应依据当前事实自然纠正。未出现在亲属投影、可见人物或有来源记忆中的关系不得按同姓或档案描述猜测。

`PersonState.traits` 是另一类出生权威事实：先民按人物 ID 固定；新生儿从亲代的可遗传特质中确定性抽样最多三项，并以独立种子样本取得最多一项不遗传的随机异变，之后不再变化。出生事实同时保存遗传和异变概率、样本、资格与截断原因，旧存档补全不倒灌异变。特质可以改变本人的寿命、出生能力、身体结算、记忆预算、婚育窗口和有来源的配方知识，但不能读取全局地图、观察器或他人私有事实。魅魔只为成年女性创建有来源的单方生殖候选：它绕过关系、双方协议、家庭准备度、通常的年龄上限与 55 点身体储备门槛，但仍受在世、异性、同地、成年和本人未妊娠等物理事实约束，动作明确记录为单方授权且分娩后不创建产后恢复；双生把同次妊娠结算为两个独立出生事实并提高妊娠中止风险；饕餮把五项基础能力各提高 20，同时令月度营养消耗乘 1.5。先知在出生时掌握全部当前规则配方，仍必须取得材料并通过正常项目、空间与动作合法性；母脉的姓氏、遗传、母子羁绊和首次母亲技术教学也必须写入出生或真实教学事实。完整规则和固定配置见《人物特质 v1》。

主动人物对话、决策阶段的 `utterance` 与事实提交后的 speech-only 台词共用同一个只读 `PersonSoul` 人格派生值。Soul v2 由人物 ID、baseline HEXACO 和控制 / 地位敏感度确定性重建，除第一人称内在自述外，还把句长、语域、直接程度、自我暴露、比喻与犹豫拆为稳定 `styleMatrix`，并提供危险与失去、自主与提议、信任与亲近、承诺与工作、未知与变化五个可由处境命中的 `sceneFacets`。每次表达只激活最相关的一个侧面，避免把全部人格平均成统一的礼貌说明；有效人格、身体、关系、记忆和处境仍作为每轮动态语境。Soul 可以参与主动建议对话中的接受 / 拒绝和当前合法 choice，也可以参与可选模型在当前合法候选之间的自主权衡；但它不进入 `PersonState`，不成为新记忆、知识、需要或价值奖励，不能创造候选、绕过领域校验或直接写世界。档案原型与外貌描述不能覆盖本局结构化人格，更不能给人物注入原作身份、历史、物品、技能或知识。

人物只有在自然回复中已经明确接受玩家请求，且隐藏意图解析唯一选中当前合法 `choice.optionId`（以及需要时的 `followUpOptionId`），才为当前分支留下一个待落实选择；普通回答、犹豫、拒绝以及解析失败都不进入行动链。服务端随后按当时与最新提交状态各做一次本地校验，并把组合后的目标、动作、对象、项目和关系语义保存为稳定 choice key，排除月份戳、临时 representation ID 与过期时间。下一次人物可行动时不会再调用模型重新决定，只在最新合法候选中按原 ID 或稳定 key 唯一重配：命中后提交带 `sourceInteractionId` 的 DecisionFact；紧急生存、必须回应或履约优先时保留为 `deferred`；候选消失、后续动作失效或匹配不唯一时记为 `blocked` 并保存具体原因。人物卡随后从真实 Intent 状态和 `actionEventIds` 持续投影“已经定下 / 已经开始 / 被打断 / 已做成 / 后来停下”。

实时人物自主对话也由 `decision` 路由表达，但分为两类请求。有多个合法方向时，模型可重选 option 并同时给出台词；不需要选择、或在后续 planning tick 才实际发生的说话，规则先提交 completed `voice communicate` ActionFact，再进入独立的 speech-only 批处理。两条路径中，参与者、沟通类型、结构化立场、提议内容、事实来源和后续真实行动均由规则固定；规划摘要只是行动标签，不是可复制的对白模板。模型措辞不能改变 `accept / reject` 立场；若改变、缺失或校验失败，该沟通不显示文字气泡。

### 7.2 表达与叙事

模型可以提出名称、故事、符号、仪式、艺术表达、假说或新协议草案，也可以为已经发生的重大事件补充人物视角。接受、传播和客观后果必须由真实 `communicate / attend / act` 及后续历史形成。

实时模型演进中的后代取名是一个受限例外：出生与所有身体、血缘、特质事实先由规则完整结算，并生成种子可回放的保底姓名；服务器随后只把孩子性别、规则已确定的继承姓氏与顺序、父母 Soul、父母近期有源经历和当前纪元气候交给 `naming` 路由，请模型返回 `givenName`。默认采用父系命名来源；任一亲代携带母脉时采用母亲姓氏、传统与姓名顺序。本地命名规则仍控制字符、长度、姓氏继承、姓名顺序、重名和一次性应用。合法结果在本月对外提交前替换保底姓名，并把保底名、提议缘由、端点、模型和 token 写入同一出生事实；非法、重复、缺端点、超时或请求失败时保留原保底姓名。回放不重新调用模型，姓名不进入人物规划评分；后台快速演化始终使用确定性保底姓名。

## 8. 实时重验与叙事旁车

实时决策适配器只接收人物可感知事实、当前意图和本地合法候选，并增加同一规则引擎生成的只读 `person.cognition`：当前最强需要、本人有界结果后验，以及每个合法 option 的 need alignment、成功预期、不确定度、motivation、aspiration 和来源理由。它是本地因果 BDI 的解释投影，不是隐藏世界事实或模型奖励。可选社交候选还会附带由同一领域函数计算的 `socialRepetition` 软成本、新证据与上次结果，使模型和本地规划器读取同一份人物记忆判断；必须回应、履约和非社交候选不携带该字段，模型也不能把它解释成合法性门禁。开局初始意图、身体危险和既定履约不进入模型重选。必须回应只在同时有两个以上合法 required option，或唯一 required option 需要 follow-up 且有两个以上语义匹配的合法 follow-up 时，才进入决策批次；单一固定回应直接由规则提交。其他生活对话、空闲人物新方向、项目停滞和状态复核也必须存在真实选择空间才可进入。模型返回的 option ID 必须仍属于同一上下文，生活对话的 follow-up 必须共享人物、项目或来源事实，随后才可创建 DecisionFact。意图保存稳定目标和来源，不把模型文本当成世界事实。

玩家建议中已经选定的 choice 是上述普通筛选的一个显式例外：它可以要求该人物在下个月边界进行一次独立、本地且不扣普通额度的重验，但不会再发起模型决策，也不豁免领域合法性。旁车同时保存当时 option ID 与排除临时月份 / 表达标识的稳定语义 key；原 ID 仍合法时直接采用，ID 更新时只有唯一语义匹配才能采用。必须回应或履约造成的暂缓会保留原选择继续等待；候选消失或歧义则停止并留下原因。同一人物的新 actionable choice 会使旧的未落实选择失效。对话、choice、结果与用量按分支持久化，热恢复和手动存档可以恢复；从旧月份创建新分支时只继承分叉月之前的对话，尚未落实的选择标为失效而不跨分支执行。

台词适配器只扫描本次实时月份中已经 `completed`、通道为 `voice`、且存在真实听者的 `communicate` ActionFact，并先投影不含显示文本的 `speech-act-v1` 草稿。草稿只保存沟通类型、话题、提议、引用、立场和来源；规则摘要不再作为可复用对白或文本相似度锚。尚无更细领域字段的客观陈述可把事实命题放在 `speechAct.subject`，但该字段只回答“说什么事实”，不提供“原话怎么说”。决策批次已为该动作提供合法模型台词时直接复用，其余草稿按月合并到同一 `decision` endpoint 的 speech-only 批次。请求中的有效人格、本月提交后的当前身体与状态、说话者对听者的当前关系、当前处境与经来源限定的近期经历全部是只读上下文，不是 action tick 精确快照。记忆先按当前 speechAct 话题与真实听者选取，再用承诺、失败和一般重要性补足；表达模型同时读取年龄 / communication 档位，只激活一个 Soul scene facet。服务端还根据当前 speechAct、宜人性、控制敏感度、饥渴与受伤压力、对听者的 trust / bond / fear，以及有源伤害、背约和“明确拒绝后的重复请求”计算只读 `relational-speech-frame-v1`；日常陈述默认使用 neutral，只有带请求、拒绝、撤回或边界意味的话语行为结合低宜人性、控制敏感或急迫压力时才进入 blunt，低信任通常先表现为 guarded；warm、familiar 与有证据门禁的 confrontational 仍可按关系和处境出现，但都不改变 speechAct。直接和短促不需要冲突证据，也不等同于不耐烦；打断、带刺反问、针对具体过错的敌意、羞辱、威胁或指责则必须与当前话语行为相称，并由 frame 携带的真实 friction evidence 开放。近期经历可改变语气、直接程度和情绪温度，但只有 ActionFact 已授权的 `sourceFactIds` 才能成为对话中对外声称的事实。

只有成功且通过沟通类型与结构化立场校验的模型台词才作为 `GameFrame.speechLines` 投影绑定原 ActionFact；普通陈述不再与规则句子做字面或相似度比较，可见来源只允许 `decision-model | speech-model`。请求既可用“请 / 能不能”等协商句式，也可用“把石头给我 / 走”等命令式或短促句式；校验器不再把礼貌词当成 request 的必要条件。关系姿态允许人物省略寒暄、共情和完整理由，但不能借语气变化改写提议对象、物资、立场或事实。台词不覆写动作的结构化 summary、result 或 diff，也不写入人物记忆、关系、知识、意图或文明纪事。只有规则动作本身可以通过领域后果改变这些状态。模型缺席、超时、返回数量不匹配、文本越界或立场冲突时，ActionFact 仍然成立，但本月不为该动作保存或显示文字气泡。旧快照中的 `source: rule` 也不会重新显示。

文明纪事先由 `projection/player-narrative.ts` 从已提交事件中筛选文明开端、纪元切换、重要天气、野兽袭击、死亡、出生、协议、关键技术和项目完成。死亡只有在其来源链中存在对象一致的袭击事实时才归因给动物；同月袭击已经被对应死亡吸收后不再重复列史。规则投影保留全部 `sourceEventIds`、涉及人物与可展开事实详情，模型总结只能压缩这组候选，不能补造死因、天气或社会结果。

长程运行的异步模型任务当前只有 `dialogue / memory / history` 三类叙事增强。它们保存来源事件、分支和运行 revision，状态为 `queued / running / completed / failed / stale`；结果固定为 `projection-only`。来源消失或分支变化时任务过期，失败可重试但不暂停模拟。它们不会产生 `DecisionFact`、意图或策略建议。

## 9. 模型预算

实时关键决定使用滚动额度：普通上下文至多约每 3 人月一个；必须回应可不占普通额度，但只有存在选择空间时才需要重选。玩家主动对话使用独立用量记录：回复阶段默认最多输出 8000 token，只有明确行动请求才追加最多 1000 token 的隐藏意图解析；两次调用用量合并记录。人物 choice 所触发的后续本地重验不调用模型，也不扣普通人月额度。这个额度不决定人物能否说话：每个实时月份完成的口头沟通都会被投影，模型演进下未在决策阶段获得台词的部分再进入独立 speech-only 批次。后代取名只在本月确有出生时批量请求一次，token 与端点元数据保存在出生事实中。月度 DecisionBudget 账本仍只记录普通候选重选的 endpoint、协议、模型、调用和 token，当前不累计主动对话、speech-only 或取名 token；人物对话记录自身 endpoint、模型与 token 用量。任何额度或基础设施失败都不能阻止规则世界继续推进。

玩家主动交互、speech-only 表达、即时纪事和长程叙事旁车分别控制请求与超时；快速演化可在完成后统一补写少量叙事，不把人口 × 月份变成外部请求数。

## 10. 记忆

短期记忆保存近期动作、失败、对话和承诺，用于局部修复。本人亲历的动作记忆还保存机器可读的 causal trace：稳定动作 / 目标 basis、结果、效价与后果标签；社会记忆通过 `personIds` 约束到真实参与者，不从中文摘要猜因果，也不把与甲的经历套到乙身上。独立的有界 `OutcomeBelief` 保存同一 basis 的尝试次数、Beta 成功后验、预计努力、预计伤害、最近月份和来源事实。长期人格由 `baseline + learnedDelta` 组成；行动后形成的 `PersonalityEvidence` 必须保存维度、方向、强度、情境键和来源事件。

```text
单次自愿行动 → 短期记忆 + 结构化人格证据
领域 ActionFact → 本人的结构化 causal episode + OutcomeBelief 更新
跨至少 3 个月、至少 2 个情境的同向高诊断性证据
→ 月末规则整合为 learnedDelta 的 1 点变化
→ 同一维度滚动 12 个月最多变化 2 点，累计偏移限制为 ±20
```

极端生存压力会降低一次伤害或未授权取物对长期人格的诊断性；生存反射、失败动作和行为缺席不直接构成人格证据。模型可以改写表达，不能在没有事件证据时直接修改人格权重或关系余额。

Soul 与长期人格分工不同：baseline 人格与稳定身份只读派生为跨轮一致的核心声音，`learnedDelta`、当前身体、关系与有源经历继续逐轮改变当下语气和具体权衡。模型只能内化 Soul，不能复述其提示或把它写回人物状态；它可以据此在已经生成的合法候选间形成个人取舍，但不能改写候选集、物理合法性、必须回应与履约边界，也不反写本地认知 appraisal。

生活对话使用同样的证据链。本地规则先从身体处境、实际照护、共同劳动、失败、发现和共同养育事件生成带 `sourceFactIds` 的定向开场，被点名者再引用该开场作出支持或保留回应。对话只有在两轮都通过参与者、来源和去重验证后，才能更新关系并成为后续结伴/生殖提议的关系证据。候选决策台词可读取决策时的有效人格、身体、关系与近期记忆；speech-only 台词则读取本月提交后的当前人格、身体、关系与有源近期经历。两者都只能用这些只读上下文改写口吻，不得更换话题、参与者、结构化立场或事实来源；改写文本本身不会再次更新记忆、关系或知识。

死亡消息使用 `loss` 主题走同一结构化沟通入口。说话者必须先持有该死亡的来源，听者必须在实际沟通范围内；动作完成后，听者才取得引用同一死亡事件的记忆和丧亲经历。未经感知或传话的远处人物不会因为全局状态里有人死亡而自动悲哀。

共同活动本身也会形成低强度、可回放的关系证据：两人必须在同一规划刻度都完成或推进非沟通行动，并在行动后真实同地；已经生效的结伴双方也可在同一稳定生活区的不同格形成这类日常经验。每个人按自己的有效人格把共同活动转成定向关系证据：有效外向性占 60%、宜人性占 40% 得到社会接近度，达到 65 时每 3 个刻度形成 1 份、达到 40 时每 4 个形成 1 份，否则每 5 个形成 1 份；每份使本人对对方的 `trust` 与 `bond` 各增加 1，因此同一段经历可以形成不对称关系。年轻只加速已经成立的信任证据：当月已有至少 1 份基础增量时，未满 16 岁额外增加 2 点 `trust`，16–29 岁额外增加 1 点，30 岁起无加成；这项月度加成不增加 `bond`，也不能在没有共同活动基础增量时凭空产生关系。15 个刻度下，每个方向单月最多形成 5 点基础关系；未满 16 岁的 `trust` 最多再加 2。事实保存双方各自的性格门槛、基础增量、年龄加成与最终定向增量。单纯同处、空闲、休眠、失败动作或只有一方行动不计；当月发生直接伤害、拘束或未授权取物时，那一对不获得这项正向积累。先民由共同抵达事实获得双向 `trust=55 / bond=55`。新生儿则只对出生事实提交时仍存活且精确同地的人形成一份单向、带出生来源的弱信任；数值由本人的有效宜人性与外向性确定，限制在 `3..9`，不增加 `bond`，也不给对方反向信任，异地或后来到场者不追授。这个起点仍低于结伴 `20 / 20`，只能让后续真实接触不再从完全无来源的零信任开始。结伴提议与接受分别要求本人对对方有来源的 `trust>=20 && bond>=20`。生殖不设固定关系分数：提议者必须拥有一段可追溯关系，但无需对方达到同一分数；随后提议、接受、拒绝、继续和撤回分别进入当事人的本地 appraisal。关系增长、恐惧、人格、照护责任与已知亲缘风险只连续改变偏好。照护、履约、对话和共同项目仍可依据各自事实改变关系。

结伴共同生活不等于同步位置。提议在发起地保存一个双方都知道的稳定 `sharedLivingAnchor`；双方在该生活区域内可位于不同可站立格，仍累计共同生活月。日常取水、生产、学习和旅行允许各自行动；只有当 24 个月约定的时间余量已耗尽、若不返回就无法完成 12 个月共同生活时，才生成返回稳定生活地点的履约候选，让尚未建立关系的已接受约定同样形成有来源的 commitment need，并进入既有 fulfillment 优先协议。返回目标是生活区内的可达空闲槽位，不是伴侣的实时坐标。共同体成员身份和“看见另一个人”本身都不生成持续追人移动；跨地交谈必须已有真实话题并绑定靠近后的沟通动作，照护、交付或共同项目也由各自具体行动形成有界会合。

共同体因成员死亡或退出只剩一名在世成员时进入 `dormant`，而不是抹除历史。仍有活跃成员身份的人可以邀请有真实合作来源的人加入；候选人和所有仍在世的既有成员明确接受后，成员事实立即成立并把共同体恢复为 `active`。没有任何在世成员的 `dissolved` 共同体不能用新邀请复活。

近亲繁衍也遵循同一原则。世界规则不把直系或共亲关系写成“禁止生殖”的非法动作，而是根据亲缘距离与双亲已有遗传负荷，确定后代的遗传易感性、初始身体和能力偏差、寿命压力及后续疾病概率。人物只有在亲眼经历体弱出生、反复疾病或能力衰退后，才形成带来源的短期记忆与“近亲后代风险较高”的个人认识；重复证据继续提高置信度。该认识从第一次有源证据起按置信度连续进入本地认知 appraisal，满置信度的亲缘成本仍保持在可与关系、照护责任和生活窗口共同权衡的软偏好尺度，不在 55 分处跳变为近似否决。每个合格伴侣都保留独立候选，由同一 appraisal 比较关系、责任与风险，不先用亲缘排序裁掉其他对象。认识可通过真实沟通传播，最终才可能涌现为亲族禁忌或婚配规范；模型不能预先注入这项知识。

生殖同意不是关系分数的永久开关。身体适格时，同一提议必须向回应者同时暴露接受和拒绝；一次明确接受形成最长四个自然月的可撤回尝试窗口。每个伴侣对每月最多完成一次真实尝试，未受孕只记录尝试，受孕、撤回或到期才结清协议。每个动作必须携带精确的有效协议引用，不能借另一份同时存在的反向协议重复采样。继续与撤回统一进入本地 `consent` 因果树，读取本人对伴侣的关系与恐惧、人格、已知亲缘风险、产后恢复和亲生未成年子女照护负担。伤害不会由领域层自动把旧协议改写成拒绝，而会降低受害者继续的偏好并提高撤回偏好；若当事人仍明确选择继续，领域层只重验协议、年龄、身体、恢复和同地等客观边界。每次真实尝试保存协议引用与双方当时的关系快照，便于回放判断自主链是否成立。规则不通过全局人口指标或硬编码孩子数量替人物决定。

## 11. 历史与回放

权威历史由更新后的 `SimulationState` 与追加的 `WorldEvent` 构成；新事件用 `planningTick / orderInTick / orderInMonth` 保存 15 个 tick 内的顺序和动作引用。实时分支时间线另外保存周期性 checkpoint、月间 delta 与可重建 `GameFrame` 的帧元数据；`society` 读取模型从对应状态快照重新投影。这些是恢复和播放编码，不是第二套领域事实。规则决策与动作仍是权威历史；模型任务、人物对话、待落实 choice 及其本地重验结果是分支内独立审计流，人物台词是绑定 ActionFact 的 `GameFrame` 表现投影。

回放：

- 不重新运行本地规划器；
- 不重新调用模型；
- 应用已提交的事件和补丁；
- 直接读取已保存的台词投影；旧帧没有 `speechLines` 时保持无台词，当前既不从 ActionFact 补建规则原话，也不补调模型；
- 分岔后从新的 branchId 继续本地规划；
- 已完成但尚未被接受的模型建议不自动跨分支生效。

文明演化程度使用《文明指数 v1》从人口、认知疆域/功能基础设施、科技、社会和历史五类事实派生。指数是观察层，不能反向为人物解锁能力。恒/乱纪元、天气、预言、脱水休眠和动物生态遵循《纪元、预言与生态 v1》，它们必须产生真实状态与后果，不只生成叙事。

## 12. 前后端迁移边界

本轮以后端长程演化为主：

- 后端 `/evolve` 和批量模拟必须使用规则优先主链；
- 实时单步与自动演化先运行本地规划，再允许通用模型协议适配器覆盖少量通过筛选和重验的关键选择；规则月提交后，完成的口头沟通才可增加只读台词投影；
- 前端旧路径不得被后端快速演化复用；
- 无论前端是否迁移，领域层都必须始终提供本地规划入口。

## 13. 多运行演化验证

规则修改不得只依据一次运行判断有效或无效。验证应按《文明演化双闭环与实验协议》选择与因果时标匹配的实验矩阵：多个配对种子、10/20/30 年中的一个或多个时长，必要时增加重复或更长的跨代运行。

本地规则完全确定时，相同种子重复只用于验证可回放性，不能冒充独立样本。基线与候选必须使用相同种子、时长、配置和模型策略；结论同时读取聚合分布、发生率、配对差异和代表性历史。单次运行只能暴露候选问题或提供因果案例。

## 14. 验收不变量

- 关闭网络和模型配置后，可从新文明推进至少 1200 月；
- 每个完整月份恰有 15 个规划刻度；
- 空闲且可行动的人不会因为没有模型额度长期保持无意图；
- 相同局部事实和候选下，HEXACO 或本人有来源的不同亲历可以改变自主 appraisal；反射与硬合法性不受人格绕过；
- 活跃意图在普通竞争候选出现时保持连续，只有到期、急性需要、持续停滞或明显更强的不同候选才替换；
- 真实完成 / 推进 / 阻塞 / 失败只更新行动者自己的语义结果后验；无位移 move 和模型文本不构成学习样本；
- 开局、紧急反射和履约不进入模型重选；必须回应始终拥有本地强制回应，无选择空间时只在事实提交后尝试台词增强；
- 模型决策请求超时或返回非法内容时采用预先计算的本地决定；台词请求失败时保留 ActionFact 但不显示文字气泡，月份不会回滚；
- 后代取名请求非法、重复、超时或失败时保留种子可回放的本地姓名；合法姓名只能改变人物称呼，并在出生事实中保存模型提议与本地验收来源；
- 模型只能在当前上下文引用临时 option ID；长期意图必须保存规则目标、来源和可编译动作，而不是把 option ID 当成战略语义；
- 每个完成且具有可解析真实听者的 `voice communicate` ActionFact 都产生一份结构化话语草稿；只有成功模型台词进入 `GameFrame.speechLines`，且不改变 summary、记忆、关系、知识或文明纪事；
- 每项客观变化都能追溯到规则动作和世界事件；
- 任意 10/20/30 年及更长快速演化的主循环不等待任何模型请求；
- 可在模拟完成后异步生成少量真实模型叙事，而不改变确定性历史。
