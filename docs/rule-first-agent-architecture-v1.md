## 1. 核心决定

Eland 是一个可以独立运行的确定性社会模拟游戏。大模型不是世界时钟、人物行动或规则裁决的依赖。

旧假设：

> 人物出现关键决策机会，就应尽量交给模型。

当前假设：

> 人物始终先由本地规划器获得完整可执行决定。实时会话把“选什么”和“怎么说”分开：只有存在真实选择空间的少量关键上下文可让模型从本地合法候选中重选；规则实际提交的每一条口头沟通，则在事实完成后以结构化 `speechAct` 交给模型自主表达。决策失败保留本地决定；台词失败保留沟通事实但不显示文字气泡。

因此必须满足：

- 没有 API Key、模型超时、模型返回非法内容或服务完全离线时，文明仍能从开局连续演化到终局；
- 后台快速演化、实验矩阵和动作提交不得等待模型；实时单月会话可在 planning tick 1 前为筛中的关键选择做有上限的等待，并在规则月提交后为已发生的口头沟通批量生成只读台词；
- 模型输出只能成为待验证的建议、人物表达或叙事，不直接成为世界事实；
- 快速演化的耗时主要由本地规则复杂度决定，不随人口 × 月份线性增加外部请求；
- 已提交月份从 DecisionFact、ActionFact 和已保存的 GameFrame 投影回放，不重新调用模型；从旧月份创建新分支后，后续模型选择与台词属于该分支的新输入。

## 2. 三层权威

```text
世界层（唯一事实权威）
  物质、空间、身体、资源、关系、承诺、知识、时间和后果

本地人物层（行动权威）
  反射、目标组合、效用评分、计划编译、动作预演、局部修复

模型层（非权威增强）
  长期战略建议、玩家对话、创造性提案、绑定已发生动作的人物台词和历史叙事
```

世界层和本地人物层必须独立闭环。模型层可以缺席。

## 3. 时间：每月 15 个规划刻度

“月”仍是存档、人口、身体状态、环境过程、历史索引和 UI 日历的最小权威时间单位，但不再是人物规划与执行的最小单位。

```text
1 月 = 15 个 planning tick
```

每个规划刻度代表本月可辨认的一段行动机会。它不是固定天数，也不向 UI 承诺现实日历；15 只是当前动作密度与性能之间的规则常数。

月度流程：

```text
月初环境与协议生命周期
→ planning tick 1
→ planning tick 2
→ ...
→ planning tick 15
→ 月末身体、状态、人口和观察器结算
→ 提交 MonthRecord / MonthFrame
```

每个 tick 对每位仍可行动人物执行：

1. 读取该 tick 开始时的局部感知与身体状态；
2. 优先执行吃、喝、逃离直接危险和依赖幼儿照护等确定性反射；
3. 检查当前长期意图是否完成、失效、受阻或需要局部修复；
4. 若无可执行意图，本地规划器立即选择一个合法目标；
5. 把目标编译为下一项原子动作，并在提交前预演其前置条件；
6. 先用廉价规则补移动、材料、恢复或替代目标；
7. 执行至多一个原子动作，写入真实路径、成本、结果和来源；
8. 下一人物读取已经提交的当前世界；稳定执行顺序写入历史。

人物不必每个 tick 更换长期目标。3～12 月状态目标仍可持续，但引擎每个 tick 都有机会推进、修复或在客观失效时改换手段。

## 4. 本地规划器

本地规划器不是占位 Mock，而是正式游戏系统。它的输入只有人物可获得的事实：

- 当前身体、状态和行动限制；
- 眼前可见对象与有来源的记忆目标；
- 当前长期意图及最近成功/失败；
- HEXACO 人格、控制/地位动机敏感度、关系、承诺和共同体职责；
- 引擎生成的合法可供性；
- 时间、距离、材料和风险的粗粒度估计。

它维护四个目标分支：

```text
survival    生存、健康与直接安全
production  采集、储备、建造、耕作、制作与维护
social      照护、合作、交换、承诺、冲突与共同体
inquiry     探索、观察、试验、学习、记录与表达
```

目标分支不是四个同时执行的计划。人物在任一 tick 只有一个当前执行焦点；其他分支保存需求压力、未完成目标和最近进展。

候选生成是只读预览：项目下一步可以在私有快照中试编译，但只有人物真正选择该候选，搜索 campaign、物流 episode、计划知识和项目状态才允许写入权威世界。年龄门禁也在每次候选编译内部执行，不能只依赖月初过滤。

年龄门禁按已经过完的月数判断，并同时约束候选与移动归属：

| 年龄 | 规划能力 | 移动规则 |
|---|---|---|
| 未满 1 岁 | 不进入普通规划，只接受照护和身体结算 | 清醒且与亲代同处时，可由亲代的一次移动携带；脱水休眠时保持原位 |
| 1–11 岁 | 可在跟随、取水、拾取、采收、拾柴和观察学习中自主选择 | 普通目标须留在当前可见亲代的本地照护半径内；严重压力时可走向当前可见亲代；每次移动仍来自本人的合法行动 |
| 12–15 岁 | 可生产并参与既有项目，不能发起重大项目或繁衍 | 与普通人物一样提交自己的移动 |
| 16 岁以上 | 完整规划能力 | 与普通人物一样提交自己的移动 |

“照护关系”不等于“同步位置”。亲代可从视野内 12 岁以下亲生子女的真实位置与身体事实判断紧急度；需要近身的协助休眠或手中食物转移会先形成可达的会合动作，真实同地后才执行。亲代只有在会合后存在可执行帮助时才接近，不能只因共同乱纪元追逐一个已经不适合安全休眠的移动目标。1–11 岁孩子的普通任务不能通过连续局部目标逐步漂出当前可见亲代的本地照护半径；水分低于 32、营养低于 34、健康低于 45 或已有冷热状态时，可把当前可见亲代编译为本人的危机会合目标，并以 `caregiverRef` 记录。未满 1 岁、清醒且真实同处的婴儿可由亲代携带去取水、找食物或进入住所；满 1 岁后，孩子不会因为亲代移动而被批量带走。视野外亲代位置、同步跟随和传送都不是合法来源。`carriedPersonIds` 只记录这类婴儿；休眠者若未来需要运输，必须通过独立、可审计的搬运能力实现。

排序使用“可解释决策因子森林”，不是由离线样本训练的黑箱随机森林。每个候选同时交给九棵相互独立的因果树评估：

```text
need          本人的身体、物资、住所与可观察缺口
care          眼前他人的身体危险、亲缘与照护关系
commitment    既有项目连续性、项目压力与明确复核点
learning      观察、知识、实体记录与项目技术缺口
relationship  有来源的关系、信任、羁绊、恐惧与社会接近倾向
social-repetition  本人记忆中的同受众同主题沟通、新证据与再次开口成本
consent       对具体协议的接受 / 拒绝、关系依据与已学得风险
feasibility   来源、预计耗时和已知风险
harm          伤害动作与当前生存压力是否相称
```

九棵树分别留下分数、理由和来源事实，再汇总为因果分。稳定种子噪声小于 1 分，只能打破同分，不能把非正向候选变成动机。所有候选因果分都不大于 0 时，人物明确保持空闲。必须回应和已生效职责仍是候选集门禁，不与普通候选混在一起靠超大常数竞争。

`social-repetition` 不是固定月份冷却，也不从候选集中删除可选社交发起。人物只查看自己仍保留的沟通记忆：若最近曾向同一受众谈过同一语义主题，而当前 `sourceFactIds` 相对上次 basis 没有新增事实，就降低再次开口的预期价值；上次未回应、拒绝、保留或违约时降权更重。出现本人可追溯的新事实会解除这项负票并提供有限的新颖度正票；即使没有新事实，与求助、照护或困境主题直接相关的身体状态显著恶化，也可能以生存急迫度抵消重复成本，不能用无关人物的危险抬高交换、生殖或共同体邀请。

这项软排序不替代社会协议的硬验证：同一协议 ID 不能重复建约，每位必需回应者只能接受或拒绝一次，同一生活对话 basis 只能开场一次，同一开场也只能回应一次。换一个临时 ID 但继续引用同一组事实来源，不会被视为新证据；必须回应和履约候选不进入 `social-repetition` 投票。

人格不是额外的总分树，而是六条有上限的调节量：开放性进入 `learning`，外向性进入主动 `relationship`，情绪性和宜人性进入 `care / relationship / harm`，尽责性进入 `commitment / harm`，诚实—谦逊进入授权履行、未授权取物和强制伤害。人格不能通过分数绕过候选合法性；高诚实人物在极端求生压力下仍可能取物，低诚实人物也不会在没有机会和收益时凭空偷窃。

结构化提议、预测、教学和回应本身就是完整动作，不强配第二个物理行动。只有有事实来源的生活对话开场，且后续行动与它共享同一人物、项目或来源事实时，才允许组成“先说、再做”的复合意图。

开局不调用模型。所有先民在第一个 planning tick 由本地规划器获得首个可执行意图。

## 5. 计划编译与动作模拟

模型或人物理由都不能直接引用临时 `optionId` 作为长期语义。长期目标使用稳定的结构化谓词，例如：

```ts
interface GoalSpec {
  domain: 'survival' | 'production' | 'social' | 'inquiry';
  predicate: FactPredicate;
  target?: WorldRef;
  reviewAtMonth?: number;
  sourceFactIds: string[];
}
```

本地计划编译器把目标逐步展开为五种原子动作。提交前的 Action Simulator 只使用世界规则进行短视窗预演：

- 目标是否仍存在且本人能够知道；
- 是否可达、是否需要先移动；
- 材料、工具、授权、身体和空间是否满足；
- 当前动作是否会产生负库存、越界、远程作用或其他非法状态；
- 是否需要先吃喝、恢复、取材或选择已知替代方法。

动作模拟器不预测完整社会未来，也不让模型判断合法性。它只保证眼前计划可执行并能留下明确失败原因。

## 6. 分级修复

失败处理固定为：

```text
一级：局部规则修复
  重算路径、靠近目标、补材料、恢复身体、重新选择同目标的已知方法

二级：本地重新规划
  保留长期目标，替换当前子目标；或在目标客观失效时选择其他目标分支

三级：可选模型建议
  实时会话可在筛中的关键重评点请求候选内重选；更长期文明策略仍创建异步任务
```

一级和二级不依赖网络。实时关键决定会先保存本地回退，再进行有上限的模型请求，并在同一只读上下文中重新验证；失败或不合法时采用回退。更长期文明策略结果以后到达时，只能在下一规划刻度重新验证；已经过时或不合法的建议被丢弃并保留审计记录。

生存反射、依赖者照护与避护维持不是项目失败。人物已有项目时，这些动作会形成有类型的临时子中断，完成后返回原父意图；被保护性中断占用的月份不计入项目停滞。本人风险与孩子风险先换算到同一紧急度尺度，再决定本刻度优先处理哪一项，而不是固定“本人永远在前”。

人物对下一纪元的预测只能读取已经发生的纪元转换、当前纪元已经持续的时间和本人认知能力。调度器内部尚未发生的 `endsAtMonth` 不属于人物事实，既不能进入候选，也不写入当期气候事件。

## 7. 模型的三个入口

实现状态：后端已经落地“已发生事实的叙事增强旁车”，接口与持久化格式见[非阻塞叙事增强旁车](../three-body/design/non-authoritative-model-enhancements.md)；实时单月会话也已接入少量候选内关键决策、完成口头沟通的台词投影、事实纪事压缩，以及玩家从人物页发起的模型对话。玩家可在模型设置页（`M`）分别把当前文明切换为本地 / 模型演进与本地 / 模型总结；主动人物对话则始终按需调用 `interaction` 路由，不受演进模式开关影响。后台长程演化不调用模型，稳定语义的文明策略任务仍是扩展位。

### 7.1 长期战略

触发示例：文明年度复盘、连续多月停滞、首次遭遇重大灾害、新产业链瓶颈、共同体规则危机。模型返回稳定语义的 `StrategySuggestion`，不得返回原子动作 ID、路径或世界补丁。

### 7.2 玩家交互

玩家在人物页打开“对话”子 tab 后，可以询问身体、当前动作、私有物品、记忆、关系和计划，也可以在自然交谈中提出请求或劝说；界面不要求玩家预先区分“聊天 / 建议”。同一轮 `interaction` 模型先按语义判断这句话只是问答，还是确实让人物考虑或定下下一步。输入使用带 `sourceId` 的局部语义事实而不是原始引擎 DTO：位置只投影成“同一位置 / 身边 / 近处 / 视野较远处”，容器与未完成建筑分开，当前可行方向不能冒充永久技能。事实性回答必须回传实际依据；人物没有来源的概念必须保持“不知道”的认知边界，但由 Soul 决定自然措辞。端点缺失、超时或结果非法时显示错误。等待只阻塞这次交互，不阻塞世界时钟。

主动对话按 `agent-interaction-v2` 组织。固定 system prompt 只保留四层协议：“身份与代词”、“权威事实”、“本轮决策”和“表达与输出”；人物状态、Soul、记忆、亲缘、证据和合法选项不在提示词中重复，只放入每轮 `localContext`。当前 user 消息是一个结构化 envelope，明确分开 `participants`、`pronounBindings`、`currentTurn` 和 `localContext`；历史仍按 user / assistant 角色传入，并在历史玩家话语中记录 speaker、requestKind、stance、choiceSummary 和 outcome。

玩家在所有人物面前拥有稳定的“主”身份。玩家对自己身份、意图、感受和偏好的陈述是一手信息，其他话语是需要认真理解和明确回应的高优先输入。玩家话语中的“我 / 我的 / 我们”固定指主，“你 / 你的”固定指当前人物；人物回复中的“我 / 我的”固定指人物自己。“我是谁”类问题的身份事实由本地协议限定，但具体回答仍由人物按 Soul 自然表达。旧版未携带 grounding 和 evidenceIds 的自由回复仍保留在界面与持久化记录中，但不再回填给模型。

“主”是模型交互协议中的稳定关系，不是未经模拟产生的世界内关系数值，也不把玩家对世界的陈述变成客观事实。自然对话若含请求、劝说或真正触发行动改变，人物必须按 Soul、人格、需要、记忆、承诺、风险与处境独立判断；纯问题和状态询问不得误生成行动。模型的 `choice` 仍须经过当轮和最新状态两次本地校验，不能创造行动、物质、知识或已经发生的结果。

父母、子女和同父母 / 半血缘兄弟姐妹从权威 `geneticParents` 谱系稳定投影到 `person.kinship`，不占用也不依赖会衰减的事件记忆。记忆仍只保存有来源的经历、对话、承诺、失败和摘要，例如“某人教过我什么”；教学、伙伴等经历关系可以与亲属身份同时成立。历史对话只证明人物曾经那样说过，不自动升级为世界事实；旧回复与本轮结构化谱系冲突时，人物应依据当前事实自然纠正。未出现在亲属投影、可见人物或有来源记忆中的关系不得按同姓或档案描述猜测。

主动人物对话、决策阶段的 `utterance` 与事实提交后的 speech-only 台词共用同一个只读 `PersonSoul` 人格派生值。核心 Soul 由人物 ID、baseline HEXACO 和控制 / 地位敏感度确定性重建，包含第一人称内在自述与稳定的说话节奏、直接程度、自我暴露和比喻倾向；有效人格、身体、关系、记忆和处境仍作为每轮动态语境。Soul 可以参与主动建议对话中的接受 / 拒绝和当前合法 choice，也可以参与可选模型在当前合法候选之间的自主权衡；但它不进入 `PersonState`，不成为新记忆、知识、需要或价值奖励，不能创造候选、绕过领域校验或直接写世界。档案原型与外貌描述不能覆盖本局结构化人格，更不能给人物注入原作身份、历史、物品、技能或知识。

人物只在同一次自然回复中返回 `accept` 并明确选中当前合法 `choice.optionId`（以及需要时的 `followUpOptionId`），才为当前分支留下一个待落实选择；普通 `answer`、未作选择的 `consider` 与 `decline` 不进入行动链。服务端在回复完成时先按当时与最新提交状态各做一次本地校验，并把组合后的目标、动作、对象、项目和关系语义保存为稳定 choice key，排除月份戳、临时 representation ID 与过期时间。下一次人物可行动时不再调用第二个模型重新解释自由文本，只在最新合法候选中按原 ID 或稳定 key 唯一重配：命中后提交带 `sourceInteractionId` 的 DecisionFact；紧急生存、必须回应或履约优先时保留为 `deferred`；候选消失、后续动作失效或匹配不唯一时记为 `blocked` 并保存具体原因。人物卡随后从真实 Intent 状态和 `actionEventIds` 持续投影“已经定下 / 已经开始 / 被打断 / 已做成 / 后来停下”。

实时人物自主对话也由 `decision` 路由表达，但分为两类请求。有多个合法方向时，模型可重选 option 并同时给出台词；不需要选择、或在后续 planning tick 才实际发生的说话，规则先提交 completed `voice communicate` ActionFact，再进入独立的 speech-only 批处理。两条路径中，参与者、沟通类型、结构化立场、提议内容、事实来源和后续真实行动均由规则固定；规划摘要只是行动标签，不是可复制的对白模板。模型措辞不能改变 `accept / reject` 立场；若改变、缺失或校验失败，该沟通不显示文字气泡。

### 7.3 创造性与叙事

模型可以提出名称、故事、符号、仪式、艺术表达、假说或新协议草案，也可以为已经发生的重大事件补充人物视角。接受、传播和客观后果必须由真实 `communicate / attend / act` 及后续历史形成。

## 8. 实时重验与异步模型任务

实时决策适配器只接收人物可感知事实、当前意图和本地合法候选。可选社交候选会附带由同一领域函数计算的 `socialRepetition` 软成本、新证据与上次结果，使模型重选与本地因子树读取同一份人物记忆判断；必须回应、履约和非社交候选不携带该字段，模型也不能把它解释成合法性门禁。开局初始意图、身体危险和既定履约不进入模型重选。必须回应只在同时有两个以上合法 required option，或唯一 required option 需要 follow-up 且有两个以上语义匹配的合法 follow-up 时，才进入决策批次；单一固定回应直接由规则提交。其他生活对话、空闲人物新方向、项目停滞和状态复核也必须存在真实选择空间才可进入。模型返回的 option ID 必须仍属于同一上下文，生活对话的 follow-up 必须共享人物、项目或来源事实，随后才可创建 DecisionFact。意图保存稳定目标和来源，不把模型文本当成世界事实。

玩家建议中已经选定的 choice 是上述普通筛选的一个显式例外：它可以要求该人物在下个月边界进行一次独立、本地且不扣普通额度的重验，但不会再发起模型决策，也不豁免领域合法性。旁车同时保存当时 option ID 与排除临时月份 / 表达标识的稳定语义 key；原 ID 仍合法时直接采用，ID 更新时只有唯一语义匹配才能采用。必须回应或履约造成的暂缓会保留原选择继续等待；候选消失或歧义则停止并留下原因。同一人物的新 actionable choice 会使旧的未落实选择失效。对话、choice、结果与用量按分支持久化，热恢复和手动存档可以恢复；从旧月份创建新分支时只继承分叉月之前的对话，尚未落实的选择标为失效而不跨分支执行。

台词适配器只扫描本次实时月份中已经 `completed`、通道为 `voice`、且存在真实听者的 `communicate` ActionFact，并先投影不含显示文本的 `speech-act-v1` 草稿。草稿只保存沟通类型、话题、提议、引用、立场和来源；规则摘要不再作为可复用对白或文本相似度锚。尚无更细领域字段的客观陈述可把事实命题放在 `speechAct.subject`，但该字段只回答“说什么事实”，不提供“原话怎么说”。决策批次已为该动作提供合法模型台词时直接复用，其余草稿按月合并到同一 `decision` endpoint 的 speech-only 批次。请求中的有效人格、本月提交后的当前身体与状态、说话者对听者的当前关系、当前处境与经来源限定的近期经历全部是只读上下文，不是 action tick 精确快照。近期经历可改变语气、直接程度和情绪温度，但只有 ActionFact 已授权的 `sourceFactIds` 才能成为对话中对外声称的事实。

只有成功且通过沟通类型与结构化立场校验的模型台词才作为 `GameFrame.speechLines` 投影绑定原 ActionFact；普通陈述不再与规则句子做字面或相似度比较，可见来源只允许 `decision-model | speech-model`。它不覆写动作的结构化 summary、result 或 diff，也不写入人物记忆、关系、知识、意图或文明纪事。只有规则动作本身可以通过领域后果改变这些状态。模型缺席、超时、返回数量不匹配、文本越界或立场冲突时，ActionFact 仍然成立，但本月不为该动作保存或显示文字气泡。旧快照中的 `source: rule` 也不会重新显示。

长期策略仍使用异步任务：

```ts
interface ModelTask {
  id: string;
  kind: 'strategy' | 'interaction' | 'creative' | 'narrative';
  requestedAtMonth: number;
  requestedAtPlanningTick: number;
  subjectIds: string[];
  sourceFactIds: string[];
  status: 'queued' | 'running' | 'completed' | 'failed' | 'stale';
}

interface StrategySuggestion {
  taskId: string;
  subjectId: string;
  goal: GoalSpec;
  reason: string;
  expression?: string;
}
```

模型任务有以下硬边界：

- 后端先提交规则结果，再派发任务；
- 同一任务可重试，但重试不暂停模拟；
- 结果必须重新读取当前状态验证，不能使用请求时的临时 option ID；
- 建议只有被人物本地规划器接受后才产生新的 DecisionFact；
- 纯叙事结果进入投影或史册，不修改世界；
- 任务失败是可观察的基础设施状态，不是文明事件。

## 9. 模型预算

实时关键决定使用滚动额度：普通上下文至多约每 3 人月一个；必须回应可不占普通额度，但只有存在选择空间时才需要重选。玩家主动对话使用独立用量记录，统一默认最多输出 8000 token；人物在同一次建议回复中选定的 choice 所触发的本地重验不调用模型，也不扣普通人月额度。这个额度不决定人物能否说话：每个实时月份完成的口头沟通都会被投影，模型演进下未在决策阶段获得台词的部分再进入独立 speech-only 批次。月度 DecisionBudget 账本仍只记录普通候选重选的 endpoint、协议、模型、调用和 token，当前不累计主动对话或 speech-only token；人物对话记录自身 endpoint、模型与 token 用量。任何额度或基础设施失败都不能阻止规则世界继续推进。

长期策略、玩家主动交互、创造性与叙事仍分别按低频任务预算控制；快速演化可在完成后统一补写少量叙事，不把人口 × 月份变成外部请求数。

## 10. 记忆

短期记忆保存近期动作、失败、对话和承诺，用于局部修复。长期人格由 `baseline + learnedDelta` 组成；行动后形成的 `PersonalityEvidence` 必须保存维度、方向、强度、情境键和来源事件。

```text
单次自愿行动 → 短期记忆 + 结构化人格证据
跨至少 3 个月、至少 2 个情境的同向高诊断性证据
→ 月末规则整合为 learnedDelta 的 1 点变化
→ 同一维度滚动 12 个月最多变化 2 点，累计偏移限制为 ±20
```

极端生存压力会降低一次伤害或未授权取物对长期人格的诊断性；生存反射、失败动作和行为缺席不直接构成人格证据。模型可以改写表达，不能在没有事件证据时直接修改人格权重或关系余额。

Soul 与长期人格分工不同：baseline 人格与稳定身份只读派生为跨轮一致的核心声音，`learnedDelta`、当前身体、关系与有源经历继续逐轮改变当下语气和具体权衡。模型只能内化 Soul，不能复述其提示或把它写回人物状态；它可以据此在已经生成的合法候选间形成个人取舍，但不能改写候选集、物理合法性、必须回应与履约边界，也不反写本地因果评分。

生活对话使用同样的证据链。本地规则先从身体处境、实际照护、共同劳动、失败、发现和共同养育事件生成带 `sourceFactIds` 的定向开场，被点名者再引用该开场作出支持或保留回应。对话只有在两轮都通过参与者、来源和去重验证后，才能更新关系并成为后续结伴/生殖提议的关系证据。候选决策台词可读取决策时的有效人格、身体、关系与近期记忆；speech-only 台词则读取本月提交后的当前人格、身体、关系与有源近期经历。两者都只能用这些只读上下文改写口吻，不得更换话题、参与者、结构化立场或事实来源；改写文本本身不会再次更新记忆、关系或知识。

共同活动本身也会形成低强度、可回放的关系证据：两人必须在同一规划刻度都完成或推进非沟通行动，并在行动后真实同地；每月每累计 5 个这样的共同活动刻度，就写入 `relationship / shared-action-ticks` 事实并使双方 `trust` 与 `bond` 各增加 1，单月最多增加 3。单纯同处、空闲、休眠、失败动作或只有一方行动不计；当月发生直接伤害、拘束或未授权取物时，那一对不获得这项正向积累。先民由共同抵达事实获得双向 `trust=55 / bond=55`；结伴提议与接受分别要求本人对对方有来源的 `trust>=20 && bond>=20`，生殖提议、接受和最终执行均要求双方双向 `trust>=60 && bond>=60`。因此每月至少共同活动 5 个刻度的先民约 5 个月可跨过生殖门槛；照护、履约、对话和共同项目仍可依据各自事实更快改变关系。

近亲繁衍也遵循同一原则。世界规则不把直系或共亲关系写成“禁止生殖”的非法动作，而是根据亲缘距离与双亲已有遗传负荷，确定后代的遗传易感性、初始身体和能力偏差、寿命压力及后续疾病概率。人物只有在亲眼经历体弱出生、反复疾病或能力衰退后，才形成带来源的短期记忆；多次证据把它提升为“近亲后代风险较高”的个人认识。该认识进入本地规划评分，使人物倾向拒绝近亲提议、优先无亲缘伴侣，并可通过真实沟通传播，最终才可能涌现为亲族禁忌或婚配规范。模型不能预先注入这项知识。

生殖同意不是关系达到阈值后的永久开关。一次接受形成最长四个自然月的可撤回尝试窗口；每个伴侣对每月最多完成一次真实尝试，未受孕只记录尝试，受孕、撤回、关系失效或到期才结清协议。每个动作必须携带精确的协议引用，不能借另一份同时存在的反向协议重复采样。动作提交时再次检查双方关系，伤害等事件使任一方向的信任或羁绊跌破 60 后，旧协议只能撤回，不能继续执行生殖；若很高的关系在扣减后仍保持双方双向 60 / 60，则不额外设置“发生过冲突即禁止”的门禁。继续或撤回统一进入本地 `consent` 因果树，读取双方关系、本人已知的亲缘风险、产后恢复和亲生未成年子女照护负担。关系到达门槛只提供有限的同意倾向；规则不通过全局人口指标或硬编码孩子数量替人物决定。

## 11. 历史与回放

MonthRecord 除月度事实外，应记录 15 个 tick 的执行顺序和动作引用。规则决策与动作是权威历史；模型任务、人物对话、待落实 choice 及其本地重验结果是分支内独立审计流，人物台词是绑定 ActionFact 的 GameFrame 表现投影。

回放：

- 不重新运行本地规划器；
- 不重新调用模型；
- 应用已提交的事件和补丁；
- 直接读取已保存的台词投影；旧帧没有 `speechLines` 时保持无台词，当前既不从 ActionFact 补建规则原话，也不补调模型；
- 分岔后从新的 branchId 继续本地规划；
- 已完成但尚未被接受的模型建议不自动跨分支生效。

文明演化程度使用《文明指数 v1》从人口、认知疆域/功能基础设施、科技、社会和历史五类事实派生。指数是观察层，不能反向为人物解锁能力。恒/乱纪元、天气、预言、脱水休眠和动物生态遵循《纪元、预言与生态 v1》，它们必须产生真实状态与后果，不只生成叙事。

## 12. 前后端迁移边界

本轮以后端长程演化为主：

- 后端 `/evolve` 和批量模拟必须使用规则优先主链；
- 实时单步与自动演化先运行本地规划，再允许通用模型协议适配器覆盖少量通过筛选和重验的关键选择；规则月提交后，完成的口头沟通才可增加只读台词投影；
- 前端旧路径不得被后端快速演化复用；
- 无论前端是否迁移，领域层都必须始终提供本地规划入口。

## 13. 多运行演化验证

规则修改不得只依据一次运行判断有效或无效。验证应按《文明演化双闭环与实验协议》选择与因果时标匹配的实验矩阵：多个配对种子、10/20/30 年中的一个或多个时长，必要时增加重复或更长的跨代运行。

本地规则完全确定时，相同种子重复只用于验证可回放性，不能冒充独立样本。基线与候选必须使用相同种子、时长、配置和模型策略；结论同时读取聚合分布、发生率、配对差异和代表性历史。单次运行只能暴露候选问题或提供因果案例。

## 14. 验收不变量

- 关闭网络和模型配置后，可从新文明推进至少 1200 月；
- 每个完整月份恰有 15 个规划刻度；
- 空闲且可行动的人不会因为没有模型额度长期保持无意图；
- 开局、紧急反射和履约不进入模型重选；必须回应始终拥有本地强制回应，无选择空间时只在事实提交后尝试台词增强；
- 模型决策请求超时或返回非法内容时采用预先计算的本地决定；台词请求失败时保留 ActionFact 但不显示文字气泡，月份不会回滚；
- 模型只能在当前上下文引用临时 option ID；长期意图必须保存规则目标、来源和可编译动作，而不是把 option ID 当成战略语义；
- 每个完成且具有可解析真实听者的 `voice communicate` ActionFact 都产生一份结构化话语草稿；只有成功模型台词进入 `GameFrame.speechLines`，且不改变 summary、记忆、关系、知识或文明纪事；
- 每项客观变化都能追溯到规则动作和世界事件；
- 任意 10/20/30 年及更长快速演化的主循环不等待任何模型请求；
- 可在模拟完成后异步生成少量真实模型叙事，而不改变确定性历史。
