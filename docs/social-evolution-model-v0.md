# Eland 世界演进模型

## 核心模型

```text
世界 = 时间 + 空间 + 物质
时间 = 过去 + 现在

人 = 头脑 + 手脚 + 关系
头脑 = 马斯洛五层需求 + 局部认知
手脚 = 行动 + 能力
行动 = 移动 + 交互

实践 = 重复的行动
制度 = 稳定的共同实践
```

- 世界保存过去的事实与现在的状态；未来只存在于头脑。
- 生理、安全、归属与爱、尊重、自我实现五层需求产生强弱不同的动机；较低层的迫切缺口会压制较高层投入。
- 局部认知只使用本人亲历、眼前可见和有来源的传授，结合环境可供性、能力与过往成败选择实际手段。
- 世界历史是完整审计日志，不等于人物记忆。人物只能访问有限情景片段和压缩摘要；推理能力决定容量与压缩后保留的信息量，遗忘会永久改变之后可用的经验。
- 能力约束行动，关系影响交互。
- 人解释历史；世界不保存对历史的唯一解释。

## 时间尺度与长期行动

世界以“月”为最小权威时间步，每 12 个月派生一个显示年。年龄、妊娠、疾病、预测期限、记忆持续和实践稳定性都以月数保存，年份只用于界面与长期统计。

人物不会在每个月固定重新思考，也不会用一次决定瞬间完成劳动：

    每月世界推进
    → 每个人按处境获得一次非零概率的关键决策机会
    → 关键决策创建、继续、修改、挂起或放弃长期计划
    → 引擎按月推进计划的移动与工作
    → 新事实可能触发后续月份重新决策

迁行、采集、建造、耕作、照护、观察和记录都可以延续数月或数年。没有新关键决策时，既有计划仍然推进；人物身体恶化、目标消失、路径阻断或突发事件则提高重新决策概率。

关键决策机会与大模型调用是两件事。系统按“同期人物月 ÷ 12”限制滚动 12 月内提交给大模型的人物上下文，并对实际 token 设置硬上限；额度以外的已触发决策由确定性 Mock 完成。月度世界推进、长期行动、寻路、身体结算和规则史册不调用大模型，年度模型总结最多每 12 个月一次。

完整契约见 [《Eland 月度时间模型 v1》](./monthly-time-model-v1.md)。

## 开局人物与马斯洛五层人格

每次建立新文明时，系统从 ELAND 人物档案池中无重复地随机选取 **3–6 人**。人物档案是唯一的人物来源，至少包含稳定 ID、名字、显示色、年龄和自然语言描述。相同“世界种子 + 文明编号”必须得到相同的入局名单，方便复盘；改变任一项则重新洗牌，不保证沿用上一局角色。

人物不再使用本我 / 自我 / 超我结构。头脑中与动机相关的权威结构只有马斯洛五层人格：

| 层级 | 运行时关注 | 档案描述中的典型线索 |
| --- | --- | --- |
| 生理需求 | 食物、饮水、休息、冷热、身体存续 | 食物、水、身体、健康、休息、生存、劳作 |
| 安全需求 | 庇护、风险、秩序、稳定 | 安全、庇护、稳定、规则、谨慎、加固 |
| 归属与爱 | 陪伴、信任、照料、共同体 | 同伴、家庭、互助、分享、照料、倾听 |
| 尊重需求 | 能力证明、责任、地位、认可 | 尊重、认可、责任、带领、贡献、组织 |
| 自我实现 | 求知、创造、表达、长期成果 | 好奇、探索、创造、观察、记录、传授 |

开局构建分为两步：

1. 从档案描述匹配各层线索，形成五层 `baselineWeight` 和对应的文字证据；最高基线层是这个人物的长期人格底色。
2. 人格基线参与生成初始位置、能力、身体韧性与初始关系。运行期间，身体、环境、关系和经历继续计算五层的实时强度。

人格底色不等于永久主导需求。实时强度由“档案基线 + 当前缺口”共同构成；系统从生理到自我实现依次查找迫切缺口，低层达到阈值时压制高层投入。低层缓解后，人物才按更高层的实时强度选择行动。因此，同一个重视创造的人在缺水时仍会先找水，但安全后更容易重新投入制作、观察或表达。

运行时最小数据契约：

```text
Agent.profile.description
Agent.profile.personality.layers[5] = level + baselineWeight + evidence
Agent.profile.personality.dominantLevel = 长期人格底色

Agent.mind.needs.layers[5] = 当前五层强度与活跃需要
Agent.mind.needs.dominantLevel = 当前主导需求
Agent.mind.cognition = 局部感知、选择、认识与有限记忆
```

`profile.personality` 是较稳定的人格参数，`mind.needs` 是随世界演化的实时状态，两者不可混为一份数据。大模型可以依据二者提出行动，但不能增删人物、改写五层权重或绕过世界规则制造结果。

## 演进循环

```text
世界的过去与现在
→ 头脑形成意图
→ 手脚移动或交互
→ 世界的现在改变，原来的现在进入历史
→ 头脑、能力与关系改变
→ 行动被重复、改变或放弃
→ 实践与制度涌现
```

## 长期目标：一百个决定性事件

> 这份早期清单已经扩展为 [《Eland 人类社会活动一千项能力地图》](./human-society-capability-map-1000.md)。扩展地图保留本节 1–100 的编号，并用社会功能域补足日常生活、多样家庭、健康照护、组织、经济、权利、生态、危机、衰退与重建等范围。本节继续作为当前实现状态的短清单；千项地图用于长期覆盖审计，不能作为线性科技树或写入人物目标。

Eland 最终应当能够模拟下列事件。它们是能力目标，不是写死的剧情，也不构成唯一的历史顺序。同一事件可以发生多次，也可能始终不发生；一个社会还可能停滞、倒退或消失。

某个目标只有满足以下条件，才算真正实现：人物能够在当时的能力、关系和环境约束下促成它；世界能够把发生过的事实及其后果保存下来；后来的实践、制度和解释能够追溯到这些事实。事件的意义仍由人物解释，不写入世界的权威状态。

以下清单是持续能力目标。当前实现只对具备完整事实来源的项目标注“本轮可观察”，不把目标文本注入人物决策，也不保证每次运行都会出现。
