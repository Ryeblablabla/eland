# Eland 世界演进模型

状态：社会演进概念模型。人物运行时决策、15 个规划刻度和模型边界以[《规则优先人物架构 v1》](./rule-first-agent-architecture-v1.md)为准。

## 核心模型

```text
世界 = 时间 + 空间 + 物质
时间 = 过去 + 现在

人 = 头脑 + 手脚 + 关系
头脑 = 马斯洛五层需求 + 局部认知
手脚 = 行动 + 能力
行动 = 移动 + 交互

实践 = 重复的行动
制度 = 稳定的共同实践
```

- 世界保存过去的事实与现在的状态；未来只存在于头脑。
- 生理、安全、归属与爱、尊重、自我实现五层需求产生强弱不同的动机；较低层的迫切缺口会压制较高层投入。
- 局部认知只使用本人亲历、眼前可见和有来源的传授，结合环境可供性、能力与过往成败选择实际手段。
- 世界历史是完整审计日志，不等于人物记忆。人物只能访问有限情景片段和压缩摘要；推理能力决定容量与压缩后保留的信息量，遗忘会永久改变之后可用的经验。
- 能力约束行动，关系影响交互。
- 人解释历史；世界不保存对历史的唯一解释。

## 时间尺度与长期行动

世界以“月”为最小存档时间步，每月包含 15 个本地规划刻度；每 12 个月派生一个显示年。年龄、妊娠、疾病、预测期限、记忆持续和实践稳定性都以月数保存，年份只用于界面与长期统计。

人物不会在每个月固定重新思考，也不会用一次决定瞬间完成劳动：

    每月世界推进
    → 顺序执行 15 个规划刻度
    → 每个刻度由本地规划器创建、继续、修复或改换意图
    → 引擎执行一个受约束的原子动作
    → 新事实立即影响后续刻度

迁行、采集、建造、耕作、照护、观察和记录都可以延续数月或数年。没有新关键决策时，既有计划仍然推进；人物身体恶化、目标消失、路径阻断或突发事件则提高重新决策概率。

人物规划与大模型调用是两件事。本地规划器在每个规划刻度始终可用；模型只在少量长期战略、玩家交互、创造性表达和历史叙事中异步参与。紧急响应、履约、寻路、身体结算、动作修复和规则史册都不调用模型，也不存在按人物月分配的模型决策额度。

完整契约见 [《规则优先人物架构 v1》](./rule-first-agent-architecture-v1.md)与[《Eland 月度时间模型 v1》](./monthly-time-model-v1.md)。

## 开局人物与动机结构

每次建立新文明时，系统从 ELAND 人物档案池中无重复地随机选取 **5–8 人**；开局配置也可显式指定 `characterIds`（至多 10 位）。人物档案是唯一的人物来源，包含稳定 ID、名字、显示色和自然语言描述。相同"世界种子 + 文明编号"必须得到相同的入局名单，方便复盘；改变任一项则重新洗牌，不保证沿用上一局角色。

人物不再使用本我 / 自我 / 超我结构，运行时也不保存五个需求槽位。动机由身体缺口、状态、关系和局部事实直接派生；马斯洛五层只作为档案描述与人物卡的解释口径：

| 层级 | 派生来源 | 档案描述中的典型线索 |
| --- | --- | --- |
| 生理需求 | 健康、水分、营养三项身体储备的缺口 | 食物、水、身体、健康、休息、生存、劳作 |
| 安全需求 | 暴露、危险、资源不确定性 | 安全、庇护、稳定、规则、谨慎、加固 |
| 归属与爱 | 关系事实与陪伴缺口 | 同伴、家庭、互助、分享、照料、倾听 |
| 尊重需求 | 授权、职责与社会反馈 | 尊重、认可、责任、带领、贡献、组织 |
| 自我实现 | 知识、技术与可用余量 | 好奇、探索、创造、观察、记录、传授 |

运行时的权威人物状态见 `domain/person.ts`：稳定档案（`profile.description`）、出生与寿命月数、亲代与遗传负荷、体素位置、三项身体储备、过程状态、私有背包、知识与当前意图。需求强度、能力和关系都在决策与展示时从事实派生，不预生成五层权重或能力数值。

本地规划器依据上述派生状态选择行动；模型可以异步提出长期建议或人物表达，但不能增删人物、改写人格参数或绕过世界规则制造结果。

## 演进循环

```text
世界的过去与现在
→ 头脑形成意图
→ 手脚移动或交互
→ 世界的现在改变，原来的现在进入历史
→ 头脑、能力与关系改变
→ 行动被重复、改变或放弃
→ 实践与制度涌现
```

## 长期目标：一百个决定性事件

> 这份早期清单已经扩展为 [《Eland 人类社会活动一千项能力地图》](./human-society-capability-map-1000.md)。扩展地图保留本节 1–100 的编号，并用社会功能域补足日常生活、多样家庭、健康照护、组织、经济、权利、生态、危机、衰退与重建等范围。本节继续作为当前实现状态的短清单；千项地图用于长期覆盖审计，不能作为线性科技树或写入人物目标。

Eland 最终应当能够模拟下列事件。它们是能力目标，不是写死的剧情，也不构成唯一的历史顺序。同一事件可以发生多次，也可能始终不发生；一个社会还可能停滞、倒退或消失。

某个目标只有满足以下条件，才算真正实现：人物能够在当时的能力、关系和环境约束下促成它；世界能够把发生过的事实及其后果保存下来；后来的实践、制度和解释能够追溯到这些事实。事件的意义仍由人物解释，不写入世界的权威状态。

以下清单是持续能力目标。当前实现只对具备完整事实来源的项目标注"本轮可观察"，不把目标文本注入人物决策，也不保证每次运行都会出现。运行时观察器见 `application/monthly-simulation.ts` 与 `projection/core-milestones.ts`；除本节 1–100 内的项目外，它们还以弱形式判定扩展编号 61（选出临时协调者）、134（交换技术知识）、143（取暖、降温与通风）和 524（通过协商形成共识）。
