# ELAND 纪元、预言与生态 v1

## 1. 恒纪元与乱纪元

世界不再每月独立抽一个气候，而是产生跨月持续的纪元区段。同一种子必须完全可回放。

- 开局为恒纪元；
- 恒纪元持续 6‑48 个月，混沌强度越高，上限越低；
- 乱纪元持续 3‑42 个月，混沌强度越高，上限越高；
- 当前 v1 交替生成恒/乱纪元，后续可由真实三体运动替代调度器；
- 恒纪元主导气候温和；乱纪元会在寒冷、炎热和烈火之间出现快速变化；
- 每个纪元保留 `sequence/sinceMonth/endsAtMonth/dominantClimate`，但 `endsAtMonth` 不直接暴露给人物。

主游戏接入实时三体天象时，“单月物理判定”与“权威纪元”分开：新的恒/乱候选必须连续出现 3 个权威月，且当前已确认纪元至少持续 6 个月，才提交一次真实纪元转换。未达到条件的短暂轨道异常保留在实时天空采样中，但不反复改写人间气候与纪元历史。三日凌空等终局天象不受确认窗和最短持续期限制。

实时三体宇宙传入的 `burned` 不是普通烈火天气，而是“三日凌空”终局灾变。权威月在第一个规划刻度开始前提交灾变事实，所有存活人物无视住所、脱水休眠和人物特质立即汽化，背包随之销毁且不生成遗体或地面遗物；该月不再产生人物行动，并以零生还者在同月结算文明毁灭。内部纪元调度产生的普通 `fire` 即使强度达到 10，也仍按冷热暴露与身体规则逐月结算，不能冒充三日凌空。

## 2. 月度天气

纪元是中长期环境，天气是按月结算的局部过程。当前天气包括晴朗、降雨、风暴、干旱、降雪和浓雾。

- 天气不再每月独立重抽；每个天气过程保留 `kind/intensity/sinceMonth`。普通天气至少持续 2 个完整月份，之后每月有 75% 的延续惯性，其余情况才按当前气候分布重新取样。重新取样仍可得到同种天气，此时过程继续。
- 当前气候中本来占优的天气会自然持续更久；两个月的最低过程长度也让低概率天气能够形成可感知片段，而不是逐月闪换。
- 持续期内强度只会偶发升降一级，不重置 `sinceMonth`；天气类型切换时才开始新过程。
- 气候变化后，降雪、降雨或干旱若与新气候不兼容会立即结束；晴朗、风暴和浓雾可跨越气候边界。延续或转换只在当月边界结算，不作为人物可提前读取的隐藏事实。

- 降雨湿润土壤、加速作物生长并熄灭露天火；对世界生成器登记的干涸河道格，降雨或风暴只有在相邻河格当前仍为真实水体时，才可能按稳定种子逐格补给。普通沙地、孤立干河格和无降水月份不会凭河道身份变成水；
- 露天火占用承托地表而不在上方新增体素；熄灭后原位转化为灰，不垫高地形；
- 干旱增加水分消耗，会使作物、果木和少量地表水退化；河道地表水仍可蒸发成沙，后续是否恢复取决于真实降水和相邻水体，因此水流不是永久可用资源；
- 降雪会加重寒冷负荷并冻结水面；
- 风暴改变火势、植物和人物暴露风险。

## 3. 智者预言

“智者”不是预设职业。认知与感知总和达到门槛的成年人，在可见范围内有受众，且本人根据天象、气温和旧纪元节律推断下一次变化已进入六个月窗口时，才可以公开喊出预言。系统不会把原本落在几年后的估计强行截短成近期预言。

- 预言只指向未来 1–6 个月，包含目标纪元、预计开始月、±3 月时间窗、受众和事件来源；
- 预测值只根据本人可获得的历史纪元转换、当前纪元已经持续的月数和认知 / 感知能力形成；首次预测使用带稳定个体误差的先验，之后使用同类已结束纪元时长的中位数。调度器尚未发生的 `endsAtMonth` 不进入人物事实，因此预测永远不保证正确；
- 纪元真正切换或时间窗过期时，世界规则结算命中/失误；
- 命中使听众对预言者的信任 `+11`，失误使信任 `-6`；
- 人物会保留命中或失误记忆，预言者的预测技术置信度也会随结果变化；
- 其他人只在已经建立足够信任，或至少两次可验证预言的命中率达到 60% 后，才会因预言提前避灾。

## 4. 脱水休眠

`dehydrated-hibernation` 是主动、可恢复的低代谢状态，与身体指标中因缺水造成的危险脱水完全分开。

- 身体储备足够，且没有妊娠、重伤或重病时才能主动进入；
- 可由可信的临近乱纪元预言触发，也可在人物亲身经历高强度乱纪元时触发；
- 休眠期间不执行普通行动，也不会因同处亲代移动而改变位置；水分/营养月消耗分别降为 `0.35/0.30`，冷热负荷乘以 `0.08`；
- 休眠本身每月消耗 `0.25` 健康，强度至少 8 的乱纪元再额外消耗 `0.15`；持续 6 / 18 个月或身体储备跌破阈值时，休眠状态升级并留下身体恶化事实，因此它只能换取时间，不能无限维持生命；
- `dormant` 是低代谢休眠阶段。重新水化必须近身，并使用附近真实可饮用物质或由同一实体容器从真实水体素装取、运输而来的水；身体已经危急时可立即唤醒，支撑休眠的预言已经失误或乱纪元已经过去时也可安全唤醒。预言仍待验证时，相信该预言的清醒人不会提前打断休眠；不相信的人可以留下“质疑并提前唤醒”的事实，但同一休眠计划在没有新证据时不能被反复唤醒；
- 重新水化不会直接删除状态，而是让同一个 episode 从 `dormant` 进入 `recovering` 并记录真实补水来源。恒纪元开始后，早于本恒纪元进入的 `dormant` episode 会自动转入 `recovering`；若人物在持续恒纪元中因预言提前休眠，预言失效或身体跌入危险储备也会触发同一转换。相位切换本身不增加身体储备；
- 看见可安全唤醒休眠者的清醒人物可建立有来源的休眠救援项目：固定休眠者最后确认位置，近身；没有现场水时取得或制作容器、前往本人可见或记得且仍真实可达的水源、装水并返回；随后消耗同一份携带水补水。自由文本长期关切不能替代这条项目与物质链；
- `recovering` 人物恢复清醒，但在 episode 结束前只能进行必要移动、取得水和食物并进食；依赖幼儿只能进食本人已经持有的物品，清醒帮助者可在同地以附近水源或携带水每月帮助补水一次。只有真实补水或进食留下来源，且健康、水分、营养的最低值达到 45，下一月月初才退出 episode 并恢复此前挂起的意图。若恢复期间再次进入乱纪元，则沿用原 episode 转回 `dormant`，不会重复支付入眠代价；
- 有新证据支持的安全唤醒立即增加双方信任与羁绊。有争议的唤醒延迟到预言结算：若乱纪元随后到来，休眠者降低对唤醒者的信任与羁绊；若验证窗平稳过去，则提高对唤醒者的信任。`dormant` 休眠者不能执行普通行动；全员休眠不会结束文明，环境、身体代价、纪元切换和后续恢复仍按月推进。三日凌空会绕过休眠保护并立即清空存活者；除此之外，只有没有存活者或运行达到显式 endpoint，文明才终止。

## 5. 动物、物品与配方

当前纵向切片包含鹿、兔、野猪和狼。它们是权威实体，拥有位置、年龄、健康、饥饿、性别、亲代和种群容量。

- 食草动物迁移、取食野生植物和作物；
- 捕食动物追踪猎物，饥饿时可袭击未受建筑保护的人；
- 动物按季节、年龄、饥饿和容量繁殖，会衰老和饿死；
- 人可观察、追踪、捕猎，失败时可被反击；
- 尸体依物种产生生肉、兽皮和骨的真实掉落物。

新增可探索配方：

- 生肉 + 火 → 熟食；
- 石制工具 + 木材 → 石刃长矛；
- 兽皮 + 绳 → 兽皮衣；
- 骨 + 石 → 骨制工具；
- 树叶 + 纤维 → 草药；
- 木材 + 火 → 木炭。

普通人物不会获得开局配方，仍通过局部尝试、成功事件、复查和传播形成技术。先知是出生特质的显式例外：它以有来源的出生知识掌握当前规则库全部配方，但不获得材料、地图或行动豁免，详见《人物特质 v1》。
