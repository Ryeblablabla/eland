# ELAND 纪元、预言与生态 v1

## 1. 恒纪元与乱纪元

世界不再每月独立抽一个气候，而是产生跨月持续的纪元区段。同一种子必须完全可回放。

- 开局为恒纪元；
- 恒纪元持续 6‑48 个月，混沌强度越高，上限越低；
- 乱纪元持续 3‑42 个月，混沌强度越高，上限越高；
- 当前 v1 交替生成恒/乱纪元，后续可由真实三体运动替代调度器；
- 恒纪元主导气候温和；乱纪元会在寒冷、炎热和烈火之间出现快速变化；
- 每个纪元保留 `sequence/sinceMonth/endsAtMonth/dominantClimate`，但 `endsAtMonth` 不直接暴露给人物。

## 2. 月度天气

纪元是中长期环境，天气是月度局部表现。当前天气包括晴朗、降雨、风暴、干旱、降雪和浓雾。

- 降雨湿润土壤、加速作物生长并熄灭露天火；
- 露天火占用承托地表而不在上方新增体素；熄灭后原位转化为灰，不垫高地形；
- 干旱增加水分消耗，会使作物、果木和少量地表水退化；
- 降雪会加重寒冷负荷并冻结水面；
- 风暴改变火势、植物和人物暴露风险。

## 3. 智者预言

“智者”不是预设职业。认知与感知总和达到门槛的成年人，在可见范围内有受众，且本人根据天象、气温和旧纪元节律推断下一次变化已进入六个月窗口时，才可以公开喊出预言。系统不会把原本落在几年后的估计强行截短成近期预言。

- 预言只指向未来 1–6 个月，包含目标纪元、预计开始月、±3 月时间窗、受众和事件来源；
- 预测值只根据本人可获得的历史纪元转换、当前纪元已经持续的月数和认知 / 感知能力形成；首次预测使用带稳定个体误差的先验，之后使用同类已结束纪元时长的中位数。调度器尚未发生的 `endsAtMonth` 不进入人物事实，因此预测永远不保证正确；
- 纪元真正切换或时间窗过期时，世界规则结算命中/失误；
- 命中使听众对预言者的信任 `+11`，失误使信任 `-6`；
- 人物会保留命中或失误记忆，预言者的预测技术置信度也会随结果变化；
- 其他人只在已经建立足够信任，或至少两次可验证预言的命中率达到 60% 后，才会因预言提前避灾。

## 4. 脱水休眠

`dehydrated-hibernation` 是主动、可恢复的低代谢状态，与身体指标中因缺水造成的危险脱水完全分开。

- 身体储备足够，且没有妊娠、重伤或重病时才能主动进入；
- 可由可信的临近乱纪元预言触发，也可在人物亲身经历高强度乱纪元时触发；
- 休眠期间不执行普通行动，也不会因同处亲代移动而改变位置；水分/营养月消耗分别降为 `0.35/0.30`，冷热负荷乘以 `0.08`；
- 休眠本身每月消耗 `0.25` 健康，强度至少 8 的乱纪元再额外消耗 `0.15`；持续 6 / 18 个月或身体储备跌破阈值时，休眠状态升级并留下身体恶化事实，因此它只能换取时间，不能无限维持生命；
- 重新水化必须近身且附近确有可饮用物质。身体已经危急时可立即唤醒；支撑休眠的预言已经失误或乱纪元已经过去时也可安全唤醒。预言仍待验证时，相信该预言的清醒人不会提前打断休眠；不相信的人可以留下“质疑并提前唤醒”的事实，但同一休眠计划在没有新证据时不能被反复唤醒；
- 有新证据支持的安全唤醒立即增加双方信任与羁绊。有争议的唤醒延迟到预言结算：若乱纪元随后到来，休眠者降低对唤醒者的信任与羁绊；若验证窗平稳过去，则提高对唤醒者的信任。若所有人都在休眠，跨过乱纪元后的环境复水仍避免全员永久沉睡；休眠者自己不能执行普通行动。

## 5. 动物、物品与配方

当前纵向切片包含鹿、兔、野猪和狼。它们是权威实体，拥有位置、年龄、健康、饥饿、性别、亲代和种群容量。

- 食草动物迁移、取食野生植物和作物；
- 捕食动物追踪猎物，饥饿时可袭击未受建筑保护的人；
- 动物按季节、年龄、饥饿和容量繁殖，会衰老和饿死；
- 人可观察、追踪、捕猎，失败时可被反击；
- 尸体依物种产生生肉、兽皮和骨的真实掉落物。

新增可探索配方：

- 生肉 + 火 → 熟食；
- 石制工具 + 木材 → 石刃长矛；
- 兽皮 + 绳 → 兽皮衣；
- 骨 + 石 → 骨制工具；
- 树叶 + 纤维 → 草药；
- 木材 + 火 → 木炭。

配方不作为开局知识注入。人物仍通过局部尝试、成功事件、复查和传播形成技术。
