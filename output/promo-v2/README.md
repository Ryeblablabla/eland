# ELAND · 他们称你为「主」

最终成片：**ELAND-promo-v2-1440p.mp4**，74 秒，原生 2560 × 1440、30 fps，H.264 / AAC 立体声。另附 15 秒动态样片。

本版重新拍摄了 19 个动态镜头，共输出 2760 个原生画面帧，剪入成片 2220 帧。全部使用项目正式的地表、宇宙和大气渲染器；没有使用上一版的低分辨率实录，也没有将静态截图推拉成视频。

## 故事与素材

主线取自第 16 号文明：孙疏影幼年随母亲生活，后来建成住所，留下失败的工艺记忆，与玩家讨论教导他人，继续采集和尝试。片尾采用后若水的真实回答：“能延续，但得靠我们自己一步步去争取。”

开场为另一轮文明第 169 月的真实严寒终局，画面已明确标注。该存档只保留终局状态，因此镜头表现终局环境与遗体，没有编造人物死亡动画，也没有把第 16 号文明说成已经灭亡。宇宙段沿现有 RK4 引擎推进真实保存的天体状态；不能将它与另一轮严寒记录解释为一条未经证明的直接因果链。

人物路径、动作、物品与住房来自实际状态。第一人称镜头沿同一条真实路径设置视点。玩家对话和人物记忆使用原文节选，明确显示回放/存档标记；拍摄页不会提交新的对话或修改存档。

图像经过裁剪边框、轻微调色、转场与字幕处理。音乐来自项目自带 BGM，环境风声、雨声和轻转场音是后期声效。六段旁白使用通用神经语音；后若水台词的配音是后期演绎，不是游戏录音，也没有克隆人物声音。相关工具：[edge-tts](https://github.com/rany2/edge-tts)。

## 可继续编辑的文件

- `timeline.json`：每个镜头的源时间、成片时间和转场。
- `titles.ass`、`subtitles.srt`：排版字幕与通用字幕文件。
- `edit-script.md`：剪辑、字幕和配音安排。
- `shots/`：重新录制时生成的原生动态镜头缓存，不提交到 Git。
- `audio/`：独立旁白、环境音和声效；最终使用 01、02、03、05、06、07 六个旁白文件。
- `data/`、`story-evidence.md`：只读存档导出、原始事件、对话和记忆来源。
- `tools/render_film.py`：从上述文件重新合成完整成片。
- `qa/`：制作过程中生成的检查截图，不提交到 Git。

## 重新拍摄

开发拍摄页位于 `three-body/.promo/`。启动现有前端后访问 `http://127.0.0.1:3217/.promo/?shot=walk`；`director.tsx` 中定义各镜头的真实帧、时间窗口和相机运动。

`SocietyScene3D`、`ThreeBodyCanvas`、`AtmosphereTransition` 增加了可选 `capture` 接口，支持显式时间、相机和原生分辨率。普通游戏不传该参数时仍走原本的自动动画循环。拍摄只调整展示层，不写回世界状态。

录制工具为 `tools/capture.mjs`，连接独立 Chrome CDP 端口 9332，每次调用正式渲染器产生一个画面，再以 30 fps 编码。制作使用的临时浏览器已关闭。

重新合成：先启动前端与独立 Chrome CDP 实例，用 `tools/capture.mjs` 按 `timeline.json` 中的镜头名称重新录制，再在项目根目录执行 `python3 output/promo-v2/tools/render_film.py`。需要 FFmpeg 及 Avenir Next、Songti SC、Hiragino Sans GB 字体。

渲染中间文件、逐帧检查图、录制镜头缓存、日志、临时 Python 环境与只读导出脚本的编译产物已清理；正式成片、字幕、独立音轨、源数据和脚本保留。`work/`、`qa/`、`shots/` 等缓存目录会在制作时重新生成。
