# ELAND 宣传片剪辑稿

成片为 74.00 秒、2560 × 1440。主体使用正式游戏渲染器拍摄的动态画面，按真实存档中的人物、事件和对话组织叙事。开场的严寒终局来自另一轮文明；人物故事来自第 16 号文明，身份标签明确区分两段记录。

上下各保留 84 px 窄黑边。所有坐标均基于完整的 2560 × 1440 帧；先完成剪辑、调色和黑边，再叠加 `titles.ass`，叠字后不再裁切或缩放。

## 字幕与片名字体

`titles.ass` 的叙事字幕使用 Songti SC，48 px 暖白，底部居中，定位为 `(1280, 1320)`，细描边与薄阴影。字幕在画面下部，上下黑边仍维持 84 px。身份标签使用 Hiragino Sans GB，32 px，左下定位 `(90, 1120)`，与叙事字幕分开。

顶部左侧小 ELAND 使用 Avenir Next，28 px，定位 `(72, 42)`；右侧「开发中画面」使用 Hiragino Sans GB，22 px，定位 `(2488, 42)`。两者位于上方黑边内，持续全片。一般字幕淡入、淡出各 0.35 秒；身份标签使用 0.35–0.40 秒。

片尾大 ELAND 使用 Avenir Next，190 px，中心位于 `(1280, 590)`；第二行「没有写好的历史」使用 Songti SC，54 px，中心位于 `(1280, 765)`；第三行使用 Hiragino Sans GB，30 px，中心位于 `(1280, 875)`。

`subtitles.srt` 是可移植的叙事字幕与片尾文字版本，不含顶部品牌或身份角标。最终视频烧录 `titles.ass` 即可；不应同时烧录 SRT，否则会重复叠字。

## 采用的旁白音轨

采用已经成功生成的 6 个 MP3 文件，03 拆成两段，形成 7 处配音。时长取自 `audio/manifest.json` 的 ffprobe 结果。

| 文件 | 原文件时长 | 配音内容与排布 |
| --- | --- | --- |
| `audio/narration_01.mp3` | 3.912 秒 | 「一场严寒，足以让一个文明结束。」从 0.30 秒附近对齐开场字幕。 |
| `audio/narration_02.mp3` | 4.224 秒 | 「而新的故事，会从一无所有开始。」从 8.10 秒附近对齐字幕。 |
| `audio/narration_03.mp3` | 5.592 秒 | 前半句在 14.40 秒附近，后半句在 21.20 秒附近，分别对应幼年与住所画面。 |
| `audio/narration_05.mp3` | 3.792 秒 | 「他们称你为主，却有自己的主意。」从 36.60 秒附近对齐字幕。 |
| `audio/narration_06.mp3` | 4.536 秒 | 「恒纪元与乱纪元之间，没有人知道结局。」从 54.00 秒附近对齐字幕。 |
| `audio/narration_07.mp3` | 4.272 秒 | 「能延续，但得靠我们自己一步步去争取。」从 63.80 秒附近对齐字幕。 |

03 的句间停顿经 `silencedetect` 检查，在原文件约 1.606–2.536 秒之间，可于 2.10 秒处拆分。建议前段取 `[0.00, 2.10]`，放至 14.40 秒；后段取 `[2.10, 5.15]`，放至 21.20 秒，保留句尾余量。两段都是原音轨裁切，不重新合成语音。其余文件的片头、片尾静音可随最终听审微调，字幕采用上表已确定的精确时间码。

01、02、03、05、06 使用 stock `zh-CN-YunxiNeural`；07 使用 stock `zh-CN-XiaoxiaoNeural` 朗读真实原句。语速均为 `-10%`，音高为 `-3Hz`。这些声音是宣传片后配神经语音；没有克隆人物声线，07 也不是游戏中的原声录音。

04 不采用；08 不采用，片尾「没有写好的历史」由画面文字与音乐收尾。因此 04、08 不属于这版成片的必需素材，现有 6 条成功音轨足以完成既定剪辑。

## 环境音与混音

`ambient_wind_70s.wav` 与 `ambient_rain_70s.wav` 分别作为风、雨段落的低音量环境底，原始 RMS 为 -35 / -38 dBFS。70 秒环境底在 74 秒时间线上按相应段落裁切和淡出；结尾让已有音乐收束即可。雨声只用于画面与天气相符的段落。

两个轻敲音和一个低频转场音可在动作、记忆出现或危机切换处轻用。它们是程序制作的后期音效，不标为游戏实录声。旁白期间降低配乐；对话面板阅读段避免音效过密。最终时间安排、响度平衡和 FFmpeg 合成由主剪辑脚本负责。
