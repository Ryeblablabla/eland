# Local exports

This directory contains generated run exports, frozen evidence bundles, and
media working files. They are local artifacts and are intentionally excluded
from Git.

Durable conclusions belong in `docs/`. When a raw export must be retained or
shared, store it in an external artifact archive and reference its identifier
from the corresponding document. Historical documents may still mention old
paths in this directory; those paths identify evidence from an earlier
revision rather than files bundled with a fresh checkout.
